# 003 その道は無電柱化されているか: 街路の写真から分類する

みちよみの街路のシーンが無電柱化されているかを、道の見た目から当てる分類の実験 (001-B、002-A、002-B、003-B、003-F、004-A から 004-C、011-A、011-B) を、データサイエンティストの作業の順に並べ直したもの。001 の携帯の速度と違い、こちらには信号がある。その代わりに、漏れと評価の分け方と確率の扱いが問題になる。数字は各実験の README から引いた (2026-09-29 に回したもの)。

## 1. 問題設定: 何のために分類するのか

- 想定した使い道: 無電柱化の記録が無い道について、写真から無電柱化の有無を推定する。
- 分類するもの: みちよみの `undergrounded` が「無電柱化済」(1) か「架空線あり」(0) か。「不明」は除く。
- 使う場面では、電柱が写っているかどうかは分からない (分かるなら分類は要らない)。この前提が、何を特徴量にしてよいかを決める。

## 2. データの確認

- みちよみ ([docs/datasets/michiyomi](../../docs/datasets/michiyomi/README.md)): Mapillary の写真 1 枚を VLM が読んだもの。台東区 53,948 シーン、23 区 1,386,941 シーン。特徴量に空のある行と隔離 (quarantined) されたシーンを除くと、台東区 32,593、23 区 988,619 ([001-B](../../src/001-B-logistic-regression/README.md))。
- 目的変数も特徴量も、同じ VLM の読み取りから来ている。ここで言う「当たる」は「VLM の判定と合う」の意味で、本当の無電柱化とは限らない。
- 偏り: 無電柱化済は台東区で 11.6%、23 区で 21.4%。
- 時期の偏り ([004-B](../../src/004-B-data-leakage/README.md)): 台東区の無電柱化済の割合は、2020 年以前の 4.9% から、2021 年以降は 17.6% に増えている。実際に進んだのか、撮影場所や VLM の読み方が変わったのかは分からない。
- 値の偏り ([011-A](../../src/011-A-shap/README.md)): 車道の幅は 5.5m、6m のようなきりのいい値に固まっている (VLM の推定の癖)。

## 3. ベースライン

- 全部「架空線あり」と答える: 精度は台東区 0.884、23 区 0.786。偏った問題では精度があてにならない ([001-B](../../src/001-B-logistic-regression/README.md))。
- ロジスティック回帰 (道と見た目の 6 つ): AUC は台東区 0.849、23 区 0.702。精度は 0.905 で、全部「架空線あり」とほとんど変わらない。

## 4. 指標

- AUC: 無電柱化の写真をそうでない写真より上に並べられるか。偏った問題でも差が出る。
- 確率として使うなら、ECE と Brier スコアも見る ([011-B](../../src/011-B-calibration/README.md))。AUC は順位しか見ない。
- 点数は、分割ごとの平均でなく、分割の外の予測をまとめて 1 回で測る。分割ごとの平均は、ばらつきの小さい 1 つの分割に振り回された ([002-A](../../src/002-A-decision-tree/README.md))。

## 5. モデル

AUC (ランダムな 5 分割):

- ロジスティック回帰: 台東区 0.849、23 区 0.702
- 決定木: 0.894 (深さ 7)、0.885 (深さ 11) ([002-A](../../src/002-A-decision-tree/README.md))
- ランダムフォレスト: 0.926、0.888 ([002-B](../../src/002-B-random-forest/README.md))
- XGBoost: 0.930、0.894 ([003-B](../../src/003-B-xgboost/README.md))

- 木にすると大きく上がる (23 区で 0.702 から 0.885)。線形で係数の向きが範囲で逆になった (台東区と 23 区で車道の幅の向きが逆) のは、効き方が線形でないからだったと読める。
- 部分依存で、細い道では緑が多いほど無電柱化済、という組み合わせの効果が見えた ([002-B](../../src/002-B-random-forest/README.md))。
- 行が少ないときは、表形式の基盤モデルの TabPFN が強い ([003-F](../../src/003-F-tabpfn/README.md))。23 区で別の地区を試験にすると、120 行の TabPFN (0.826) が 1,000 行の XGBoost (0.829) と同じで、3,000 行の TabPFN (0.877) と全 83 万行の XGBoost (0.890) の差は 0.013。ただし 10,000 行で 164 秒かかり、GBDT より数百倍遅い。
- XGBoost とランダムフォレストの差は 0.004 から 0.006 で小さい。学習率を下げると本数が増えるだけで AUC はほとんど変わらない (学習率 x 本数がほぼ一定)。
- 23 区の全 99 万行で森を作ると 16GB に達したので、20 万行の標本にした (AUC は全体で 0.893、標本で 0.888)。

## 6. 漏れ

- 答えの言い換え ([001-B](../../src/001-B-logistic-regression/README.md)): 見える電柱の数と電線の多さを入れると、AUC は 0.849 から 0.988 に跳ねる。電柱が写っていることは架空線の言い換えで、使う場面では使えない。SHAP では電柱の数が、ほかの全部を合わせたより大きく効く ([011-A](../../src/011-A-shap/README.md))。
- 間接的な漏れの疑い: 街灯の数は、多いほど「架空線あり」の側に効く。日本の街灯は電柱に付いていることが多いので、街灯の数が電柱の数の代わりになっている可能性がある (確かめていない)。
- 近所の答えの平均 (target encoding) ([004-B](../../src/004-B-data-leakage/README.md)): 同じ 250m 格子の無電柱化の割合を足すと、ランダムな分割では、全データで計算しても (0.970)、学習側だけで正直に計算しても (0.967) ほぼ同じに高く出る。空間で分けて正直に計算して初めて 0.854 に落ち、足さないとき (0.889) より悪いと分かる。

## 7. 評価の設計

AUC、XGBoost ([004-A](../../src/004-A-cross-validation/README.md)):

- 台東区: ランダム 0.931、撮影の続き 0.927、250m 格子 0.924、1km ブロック 0.889、2km ブロック 0.870
- 23 区: ランダム 0.894、2km ブロック 0.892、区ごと 0.887、22 区で学習して台東区 0.890

- 台東区では、空間で分けると点数がはっきり下がる。効いているのは「同じシーンの写し」より「近所どうしが似ている」こと。無電柱化は地区単位で進むので筋が通る。
- 台東区だけが下がるのは、範囲が小さくブロックが少ないため ([004-C](../../src/004-C-small-areas/README.md))。23 区すべてで区の中の空間ブロックは点数を下げ、ブロックの少ない区ほど大きく下がった (順位相関 -0.54、p = 0.008)。小さな区ほど、ほかの 22 区で学習したモデルのほうがよく当たる。
- 時間で分ける ([004-B](../../src/004-B-data-leakage/README.md)): 2020 年以前で学習して 2021 年以降を当てると 0.897、ランダムな分割の同じ行では 0.912。時間の漏れは小さい。

## 8. 説明

[011-A](../../src/011-A-shap/README.md) (XGBoost、分割の外の SHAP):

- SHAP の和は予測に戻る (差 10⁻⁵ 以下)。250m 格子で平均した SHAP の和は、実際の無電柱化の割合と相関 0.88。
- 上位 3 つ (車道の幅、街灯の数、緑の割合) は、平均 |SHAP|、gain、並べ替えの 3 つの測り方で同じ順。
- 効き方の形は、重要度の表では見えない。「広い道ほど無電柱化」ではなく、4m 未満の細い道が最も無電柱化済 (45.2%)。地図では上野公園の一帯に集まる。15m の道も強く無電柱化の側に効くが、特定の大通りが特定の値に集まっていると考えられ、滑らかな関係ではない。

## 9. 確率として使えるか

[011-B](../../src/011-B-calibration/README.md) (ECE、ランダムな 5 分割):

- ランダムフォレスト 0.004、XGBoost 0.012、ロジスティック回帰 0.018。AUC が同じランダムフォレストと XGBoost で、ECE は 3 倍違う。
- isotonic で較正すると、3 つとも改善した (ロジスティック 0.018 から 0.002)。Platt は木のモデルをかえって悪くした (0.004 から 0.019)。
- 250m 格子を丸ごと試験に回しても、この順位は変わらず、isotonic の ECE は 0.005 以下を保った。

## 10. 結論

- 道の見た目だけで、台東区で AUC 0.93 まで分類できる。ただし、新しい場所で使うときの点数は 2km ブロックの 0.87 に近い。
- 当たるモデルでも、何で当てているかを確かめる。電柱の数は答えの言い換えで、街灯の数にもその疑いがある。
- 近所の答えを使う特徴量は、ランダムな分割では良く見え、空間で分けて正直に作ると役に立たない。
- 小さな範囲だけで学ぶより、広い範囲で学んだモデルのほうが持ち出せる。
- 確率として使うなら、AUC とは別に較正を確かめ、isotonic で直す。
- 前提として、目的変数そのものが VLM の読み取りで、年による割合の変化の理由は分からない。
