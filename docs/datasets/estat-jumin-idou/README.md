# 総務省統計局 住民基本台帳人口移動報告

2026-10-04 に読んで確かめた内容。表の数と件数は、この日に e-Stat の API (`getStatsList`、`getDataCatalog`、`getMetaInfo`) を投げて数えた値。値そのものは `getStatsData` で小さい切り出しを 5 回取っただけで、全件は取っていない。ファイル配布は e-Stat の「ファイルから探す」の HTML を curl で読み、Excel は 3 本だけ取得して大きさを測った。統計局のページ (`stat.go.jp/data/idou/`) と、そこにある PDF (結果表の変更、正誤情報) も読んだ。

- 入口 (e-Stat のファイル): <https://www.e-stat.go.jp/stat-search/files?toukei=00200523&tstat=000000070001>
- 入口 (e-Stat のデータベース): <https://www.e-stat.go.jp/stat-search/database?toukei=00200523>
- 入口 (統計局): <https://www.stat.go.jp/data/idou/index.html>
- 政府統計コード `00200523`。e-Stat API と規約の一般的な話は [../estat/README.md](../estat/README.md)。
- 作成: 総務省統計局 (`getDataCatalog` の `CREATOR` と `CONTACT_POINT` は「統計局統計調査部国勢統計課」)。
- 中身: 住民基本台帳の転入届から作った、日本国内の住所の移動の件数。月次と年次。移動元 (移動前の住所地) と移動先 (移動後の住所地) の組み合わせを持つ表がある。
- 公表: 月次結果は翌月下旬、年次結果は翌年 1 月下旬から 2 月上旬、市区町村別の結果は 4 月下旬 (統計局の Q&A)。e-Stat の最新の公開日は 2026-09-29 (2026 年 8 月分の月報)。

## 何を数えた統計か

統計局の「統計の概要」(<https://www.stat.go.jp/data/idou/1.html>) と Q&A (<https://www.stat.go.jp/data/idou/qa-1.html>) から。

- 住民基本台帳法第 22 条の転入届と、第 8 条の職権記載があった転入者の、住所 (市区町村コード)、性別、出生年月日、異動事由、異動年月を、住民基本台帳ネットワークシステムから受け取って集計している。
- 同じ市区町村の中での住所の変更と、従前の住所が不詳の者は含まない。同じ人が期間中に 2 回以上移れば、その都度数える。人数ではなく件数。
- 年次結果は月次結果の合計 (Q&A 12)。年次の値が月次と別に推計されることは無い。
- 外国人は 2013 年 7 月 8 日以降が対象 (住民基本台帳法の改正で外国人が住基ネットに載った日)。
- 地域は、年報は 12 月末、月報は月末の市区町村の境域で表章する (利用上の注意 <https://www.stat.go.jp/data/idou/riyou.html>)。合併などの扱いは各表の脚注にある。
- 記号は「－」が定義上該当数値がないもの、「…」が集計していないもの。API の `NOTE` では`***` が調査していないもの、`-` が定義上該当数値がないもの。
- 前身は 1954 年 (昭和 29 年) の「住民登録人口移動報告」。e-Stat の長期時系列表は昭和 29 年から始まる。

### 属性 (男女、年齢、国籍)

- 男女はほぼすべての表にある。
- 年齢は 2010 年から (Q&A 7)。各歳、5 歳階級、3 区分 (0〜14、15〜64、65 以上)。市区町村の参考表は 10 歳階級 (0〜9 から 60 歳以上まで 7 区分と不詳)。
- 国籍の分け方は 3 段階で変わった。
  - 2013 年まで: 日本人移動者だけ。
  - 2014 年から: 「移動者 (外国人含む)」が加わる。名前は年次が 2014 年結果から、月次が 2015 年 1 月分から「総移動者 (外国人含む)」を「移動者 (外国人含む)」に変えた。2013 年 7 月分から 2014 年 12 月分は遡って直すと告知されている (統計局 PDF <https://www.stat.go.jp/data/idou/pdf/betten2.pdf>)。
  - 2020 年から: 「外国人移動者」が別に立ち、「移動者 (外国人含む)」は「移動者」に名前が変わった (移動者 = 日本人移動者 + 外国人移動者。<https://www.stat.go.jp/data/idou/pdf/henko20200227.pdf>)。
- 実際の値で確かめた。都道府県間の表 `0003420481` で東京都の転入者 (移動前の住所地 総数、男女 総数) を引くと、日本人移動者は 2010 年から、移動者は 2014 年から、外国人移動者は 2020 年からしか行が無い。2014 年は移動者 431,670、日本人移動者 404,736。2025 年は移動者 451,843、日本人移動者 397,985、外国人移動者 53,858。
- 同じ期間をまとめた表でも、国籍の範囲が揃っていない。`0004009739` (1999〜2019) の移動者は 2018 年と 2019 年にしか無く、2014〜2017 年の移動者は `0003420481` にしか無い。
- 国外との出入り (国外からの転入、国外への転出、職権消除等) は 2020 年から別に集計している (`0003423635` 月次、`0003423029` 年次の市区町村)。1999〜2006 年の年ごとの束にも「国外からの転入者数」の表がある (`0000180013` など)。

## 過去の表は消えるか、値は変わるか

- 古い表は残っている。1999 年の束 (`0000180001` など、`OPEN_DATE` 2007-10-03) は今も API で引ける。
- 置き換えではなく、まとめ直しの表が足される。2010〜2019 年の年齢別の表は、年ごとの束の中の表が残ったまま、`年報（年齢別）2010年～2019年` の 18 表が 2023-03-20 に足された。1999〜2019 年の `年報（総数）2019年以前` の 7 表は 2024-03-13、日本人移動者の月報 3 表 (`0004022280`〜`0004022282`) は 2025-04-11 に公開された。同じ値が複数の表に重なって入っている。
- 同じ ID の表の中身と題名が変わる。2020 年以降の表は年が足されるたびに `OPEN_DATE` が書き換わる (`0003419943` は 2026-04-23)。月報 `0003423614` は、Internet Archive の 2022-05-18 と 2025-02-16 の保存では題名が「（移動者）（2021年1月～）」だったが、2026-10-04 の API では「（移動者）（2019年1月～）」で、期間が前に延びている。
- `UPDATED_DATE` は束で書き換わっている。多いのは 2023-10-31 (143 表)、2022-11-15 (118 表)、2019-02-25 (54 表)、2025-11-28 (32 表)。何が変わったのかは API からは分からない。
- 速報と確報の区別は無い。年次は月次の合計で、年次の公表は 2 回に分かれる (2024 年結果から、都道府県と大都市の表は 1 月下旬、市区町村の表は 4 月下旬。<https://www.stat.go.jp/data/idou/pdf/henko20240131.pdf>)。
- 誤りは公表後に直される。統計局の正誤情報 (<https://www.stat.go.jp/data/seigo/idou/index.html>) には 2010 年から 11 件ある。最新は 2025-11-21 の「年報（実数）2024年 第10表（秋田県）」で、e-Stat の「EXCEL」の列のずれを直したもの。「EXCEL閲覧用」と「DB」には誤りが無かったと書かれている。2022-06-06 には長期時系列表の第 1、3、5、11 表 (昭和 57 年、平成 7 年、平成 17 年) が直されている。
- 移動率は分母が変わって系列が切れた。2020〜2024 年は人口推計、2025 年からは住民基本台帳人口に基づく移動率で、別の表になっている。
- e-Stat の利用規約は「コンテンツは、予告なく変更、移転、削除等が行われることがあります」と書いている。

取得した版を固定するには、取得日と各表の `UPDATED_DATE` を残す必要がある。

### API の getDataCatalog との対応

同じデータセットの中で同じ名前を持つリソースを 1 項目として、DB があるかどうかで分けた。

## 取り出し方

区分は catalog。`getStatsList` で表を、`getDataCatalog` でファイルを列挙できる。都道府県や市区町村で分けるには `getStatsData` の `cdArea` や `cdCat01` で絞る。

- `getStatsData` は 1 回に 100,000 件まで。471 表の件数を表ごとに 100,000 で割って切り上げると 2,474 回。1 秒あけると、応答時間を除いて約 41 分。
- 件数の 69% (144,658,035) は参考表の年齢別の第 1、2 表 (28 表)。これを除くと 64,643,929 件、要求は約 1,016 回。
- JSON の応答は 1 件あたり 120〜140 バイトだった (5 回の切り出しで測った)。2 億 900 万件をそのまま JSON で取ると 25〜30GB ほどになる見込み (測っていない、比例で出した値)。
- 同じ値が年ごとの表とまとめの表に重なって入っているので、件数の合計は中身の量より多い。
- 1999〜2006 年の束 (143 表) と季報 (4 表) はカタログから辿れないので、`getStatsList` から拾う。
- 長期時系列表 66 件と 1999〜2006 年のファイルだけの表は、Excel を取るしかない。
- 統計 LOD にもグラフ `g00200523` (659,898 トリプル) がある ([../estat/lod.md](../estat/lod.md))。どの表が入っているかは確かめていない。
