# WDI Database Archives (WDI の過去の版)

2026-10-03 に読んで確かめた内容。大きさは HEAD と Range で測り、データ本体は落としていない。
件数は API の応答の `total` と、少数の要求で返った行を数えたもの。

- WDI の過去の版を版ごとに残したデータベース。API では source 57、コード `WDA`。
- 入口: `https://datatopics.worldbank.org/world-development-indicators/wdi-archives.html`
- DataBank: `https://databank.worldbank.org/source/wdi-database-archives`
- API: `https://api.worldbank.org/v2/sources/57/`
- 親項目は [README.md](README.md)。現行の WDI の一括配布と既定のライセンスはそちら。

## 版は 142 ある

`https://api.worldbank.org/v2/sources/57/version?format=json&per_page=200` が 142 件を返す。
最古が `198904` (1989 Apr)、最新が `202607` (2026 Jul)。

`https://api.worldbank.org/v2/source/57?format=json` の `lastupdated` は 2025-10-29 のままで、
それより新しい版 (202510 から 202607 の 7 件) が入っている。`lastupdated` では版の追加が分からない。

版の id とラベルが食い違うものがある。

| id | ラベル |
|---|---|
| 199309 | 1994 Sep |
| 201703 | 2017 Apr |
| 201704 | 2017 Mar |

id を正とし、ラベルは参考にとどめる。

## 世界銀行自身が版ごとの zip を置いている

入口のページ (WDI Archives) の「Archives by Year」に、版ごとの zip へのリンクが 121 本ある。
リンク先は `http://databank.worldbank.org/data/download/archive/<名前>.zip` または
`.../download/Archive/<名前>.zip` で、`https://databankfiles.worldbank.org/public/ddpext_download/archive/<名前>.zip` に転送される。
121 本すべてに HEAD を送り、すべて 200、すべて `accept-ranges: bytes` だった。

合計 8,642,378,760 バイト、8.05GiB。

ページ自身の説明はこう。

> These archives contain Excel spreadsheets and range in size from 36-80Mb (compressed).
> Archives from July, 2010 to October, 2012 also include data from the Global Development Finance (GDF) report
> (now named International Debt Statistics). Archives prior to April, 2010 also include data in text and MS Access formats

データカタログの WDI のエントリ (下の節) も、Excel file の説明で同じページを指して
「Archives of all WDI releases since April 1, 2005」と書いている。2005 年 4 月より前の版の zip は無い。

### 形式は時期で 3 つに分かれる

中央ディレクトリだけを Range で読んで中身を見た。1 本あたり読んだのは末尾の 65,536 バイト。

| 時期 | 名前 | 中身 |
|---|---|---|
| 2005-04 から 2010-04 | `WDI_YYYY_MM.zip` | テキスト (`WDIdata_*.txt`, `WDInotes_*.txt`)、Access (`WDIonline_*.mdb`)、系列と国の表 (`WDIseries_*.xls`, `WDIcountry_*.xls`) |
| 2010-07 から 2012-10 | `WDIandGDF_excel_YYYY_MM.zip` | `WDI_GDF.xlsx` 1 つ (GDF、今の IDS を含む) |
| 2012-12 以降 | `WDI_excel_YYYY_MM.zip`、2017-09 以降は `WDI_excel_YYYY_MM_DD.zip` | `WDI.xlsx`、`WDI_EXCEL.xlsx` または `WDIEXCEL.xlsx` 1 つ |

2012-12 以降は xlsx が 1 つだけで、xlsx 自体が圧縮済みなので zip の圧縮はほぼ効いていない。
CSV ではないので、取ったあとに xlsx を読む工程が要る。

`WDI_excel_2012_12.zip` の中の xlsx は時刻が 2013-03-21 で、名前の月より 3 か月新しい。
`WDI_2005_04.zip` の mdb も 2005-09-22 になっている。zip が版の公開時点そのままとは限らない。

サーバーの `Last-Modified` は 97 本が 2023-01-25 で、残りも 2023-12 から 2026-03 のいずれか。
置き直された日付で、版の日付ではない。

### API の版との対応

zip の名前の年月と API の版の id を突き合わせると、121 本のうち 117 本が一致する。

- zip にあって API の版に無い年月: 2021_10、2022_06、2023_06、2024_02。
- API の版にあって zip が無いもの: 2005 年より前の 21 版 (198904 から 200404)、201806、202403、202604、202607。

2024_02_22 の zip と 202403 の版は同じものかもしれないが、値を突き合わせてはいない。
年月が一致しない 4 本が API のどの版に当たるかも確かめていない。

## Internet Archive に残る WDI_CSV.zip

CDX で 2 つの URL を引いた。

```
https://web.archive.org/cdx/search/cdx?url=databank.worldbank.org/data/download/WDI_CSV.zip&output=json
https://web.archive.org/cdx/search/cdx?url=databankfiles.worldbank.org/&matchType=prefix&output=json&filter=urlkey:.*wdi.*
```

CDX の `length` は WARC レコードの圧縮後の長さで、ファイルの大きさではない。
たとえば 2026-05-08 の保存は `length` が 78,027,304 だが、ファイルは 280,478,558 バイトある。
大きさは `https://web.archive.org/web/<時刻>id_/<元の URL>` に Range を送り、`Content-Range` の全長で測った。
Wayback も Range に 206 で応じるので、中央ディレクトリだけを読める。

ステータス 200 で digest の異なる保存が 50 件あった。そのうち 3 件は欠けている。

- 2019-03-28 (`length` 10,003,279)、2022-04-19 (`length` 21,758,099) は前後の版よりずっと小さく、途中で切れている。読んでいない。
- 2021-11-06 は `length` 471 で、`id_` で開くと 2021-05-27 の保存と同じファイルが返った。

残る 47 件は中央ディレクトリが読め、47 件とも別の中身だった。最古は 2013-05-22 の保存、最新は 2026-05-08 の保存。
2024-08 以降は 404 の保存も多く、2026-08-25 の保存は 404 だった。

## API で取る場合

### 格子は版によらず 292 国 × 67 年

`sources/57/series` が 2,836、`sources/57/country` が 292、`sources/57/time` が 67 (YR1960 から YR2026) を返す。
1 系列 1 版を `country/all/time/all` で引くと、版によらず 292 × 67 = 19,564 行が返り、値の無いセルは `null`。

| 版 | 系列 | 行 | null でない |
|---|---|---:|---:|
| 199004 | SP.POP.TOTL | 19,564 | 2,860 (YR1968 から YR1988) |
| 202607 | SP.POP.TOTL | 19,564 | 17,394 (YR1960 から YR2025) |
| 199004 | IT.NET.USER.ZS | 19,564 | 0 |

1990 年の版にまだ無い系列 (インターネット利用率) でも、19,564 行の `null` が返る。
どの版にどの系列があるかを API から先に知る手段は見つけていない
(`sources/57/version/199004/series` は HTML のエラーページを返す)。全部引くなら版ごとに 2,836 系列すべてを回すことになる。

1 版の格子は 2,836 × 19,564 = 55,483,504 セル。null でないセルの数は版ごとに測っていない。
参考に、202607 の版で人口・GDP・平均寿命など主要 10 系列を引いた 195,640 行のうち 115,157 行 (58.9%) が null でなかった。
主要系列に偏った標本なので、全系列の割合はこれより低いはず。

### 1 回の要求

URL の形は次のとおり。系列は `;` で複数並べられる。

```
https://api.worldbank.org/v2/sources/57/country/all/series/<系列;系列;...>/time/all/version/<版>/data?format=json&per_page=<N>
```

応答は `{page, pages, per_page, total, lastupdated, source: {id, name, data: [...]}}` の形。
`data` の各要素は `variable` (Country, Version, Series, Time の 4 つ) と `value`。

| 系列数 | per_page | 行 | 本体 | gzip 時の転送 | 時間 |
|---:|---:|---:|---:|---:|---:|
| 1 | 20,000 | 19,564 | 5,049,053 | 計らず | 1.6 秒 |
| 2 | 40,000 | 39,128 | 10,266,964 | 計らず | 4.6 秒 |
| 3 | 60,000 | 58,692 | 15,844,576 | 675,346 | 2.9 秒 |
| 10 | 200,000 | 195,640 | 55,136,137 | 1,832,942 | 7.3 秒 |

source 57 では `per_page=200000` でも 1 ページで返った。README.md が source 2 の指標 API で測った
上限 (32,500 と 50,000 の間) はここには当たらない。上限は確かめていない。
1 行あたり本体が約 282 バイト、gzip で約 9.4 バイト。`--compressed` を付けると転送は 3.3% になる。

`country/all/series/all/time/all` を 1 版まるごと引こうとすると、`per_page=1` でも 60 秒以内に応答が返らなかった (2 回)。

応答ヘッダーは Cloudflare 経由 (`cf-cache-status: MISS`, `cache-control: public, max-age=86400`)。
レートリミットを示すヘッダーは無く、1 秒あけて 31 回投げたかぎりでは 429 は返らなかった。

### 全版の見積もり

10 系列ずつ、1 秒あけて引くとした場合。

| 範囲 | 要求 | 時間 | 本体 | gzip 時の転送 |
|---|---:|---:|---:|---:|
| 1 版 | 284 | 約 39 分 | 約 15.6GB | 約 520MB |
| 142 版 | 40,328 | 約 93 時間 | 約 2.2TB | 約 74GB |
| zip の無い 2005 年より前の 21 版 | 5,964 | 約 14 時間 | 約 330GB | 約 11GB |

時間は 1 回 7.3 秒と間隔 1 秒の和で見た。gzip の比は主要系列で測った値で、全部 `null` の系列はもっと縮むはず。
1 回にまとめる系列を増やせば要求は減るが、試したのは 10 系列まで。

## 版ごとのメタデータは取れない

`sources/57/series/SP.POP.TOTL/metadata` と `sources/57/series/SP.POP.TOTL/version/199004/metadata` は
バイト単位で同じ 6,143 バイトを返した。`version` は無視され、返るのは現行の定義
(`Referenceperiod` が 1960-2025、出典が World Population Prospects)。
国のメタデータ `sources/57/country/USA/metadata` も現行の内容 (BPM6、人口センサス 2020) だった。

`sources/57/series/all/metadata?per_page=30000` が 1 回で全系列を返す (本体 8,342,514 バイト)。
メタデータがあるのは 2,836 系列のうち 2,137 系列で、699 系列には無い。`Dataset` の内訳は
WB_WDI 1,467、International Debt Statistics 172、WDI 16、記載無し 482。

版ごとの定義や国の一覧が要るなら、Excel の zip の中の系列表・国表 (2005 から 2010 年の版は
`WDIseries_*.xls` と `WDIcountry_*.xls`、それ以降は xlsx の中のシート) から取ることになる。xlsx のシート構成は確かめていない。

## 202607 の版は現行の WDI と同じ値

5 国 (USA, JPN, BRA, IND, NGA) × 3 系列 (SP.POP.TOTL, NY.GDP.MKTP.CD, SP.DYN.LE00.IN) × 4 年
(2015, 2020, 2023, 2024) の 60 点を、source 57 の 202607 と 202604、source 2 で引いて比べた。

| 比べたもの | 一致 |
|---|---:|
| 57 の 202607 と source 2 | 60 / 60 |
| 57 の 202604 と source 2 | 40 / 60 |

202607 は現行の WDI (source 2、`lastupdated` 2026-07-13) と全点で一致した。
202604 とは GDP を中心に 20 点が違う。たとえば JPN の 2024 年の GDP は 202607 が 4,190,008,188,358.57、
202604 が 4,027,597,523,550.58。USA の 2024 年の人口は 340,003,797 と 340,110,988。

WDA には現行の版も入っている。2026-10-01 の WDI_CSV.zip (データカタログの節) の版はまだ API の版の一覧に無い。

## ライセンス

WDA に専用のライセンスの記載は見つからなかった。

- データカタログに WDA 単独のエントリは見つけていない。WDI のエントリ (0037712) が Excel file の説明で
  アーカイブのページを指しているだけで、そのエントリのライセンスは「Creative Commons Attribution 4.0」。
- アーカイブのページ自体にライセンスの記載は無い。
- カタログ API (`https://datacatalogapi.worldbank.org/ddhxext/Search`、`.../DatasetView`) は
  4 回とも 429 `Rate limit is exceeded` を返し、数十秒から数分あけても変わらなかった。ここからは読めていない。

条件は系列ごとのメタデータに書かれている。`sources/57/series/all/metadata` の `License_Type` を数えた。

| License_Type | 系列 |

| CC BY-4.0 | 2,087 |
| IEA terms and conditions | 22 |
| CC BY-NC 4.0 | 12 |
| IRF terms and conditions | 7 |
| SIPRI terms and conditions (商用不可) | 6 |
| CAIT のデータとして CC BY-NC 4.0 | 2 |
| ITU terms and conditions | 1 |

CC BY でない 50 系列。

  EN.CO2.BLDG/ETOT/MANF/OTHX/TRAN の .MT と .ZS、IS.ROD.* の 7 系列、IT.TEL.REVN.GD.ZS
- CC BY-NC 4.0 (14 系列): EN.ATM.CO2E.KD.GD、EN.ATM.CO2E.KT、EN.ATM.CO2E.PC、EN.ATM.CO2E.PP.GD、EN.ATM.CO2E.PP.GD.KD、

  記載は「SIPRI data may not be used for commercial purposes ... Use of more than 10 percent of any SIPRI data set for
  non-commercial purposes ... must be directly authorized by SIPRI」。

CC BY 4.0 の系列は、既定のライセンスと調停・仲裁の追加条項 (README.md のライセンスの節) と同じ扱いで、
`License_URL` は `https://datacatalog.worldbank.org/int/public-licenses#cc-by` (1,450 系列) か
`https://datacatalog.worldbank.org/public-licenses#cc-by` (626 系列) を指す。

注意すること。

- メタデータは現行のもので、版ごとではない (前の節)。過去の版を配ったときの条件が今の記載と同じだったかは分からない。
- 699 系列はメタデータが無く、API からは条件が読めない。
- Excel の zip は全系列を 1 ファイルに入れているので、CC BY-NC と SIPRI の系列が混ざっている。
  丸ごと CC BY 4.0 として再配布すると、系列のメタデータと食い違う。SIPRI は 10% を超える非商用利用にも許可を求めている。

## 取り出し方

区分は whole。版ごとの zip が世界銀行自身の置き場にあり、Range で中身の一覧も取れる。

| 版 | 手段 | 実測 |
|---|---|---|
| 200504 から 202602 (117 版、ほかに年月の合わない 4 本) | `databankfiles.../archive/` の Excel の zip | 121 本、8.05GiB、すべて 200 |
| 202604、202607 | データカタログの `WDI_CSV_2026_04_09.zip`、`WDI_CSV_2026_07_15.zip` | 280,478,558 と 282,845,220 バイト |
| 202403 (かもしれない) | `WDI_excel_2024_02_22.zip` か Wayback の 2024-05-17 の保存 | 値の照合は未実施 |
| 198904 から 200404 (21 版)、201806 | Indicators API の source 57 | 21 版で 5,964 要求、約 14 時間 (見積もり) |
| CSV で揃えたい 2013 年以降の一部 | Wayback の WDI_CSV.zip | 47 件、Range 可、5 秒以上あける |

zip で取れない版だけを API で補う形にすれば、API の要求は 142 版全部の 40,328 から 6,248 (22 版) に減る。
