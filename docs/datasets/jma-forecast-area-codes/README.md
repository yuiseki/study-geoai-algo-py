# 気象庁 予報区等のコード表と予報区等 GIS データ

2026-10-03 に読んで確かめた内容。ページは curl で取得して読んだ。大きさと Last-Modified は HEAD、コード表は最新の個別コード表 `jmaxml_20260917_Code.zip` (1,684,136 bytes) を 1 本だけ取得して中を数えた。GIS データは Range 要求で zip の目録と、`府県予報区等` と `市町村等（気象警報等）` の 2 本の dbf と shp の見出しだけを読んだ。本体の shp は落としていない。

気象警報・注意報などの区域は、2 つの資料に分かれて配られている。

- コード表: 気象庁防災情報 XML フォーマットの「個別コード表」。府県予報区、一次細分区域、市町村等などのコードと名前と所属関係。Excel。
- 予報区等 GIS データ: 同じコードが示す区域の形。Shapefile。

## 入口

- コード表: <https://xml.kishou.go.jp/tec_material.html> (気象庁防災情報XMLフォーマット 技術資料)。過去の版は <https://xml.kishou.go.jp/past_reference.html>、更新情報は <https://xml.kishou.go.jp/revise.html>。
- GIS データ: <https://www.data.jma.go.jp/developer/gis.html> (気象データ高度利用ポータルサイト「予報区等GISデータの一覧」)。技術資料のページに「コード表が示す予報区等のGISデータについて、「高度利用ポータルサイト」で提供しています。」とある。
- e-Gov データポータル: <https://data.e-gov.go.jp/data/api/3/action/package_show?id=mlit_20140919_0758> (「気象警報・注意報等に用いる府県予報区、一次細分区域等のコード」)。リソースの URL は `https://xml.kishou.go.jp/jmaxml_20170706_Code.zip` だが、このファイルはもう無い (HEAD が 404)。e-Gov は配布元ではなく、古い版を指した目録の 1 行にすぎない。

## 取り出し方

区分は split。

- コード表は 1 本の zip (1,684,136 bytes) にまとまっている。xlsx 単体の「コード管理表一式」(`jmaxml_20260917_code.xlsx`、98,888 bytes) は別物で、コードの一覧ではなく管理表。個別コード表は zip を丸ごと取るしかない。小さいので問題にならない。
- GIS データは区域の種類ごとに 19 本に分かれていて、必要な種類だけ取れる。地域 (都道府県) では分かれていない。
- `curl -r 0-1023` は、コード表の zip (`xml.kishou.go.jp`) にも GIS の zip (`www.data.jma.go.jp`) にも 206 を返した。GIS の zip は Range で目録 (zip の中央ディレクトリ) を読み、dbf だけを抜き出せた。ただし shp は 1 本のファイルで索引が無いので、区域の一部の形だけを取ることはできない。形が要るなら最小でも約 94MB の zip を丸ごと取る。
- 目録は HTML ページだけ。機械可読の一覧は無い。ファイル名は `<日付>_<コード表の名前>_GIS.zip` と `jmaxml_<日付>_Code.zip` で、日付が変わるので、決め打ちの URL は版が上がると 404 になる。

## ライセンス

GIS のページも、防災情報 XML の Q&A も、気象庁ホームページの利用規約を指している。

気象庁ホームページについて (<https://www.jma.go.jp/jma/kishou/info/coment.html>、2026-10-03 に読んだ) の「利用規約」:

> 気象庁ホームページで公開している情報（以下「コンテンツ」といいます。）は、権利表記の記載がない限り「公共データ利用規約（第1.0版）」に準拠した利用条件の下で、利用することができます。 利用に当たっては、公共データ利用規約（第 1.0 版）を遵守してください。

出典の記載:

> コンテンツを利用する際は出典を記載してください。出典の記載方法は以下のとおりです。
> （出典記載例）
> 出典：気象庁ホームページ　（当該ページのURL）

> コンテンツを編集・加工等して利用する場合は、上記出典とは別に、編集・加工等を行ったことを記載してください。
> また編集・加工した情報を、あたかも国（又は府省等）が作成したかのような態様で公表・利用してはいけません。

加工したときの記載例は「気象庁「図・写真等の名称」 （当該ページのURL）を加工して作成」。

個別法令による制約として、気象業務法の第十七条 (予報業務の許可) と第二十三条 (警報の制限) が挙がっている。どちらも予報や警報を出す行為の制約で、区域のコードや形を再配布することには関わらないと読めるが、規約はそこまで書いていない。

GIS のページの「利用上の留意点」:

> ・データの利用においては、気象庁ホームページの利用規約を遵守ください。

防災情報 XML の Q&A (<https://xml.kishou.go.jp/qanda.html>) には、XML 電文について「いずれも商用利用への制限はございません」とある。これは電文の話で、コード表と GIS データについての答えではない。

- PDL1.0 は CC BY 4.0 と互換で、商用と再配布を認める。出典の記載が条件。
- コード表は、ページにも xlsx にも別の権利表記は見当たらなかった。PDL1.0 の下で Hugging Face に置ける見込みが高い。
- GIS データには国土地理院長の承認番号の注記がある。これは気象庁が地理院の地図を使って作ったことについての測量法の承認で、利用者がこの Shapefile を再配布するときに改めて承認が要るかどうかは、ページも規約も書いていない (未確認)。PDL1.0 の「権利表記」にこの注記が当たるのかも書かれていない (未確認)。再配布するなら、出典に加えてこの承認番号の注記もそのまま付けておくのが安全。

### e-Gov のメタデータとの関係

- e-Gov のリソースの `license_id` は `gjstu`。e-Gov の `license_list` では `gjstu` の title は「政府標準利用規約（第 2.0 版）」。データセット (package) の `license_id` は null。
- 政府標準利用規約 2.0 も PDL1.0 も CC BY 4.0 互換で、条件 (出典の記載、加工の表示、国が作ったように見せない) はほぼ同じ。食い違いは、規約の名前と版が古いことだけで、利用できる範囲は変わらない。現行の配布元の規約は PDL1.0。

## 未確認の点

- GIS データを再配布するときに、測量法に基づく国土地理院の承認が改めて要るか。PDL1.0 の「権利表記」に承認番号の注記が当たるか。
- GIS の `市町村等（気象警報等）` 1,821 レコードと、コード表の気象警報・注意報で使う市町村等 1,805 コードの差の理由。
- GIS データで中を見たのは 2 本だけ。残り 17 本の列、レコード数、`.prj` の有無、文字コードは、データ定義書と同じだと仮定している。
- 3 年より古いコード表と、差し替え前の GIS データを取る手段 (国立国会図書館の WARP などのアーカイブは調べていない)。
