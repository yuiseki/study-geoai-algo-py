# 国税庁 法人番号公表サイト 基本 3 情報 (全件データ・差分データ)

2026-10-03 に読んで確かめた内容。ページは curl で取得して読んだ。中身は全件データの鳥取県 (CSV 形式・Shift-JIS、`31_tottori_all_20260930.zip`) 1 本と、差分データ (CSV 形式・Shift-JIS、`diff_20261002.zip`) 1 本を取得して数えた値。列の意味は配布元の「リソース定義書」(Excel 版、4.1 版) で確かめた。全国のファイルは落としていない。大きさはダウンロード画面の表示の値。

- 入口: <https://www.houjin-bangou.nta.go.jp/download/> (ページ名「基本３情報ダウンロード」)。全件データは <https://www.houjin-bangou.nta.go.jp/download/zenken/>、差分データは <https://www.houjin-bangou.nta.go.jp/download/sabun/>。

- 中身: 法人番号の指定を受けた法人等の基本 3 情報 (商号又は名称、本店又は主たる事務所の所在地、法人番号) と、それに付随する項目 (法人種別、郵便番号、登記記録の閉鎖等、英語表記、フリガナなど)。1 法人 1 行 (全件データ)。

- 全件データは月 1 回 (前月末時点)、差分データは平日に毎日。サイトに置かれている全件データは最新の 1 版だけで、差分データは過去 40 日分。

## 中身

### 文字コードと形式

- 配布は zip。CSV 形式・Shift-JIS、CSV 形式・Unicode、XML 形式・Unicode の 3 種類。ページの説明では、Shift-JIS は「JIS第一・第二水準」、Unicode は「JIS第一～第四水準」。
- 鳥取県の Shift-JIS の CSV は cp932 で読めた。改行は CRLF、BOM なし。見出し行は無い (1 行目からデータ)。全角文字の列はダブルクォートで囲まれる。
- Shift-JIS 版では、第一・第二水準に無い文字は「JIS縮退マップ」で置き換えられ、置き換え先の無い文字は「＿」になる (ページの説明)。鳥取県では「＿」が 12 か所あった。元の字形は `商号又は名称イメージID` などのイメージ ID で画像として見られる。
- Unicode の CSV の実ファイルは取っていない。サンプルデータの Unicode 版の CSV は UTF-8 (BOM なし) だった。実ファイルも同じかは未確認。
- 各 zip に OpenPGP の署名ファイル (`.asc`) が入っている。

### 住所と座標

- 住所はある。本店又は主たる事務所の所在地が、`国内所在地（都道府県）`、`国内所在地（市区町村）`、`国内所在地（丁目番地等）` の 3 列に分かれている。定義書には、利用者が分割する手間を省くために分けた、とある。
- `国内所在地（市区町村）` には郡名が付く (`岩美郡岩美町`、`八頭郡智頭町`)。政令指定都市は区まで入り (`横浜市鶴見区`、`市区町村コード` は `101`)、東京の特別区は区名だけ (`千代田区`、`101`)。差分データ 1 本で確かめた。
- `国内所在地（丁目番地等）` は全角の数字と記号 (`東町２丁目２２３`、`富安１丁目２２０番地２丸壽ビル３階`)。建物名や階が入る行もある。
- `都道府県コード` (2 桁) は JIS X 0401、`市区町村コード` (3 桁) は JIS X 0402 に準ずる (定義書)。並べると検査数字なしの 5 桁の地方公共団体コードになる。鳥取県では `市区町村コード` の空は 0 行。
- `郵便番号` は 7 桁、ハイフンなし。定義書の説明では、所在地の文字から全国町・字ファイルで引いたもので、個別郵便番号や地番ごとの郵便番号には対応していない。鳥取県では 20,258 行のうち 11 行が空。
- 緯度経度の列は無い。地図に置くにはジオコーディングが要る。
- 本店が国外にある法人は `国外所在地` に住所が入り、`国内所在地` には国内の事務所又は営業所の所在地が入る (定義書)。
- `検索対象除外` が 1 の行は、登記上の所在地が住居表示の実施や区画整理で廃止され、今は存在しない住所表記になっている設立登記法人 (定義書)。鳥取県では 32 行。住所が今の住所として引けない行の目印になる。
- 英語表記とフリガナは届出があった法人だけ。鳥取県では英語の名称が 149 行、フリガナが 11,382 行。

### 閉鎖した法人と人格のない社団等

- 閉鎖した法人も全件データに残る。FAQ (<https://www.houjin-bangou.nta.go.jp/shitsumon/shosai.html?selQaId=00147>) の原文:

> 清算の結了等をした場合、法人番号公表サイトでは、法令（番号法第39条第４項、番号法施行令第41条第３項）に基づき、法人番号、名称、所在地を引き続き公表するほか、清算の結了等の事由が生じた旨と生じた年月日を公表します。

- 鳥取県では 20,258 行のうち 2,809 行に `登記記録の閉鎖等年月日` がある (約 14%)。事由は 01 清算の結了等 1,896、21 登記官による閉鎖 688、11 合併による解散等 218、31 その他の清算の結了等 7。いま存在する法人だけを使うなら、この列で除く。
- 人格のない社団等は、代表者又は管理人が公表に同意したものだけが載る (FAQ <https://www.houjin-bangou.nta.go.jp/shitsumon/shosai.html?selQaId=00012>)。同意を撤回すると処理区分 99 (削除) の行が差分に出て、一連番号、法人番号、更新年月日以外は空になる (定義書)。
- 設立登記法人は公表を止められない (FAQ selQaId=00061)。所在地が自宅と同じでも、住所の削除や一部非表示はできない (FAQ selQaId=00153)。

## 取り出し方

区分は split。全国 1 本のほかに、47 都道府県と国外の単位で分かれている (CSV で 50 本、XML で 67 本)。各ファイルの中は whole。

- ダウンロードは GET の URL ではない。画面のリンクは `doDownload(ファイル番号)` という JavaScript で、フォームを `/download/zenken/index.html` (差分は `/download/sabun/index.html`) へ POST する。送る値は `event=download`、`selDlFileNo=<ファイル番号>`、ページに埋め込まれたトークン (`jp.go.nta.houjin_bangou.framework.web.common.CNSFWTokenProcessor.request.token`)。ページを GET したときのクッキーとトークンを付けて POST すると、`Content-Disposition` 付きで zip が返った。利用規約への同意の画面は無かった。
- ファイル番号は版ごとに変わる (2026-09-30 版の鳥取県 CSV・Shift-JIS は 28222、全国は 28110)。決まった URL は無いので、毎回ページから読む。
- POST の応答に `Content-Length` は無く、`Range: bytes=0-1023` を付けても 206 ではなく 200 で全体 (843,752 bytes) が返った。HEAD や Range で大きさを測れない。大きさは画面の表示だけが手がかり。
- 目録は HTML のダウンロード画面だけ。e-Gov の CKAN はページの URL を指すだけで、ファイルの一覧は持っていない。
- 全件データを 1 回取り、以後は差分データ (日次、40 日分) で追う使い方を配布元が想定している。

### Web-API

<https://www.houjin-bangou.nta.go.jp/webapi/> による。

- REST 方式。機能は「法人番号を指定して情報を取得する機能」「取得期間を指定して情報を取得する機能」「法人名を指定して情報を取得する機能」(法人名は Ver.2.0 以降)。期間と法人名の検索は、所在地 (都道府県・市区町村) と法人種別で絞れる。Ver.1.0 から 4.0 まであり、版が上がるごとに英語表記、フリガナ、検索対象除外が加わる。項目は全件データと同じリソース定義書で定義される。
- ページの注記に「Web-API機能では全件データを取得することはできません。」とある。
- 1 回で返る件数は 2,000 件までで、超えると分割され、分割番号を増やして繰り返し取る (定義書の `divideNumber`)。
- 法人番号を指定する機能では、変更履歴も併せて取れる。
- 使うにはアプリケーション ID が要る。無料。発行の手続は国税庁適格請求書発行事業者公表サイト (<https://www.invoice-kohyo.nta.go.jp/web-api/index.html>) で行い、発行まで「２週間から１か月程度」。
- 検証環境 (架空の法人) がある。
- Web-API は catalog に近い使い方 (法人番号、期間、名称、地域で絞って取る) ができるが、全件は取れない。

### Web-API の利用規約

「法人番号システムWeb-API機能利用規約」(<https://www.houjin-bangou.nta.go.jp/webapi/riyokiyaku.html>、2026-10-03 に読んだ。最新の一部改正は令和 8 年 9 月 24 日施行)。

- 取得したデータの利用条件は、サイトの利用規約と同じ:

> 第７条 （コンテンツの利用条件等）
> コンテンツの利用条件等は、別に定める「国税庁法人番号公表サイト利用規約」 により取り扱います。

- 違いは API を使うこと自体の条件。全条項への同意、アプリケーション ID の届出と管理 (第三者への譲渡、貸与、開示の禁止)、短時間の大量アクセスの禁止、3 年使わない ID の停止など。
- サービスとして公開するときは、出典とは別に次の明示が要る:

> 第６条 （情報の取得元の明示）
> 利用者は、本機能を利用したサービスを提供する場合は、「このサービスは、国税庁法人番号システムWeb-API 機能を利用して取得した情報をもとに作成しているが、サービスの内容は国税庁によって保証されたものではない」を適宜の場所に明示するものとします。

- 全件・差分データのダウンロードには、このような同意や ID は要らない。

### e-Gov のメタデータとの突き合わせ

- e-Gov のリソースの `license_id` は `gjstu` (政府標準利用規約 第 2.0 版)。配布元のサイトは公共データ利用規約 (第 1.0 版) を掲げている。e-Gov のメタデータは 2023 年 (差分は 2018 年) から更新されておらず、規約の名前が古いままになっている。
- どちらも CC BY 4.0 と互換で、出典を書けば商用利用も再配布もできるという中身は同じ向き。利用条件として食い違う点は見つからなかった。公共データ利用規約の原文には、以前の政府標準利用規約に従って利用している場合はその条件が引き続き適用される、とある。
- 規約名は配布元に合わせて「公共データ利用規約（第1.0版）(PDL1.0)」と書くのが正しい。

## 版

- 全件データは毎月末時点で作り直され、サイトに置かれるのは最新の 1 版だけ。過去の月の全件データを取る手段はサイトに無い。Internet Archive など、ほかに過去の版が残っているかは確かめていない (未確認)。
- 差分データは過去 40 日分 (営業日)。それより前は取れない。
- 法人ごとの履歴は Web-API (法人番号を指定し、変更履歴も取る) で取れる。全法人の履歴をまとめて取る手段は無い。
