## 中身

### 文字コードと形式

入口のページの留意事項:

> CSVファイルの出力文字コードは、UTF-8-BOMです。

> データ内に改行コードが含まれている場合は、「（改行）」という文字列に置き換えています。

- 取得した 2 本は UTF-8 (BOM あり)、改行は CRLF だった。値の中に改行は無く、物理行数は件数 + 1 (見出し) と一致した。「（改行）」の文字列は病院 (施設票) に 845 か所、薬局に 9,496 か所あった。
- 列数はどの行も見出しと同じだった。

### 列

施設票の先頭の列は対象をまたいで共通。病院、診療所、歯科診療所、助産所 (定義書と、病院は実物で確かめた):

`ID`, `正式名称`, `正式名称（フリガナ）`, `略称`, `略称（フリガナ）`, `英語表記（ローマ字表記）`, `機関区分`, `都道府県コード`, `市区町村コード`, `所在地`, `所在地座標（緯度）`, `所在地座標（経度）`, `案内用ホームページアドレス`

続く列:

- 病院 (65 列): 曜日ごとと第 1〜5 週の曜日ごとの休診 (`毎週決まった曜日に休診（月）`、`決まった週に休診（定期週）第1週（月）` など)、`祝日に休診`、`その他の休診日（GW、お盆等）`、病床数 (`一般病床`、`療養病床`、`療養病床のうち医療保険適用`、`療養病床のうち介護保険適用`、`精神病床`、`結核病床`、`感染症病床`、`合計病床数`)。
- 診療所 (62 列): 病院と同じ休診の列と、`一般病床`、`療養病床` とその内訳、`合計病床数`。
- 歯科診療所 (57 列): 休診の列まで。病床の列は無い。
- 助産所 (153 列): 休業の列 (`0：休業/1：就業`)、曜日ごとの就業時間帯 1〜3 と外来受付時間帯 1〜3 の開始と終了 (`HH:MM`)。助産所は診療科・診療時間票が無く、時間も 1 本に入っている。

薬局 (128 列、実物で確かめた) は並びが違う:

`ID`, `名称`, `フリガナ`, `ローマ字`, `機関区分`, `都道府県コード`, `市区町村コード`, `所在地`, `所在地座標（緯度）`, `所在地座標（経度）`, `薬局のホームページアドレス`、続いて `営業日（月）` から `営業日（祝）`、定期閉店の列 (毎週と第 1〜5 週)、`その他の閉店日（GW、お盆等）`、曜日と祝日ごとの開店時間帯 1〜4 の開始と終了。

診療科・診療時間票 (病院、診療所、歯科診療所、36 列。定義書から):

`ID`, `診療科目コード`, `診療科目名`, `診療時間帯` (`1`〜`3`)、曜日と祝日ごとの `診療開始時間`、`診療終了時間`、`外来受付開始時間`、`外来受付終了時間` (`HH:MM`)。`ID` で施設票と結ぶ。1 行が施設、診療科、時間帯の組になると読めるが、件数は数えていない。

### 住所と座標

- 住所はある。`所在地` は都道府県名から始まる全体の表記 (`北海道札幌市中央区南１条西１６丁目２９１番地`)。取得した 2 本では空の行は無く、全行が都道府県名で始まった。数字は全角。
- `都道府県コード` は 2 桁、`市区町村コード` は 3 桁 (全国地方公共団体コードの 5 桁を 2 つに分けた形で、検査数字は無い)。薬局では `市区町村コード` が空の行が 2 行あった。
- 緯度経度の列がある。小数 6 桁が多い (病院 7,715 行のうち 6,736 行)。
- 座標が `0.0`、`0.0` の行がある。病院 (施設票) で 268 行、薬局で 7,303 行 (11.9%)。札幌市中央区の病院などにもあり、地域が偏っているかは数えていない。`0.0` 以外の値はすべて北緯 20〜46 度、東経 122〜154 度の範囲に入った。
- 座標の測地系は定義書にもページにも書かれていない (未確認)。

### ID

- `ID` は文字列で、桁数がそろわない。病院 (施設票) では 13 桁が 6,561 行、12 桁 432、10 桁 224、8 桁 214、9 桁 135 など。`471f0004` のように英字を含むものもある。数値として読むと先頭のゼロが落ちる。
- 取得した 2 本では `ID` は表の中で一意だった。

### 個人名

- 開設者、管理者、医師、薬剤師の氏名の列は無い (定義書の全シートと、実物 2 本で確かめた)。
- 施設の名称に個人の姓が使われることはありうる (`やまざき薬局` のような名称がある)。それが開設者の氏名かどうかは、このデータからは分からない。

### 件数

- 病院 (施設票) 7,715 件。47 都道府県すべてにあり、多い順に東京都 605、大阪府 480、北海道 475。
- 薬局 61,398 件。多い順に東京都 6,755、大阪府 4,307、神奈川県 4,186。
- 医療情報ネットに報告された施設の全数か、「データの一部」として絞られているのかは、ページに書かれていない (未確認)。

## 取り出し方

区分は split。時点ごとに、対象 (病院、診療所、歯科診療所、助産所、薬局) と票の種類で 8 本に分かれている。各 ZIP の中は whole。

- 厚生労働省のファイルは `curl -r 0-1023` に 206 を返した (`05_pharmacy_20260601.csv.zip` で確かめた)。Range で ZIP の目録は読めるが、中身は CSV 1 本なので行の部分集合は選べない。
- 都道府県ごとには分かれていない。最小は助産所 (ZIP 225,000 bytes)、最大は診療所 (施設票) の ZIP 6,856,873 bytes。展開後は診療所 (診療科・診療時間票) が 128,912,478 bytes で最大。
- e-Gov の ZIP は 8 種類をまとめた 1 本 (約 24〜28MB) で、e-Gov 側も Range で 206 を返した。
- 機械可読の目録は e-Gov の CKAN だが、2026-06-01 時点が載っていない。最新まで追うには入口の HTML を読む。
