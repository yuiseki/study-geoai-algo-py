# 国土数値情報 鉄道データ (N02)

2026-10-04 に読んで確かめた内容。ページは curl で取得して読んだ。大きさと Last-Modified は、ページに並ぶ全国のファイル 19 本の応答ヘッダ (16 本は HEAD、2023〜2025 年度の 3 本は GET)。中身は、取得した 17 本の ZIP の中のメタデータ XML と DBF のヘッダで確かめ、地物数と属性の値は 2025 年度版の GeoJSON (UTF-8) を数えた。2005 年度と 2012 年度は丸ごとは取得せず、HTTP Range で ZIP の中央ディレクトリとメタデータ XML だけを読んだ。

- 入口: <https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2025.html> (国土数値情報のデータ一覧 <https://nlftp.mlit.go.jp/ksj/index.html> の「鉄道」がここを指す)
- 作成: 国土交通省。サイトの著作権表示は国土政策局 国土情報課 (National Land Information Division)。
- 中身: 全国の旅客鉄道と軌道の路線 (鉄道区間) と駅。形状は線。駅も点ではなく、路線の一部分の線として持つ。属性は鉄道区分、事業者種別、路線名、運営会社、駅名、駅コード、グループコード。
- 版は 2005 年度から 2025 年度まで 19 年度分 (2009 年度と 2010 年度は無い)。どの年度も全国 1 本の ZIP で、都道府県別の分割は無い。
- 毎年更新されている。更新履歴は「2026年4月：2025年度（令和7年度）版に更新」「2025年6月：2024年度（令和6年度）版に更新」「2024年6月：2023年度（令和5年度）版に更新」「2023年5月：2022年度（令和4年度）版に更新」「2022年7月：2021年度（令和3年度）版に更新」「2021年7月：2020年度（令和2年度）版に更新」。

- 層は `RailroadSection` (鉄道区間) と `Station` (駅) の 2 つ。ファイル名は `N02-YY_RailroadSection.*`、`N02-YY_Station.*` (2005〜2008 年度は `N02-YY-g_*`)。
- ZIP の中のフォルダの切り方が年度で違う。ZIP の直下に置くもの (2016、2018、2019 年度など)、`N02-YY_GML/` や `N02-YY/` の下に置くもの、`Shift-JIS/` と `UTF-8/` に分けるものがある。パスは決め打ちせず、ZIP の一覧から探す。
- 2005 年度の ZIP には `N02-05/` と `N02-05_v1.0/` の 2 組が入っている。メタデータの来歴に「平成23年度に，JPGIS1.0フォーマットからGML形式への変換作業を実施した」とある。
- 2013 年度の ZIP にはメタデータ XML (`KS-META-*.xml`) が無い。
- 2025 年度の UTF-8 の DBF には `.cpg` が無く、DBF ヘッダの言語ドライバ ID は 0。Shift-JIS の DBF は 0x13。読むときは文字コードを指定する。

## 取り出し方

区分は whole。年度ごとに全国 1 本の ZIP で、地域の分割は無い。

- 2005 年度と 2012 年度の ZIP に `Range` を送ると 206 が返り、末尾の中央ディレクトリと個別のメンバー (メタデータ XML) を抜き出せた。ただしシェープファイルも GeoJSON も索引を持たないので、地物の部分集合は選べない。
- 最大の 2005 年度でも 18.8MB で、実際には丸ごと取る。
- 目録は HTML のページだけ。ファイルの URL はページの `DownLd('16.7MB','N02-22_GML.zip','../data/N02/N02-22/N02-22_GML.zip' ,this)` という JavaScript の呼び出しに書かれている。2013 年度だけファイル名に `_GML` が付かない。
- 年度ごとのページの 2025 年度版には「一括DL」の欄がある。

- 鉄道データの表示は「オープンデータ」で、「一部制限」は付いていない。1.3 の例外に当たらないので、利用規約本体の PDL1.0 が掛かる。2023〜2025 年度のページは「オープンデータ（CC_BY_4.0）」と書いている。
