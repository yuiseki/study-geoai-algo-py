## きっかけの二次配布

<https://ranger-k.eco.coocan.jp/Npark/map_ver02/history_log/data.html> (国立公園ウェブマップ、個人の運営) の説明: 表示しているデータは、環境省生物多様性センターが提供する自然環境情報GIS「国立公園(全国)のデータ(shape形式)」のファイル形式を変更したもの (複製頒布承認 平成26年6月6日環生多発第1406061号)。区域や計画の変更の告示があってから環境省が新しいデータを公開するまでは、審議会資料の地図画像から暫定的に作ったデータを表示している。環境省の閲覧上の留意点として、データは指定区域の概要を示すために作ったもので誤差を含み、規制対象の行為をするときの区域の確認は管轄の地方環境事務所に必ず照会すること。「本ページで表示されているデータをさらに複製頒布することを禁じます」とある。二次配布で、再配布を禁じ、環境省の複製頒布承認を得て成り立っているので、ここからは集めない。

## 近いが別のもの
