# 総務省統計局 国勢調査 人口等基本集計 (e-Stat)

2026-10-04 に読んで確かめた内容。表の数、セル数、公開日は e-Stat の統計データ API 3.0 (`getStatsList`、`getMetaInfo`、`getStatsData`) の応答を数えた値。ファイルの数と公開日は e-Stat のファイル一覧の画面を headless の Chromium で描画して数え、2025 年の Excel 212 本の大きさは HEAD の `Content-Length` を足した。実データは `getStatsData` で小さい表を 8 本 (うち 5 本は全国、または全国と東京都だけに絞った) と、2020 年の小地域集計の東京都の CSV 1 本、統計 GIS の小地域の統計データ (東京都) 1 本を取得して読んだ。集計の体系、公表の予定、不詳補完値の説明は統計局のサイトのページと PDF (結果の概要、ユーザーズガイド) を読んだ。

- 入口 (統計局): <https://www.stat.go.jp/data/kokusei/2025/kekka.html> (ページ名「令和7年国勢調査 調査の結果」)
- 入口 (e-Stat): <https://www.e-stat.go.jp/stat-search?page=1&toukei=00200521> (政府統計コード 00200521)
- 作成: 総務省統計局 (統計調査部 国勢統計課)。配布は e-Stat (運用管理は独立行政法人統計センター)。
- 中身: 全数の調査票による人口、世帯、住居の確定値。男女、年齢、配偶関係、国籍 (日本人・外国人の別)、世帯の種類と家族類型、住宅の所有の関係と建て方、高齢者世帯、母子・父子世帯、親子の同居など。
- 地域は全国、都道府県、市区町村 (政令指定都市の区と 2000 年の市区町村を含む)、人口集中地区。町丁・字等とメッシュは別の集計 (小地域集計、地域メッシュ統計) で配られる。
- 人口移動 (5 年前の常住地) の表はここでは扱わない。
- 2025 年 (令和 7 年) 調査の人口等基本集計は 2026-09-29 に公表済み。

e-Stat の API の使い方と利用規約は [estat/README.md](../estat/README.md)、小地域の境界は [estat-boundary/README.md](../estat-boundary/README.md) にある。

## 集計の体系の中の位置

令和 7 年国勢調査の集計体系 (統計局「令和７年国勢調査の集計体系及び結果の公表・提供等一覧」<https://www.stat.go.jp/data/kokusei/2025/pdf/schedule.pdf>、結果の概要の 55 ページにも同じ表) は次のとおり。人口等基本集計は基本集計の最初の区分で、全数の調査票を使う。

| 区分 | 集計 | 集計対象 | 全国結果の公表 (2025 年調査) | 前回 (2020 年調査) の実績 |
|---|---|---|---|---|
| 速報集計 | 人口速報集計 (要計表による人口集計) | 全数 | 2026-05-29 (実績) | 2021-06-25 |
| 基本集計 | 人口等基本集計 | 全数 | 2026-09-29 (実績) | 2021-11-30 |
| 基本集計 | 就業状態等基本集計 | 全数 | 2027 年 3 月まで | 2022-05-27 |
| 抽出詳細集計 | 抽出詳細集計 | 抽出 | 2027 年 11 月まで | 2022-12-27 |
| 従業地・通学地集計 | 従業地・通学地による人口・就業状態等集計 | 全数 | 2027 年 5 月まで | 2022-07-22 |
| 人口移動集計 | 移動人口の男女・年齢等集計 | 全数 | 2026 年 12 月まで | 2022-02-28 |
| 人口移動集計 | 移動人口の就業状態等集計 | 全数 | 2027 年 6 月まで | 2022-08-31 |
| 小地域集計 | 上の各集計に関する集計 (4 区分) | 全数 | 該当する基本集計等の公表後に順次 | 2022-02-10 から 2022-08-31 |

- 人口等基本集計の説明 (結果の概要の冒頭): 「人口等基本集計は、全ての調査票を用いて市区町村別の人口、世帯、住居に関する結果及び外国人、高齢者世帯等に関する結果について集計した確定値である。」
- 表章地域は、人口等基本集計が「全国、都道府県、市区町村」、小地域集計が「町丁・字等、基本単位区、地域メッシュ」。小地域集計は「地理データ等を活用して秘匿処理を施した上で」公表する、と集計体系の表にある。
- 2025 年の公表の告示は総務省告示第 358 号 (2026-09-30)。公表は 2026-09-29 14:00 (統計局の公表予定 XML <https://www.stat.go.jp/data/kouhyou/e-stat_kokusei2025.xml>)。人口速報集計は総務省告示第 208 号、2026-05-29 8:30。
- 2025 年の全国の人口は 122,972,528 (男 59,772,092、女 63,200,436)。人口速報集計では 123,049,524 だった (API の `0004050397` と `0004065881` の全国の値)。
- 2026-10-04 の時点で、2025 年の小地域集計、地域メッシュ統計、人口集中地区境界図はまだ出ていない。人口集中地区境界図は「令和9年3月の公表を予定」と調査の結果のページにある。統計 GIS の目録 (`search_detail`、`type=1`) の調査年も 2020 年が最新だった。

#### 地域コード

`getMetaInfo` で 2025 年の `0004065881` (男女別人口－全国、都道府県、市区町村（2000年市区町村含む）) を読んだ。

- `area` は 4,082 項目。コードは 5 文字で、全国は `00000`、都道府県は `01000` のように末尾 3 桁が 0、市区町村は全国地方公共団体コードの検査数字を除いた 5 桁 (`01101` 札幌市中央区)。
- `@level` は 1 (全国 1)、2 (都道府県 47)、4 (市 792、東京都の特別区 23、特別区部 1 の計 816)、5 (政令指定都市の区 171)、6 (町 743、村 183 の計 926)、7 (2000 年の市区町村 2,121)。特別区 (`13101` 千代田区) の親は特別区部 (`13100`)、政令指定都市の区の親は市 (`01100` 札幌市)。
- 2000 年の市区町村には英字の入ったコードがある (`0120B`「（旧：函館市）」、`0120C`、`0121B` など)。数字だけを想定すると壊れる。親は `@parentCode` で都道府県 (`01000`) を指している。
- 統計表には「地域識別コード」(a: 全国・都道府県、0: 東京都23区及び政令指定都市の区、1: 東京都特別区部及び政令指定都市、2: 政令指定都市以外の市、3: 町村、9: 2000年(平成12年)現在の市区町村) を付けたものがある (ユーザーズガイド `ug_02.pdf`)。

## 原数値と不詳補完値

### 不詳とは

ユーザーズガイド (`ug_02.pdf` の「３ 利用上の注意」) から。

> 集計結果には、調査票に未記入や誤記入がある場合や、調査票に記入された内容の分類が不可能である場合、「不詳」として取り扱うものが存在します。令和７年国勢調査では、不詳を原則として分類事項の最後に表章しています。

> また、年齢別割合、労働力率などの割合・比率を算出する際は、分母となる総数から不詳の数を除いて算出しています。

### 補完の経緯と方法

結果の概要 (`outline_01.pdf`) の参考「令和７年国勢調査に関する不詳補完値について」(54 ページ) から。

> 国勢調査の集計に当たり、結果利用者の利便性向上を図るため、令和２年国勢調査の集計においては、主な項目※１の集計結果（原数値）に含まれる「不詳」をあん分等によって補完した「不詳補完値」を算出し、これを表章した統計表を参考表として公表した。その際、平成 27 年国勢調査についても、同様の方法で遡及集計した結果（平成 27 年国勢調査に係るあん分等による不詳補完値）を併せて提供し、令和２年国勢調査との時系列比較等に利用した。

> 令和７年国勢調査の確報集計においては、原数値に加え、参考表として、主要国で使用されている CANCEIS※２による不詳補完値を全集計区分※３で公表するとともに、令和２年国勢調査結果のうち、主要な集計区分※４についても、CANCEIS による不詳補完値を算出し、遡及集計結果として公表した。なお、CANCEIS による不詳補完値については、不詳が一部残る場合がある。

- 補完の対象 (※1): 人口等基本集計では年齢、国籍 (日本人・外国人の別)、配偶関係。
- CANCEIS (※2) は「カナダ統計局が開発したソフトウェアであり、カナダ、イギリス、ドイツ等の人口センサスで使用されている」。
- ※3 は人口等基本集計から小地域集計までの全区分。※4 (2020 年の遡及) は人口等基本集計、就業状態等基本集計、従業地・通学地集計、移動人口の男女・年齢等集計。
- 回ごとの補完値の有無 (同ページの表):

| | 2025 | 2020 | 2015 |
|---|---|---|---|
| CANCEIS による不詳補完値 | あり | あり (遡及、2026-09-29) | なし |
| あん分等による不詳補完値 | なし | あり (参考表：不詳補完結果) | あり (遡及) |

- 結果の概要の本文と図表は「2015 年以降は不詳補完値による」と注記し、増減は「同一の補完方法による不詳補完値又は原数値同士の比較により算出している」。

e-Stat 上の名前は紛らわしい。「参考表：不詳補完結果」があん分等による値 (2020 年と 2015 年の遡及)、「参考表：不詳補完値 ※原数値の不詳を補完した結果」が CANCEIS による値 (2025 年と 2020 年の遡及)。

### どちらを使うか

- 統計局は原数値を「集計結果」、不詳補完値を「参考表」として出している。公式の確定値は原数値。
- 年齢や国籍の構成を比べる用途 (人口ピラミッド、年齢構成比、地域間の比較、2020 年との比較) では、不詳が地域によって偏る (東京都 4.3%、全国 2.7%) ので、原数値をそのまま使うと都市部の若い層が少なく出る。統計局自身が結果の概要で 2015 年以降の年齢構成に不詳補完値を使っている。
- 原数値で割合を出すときは、統計局と同じく分母から不詳を除く。
- 置くなら両方を置き、版の名前 (原数値、CANCEIS 補完、あん分等補完) を列か設定名で区別するのがよい。セル数は同じで、補完値の側は原数値の 2 倍にはならない (同じ大きさがもう 1 組)。

## 過去の回の扱い

### 2010 年と 2015 年の表が少ない理由

API で数えると 2010 年は 65 表、2015 年は 61 表で、2020 年の 225 表より少ない。消えたのではなく、表の切り方が違う。

- 2010 年と 2015 年の表は `COLLECT_AREA` が「該当なし」で、1 表が全国、都道府県、市区町村をまとめて持つ (題名「全国，市部・郡部，都道府県，市部・郡部，支庁，郡計，市区町村・旧市町村，全域・人口集中地区」など)。1 表あたりのセル数は 2010 年が平均約 214 万、2020 年が平均約 74 万。セル数の合計では 2010 年 139,316,422、2015 年 110,878,238、2020 年 165,995,274 で、桁は同じ。
- ファイルの側は都道府県ごとに分かれている。2015 年の人口等基本集計のファイルは 3,129 本 (全国結果 71、都道府県結果 3,055 で 1 都道府県 65 本)。DB の 1 表がファイルでは都道府県ごとの多数のファイルになる。
- 2015 年は母子・父子世帯と親子の同居が世帯構造等基本集計 (56 表) に、2010 年は親子の同居などが職業等基本集計 (39 表) に分かれていた。
- 2005 年以前は名前が「第1次基本集計」で、`searchWord=人口等基本集計` では引っかからない。

### 速報値と確定値

- 速報値は確定値で置き換えられず、別の表として残る。2025 年の人口速報集計 (`0004050397`、2026-05-29) と人口等基本集計 (`0004065881`、2026-09-29) は両方とも API にあり、全国の人口は 123,049,524 と 122,972,528。2020 年の人口速報集計 (2 表) も残っている。
- 2015 年の調査の結果のページは「確定数は，全調査票の記入内容に基づいた審査を経て集計・公表するため，速報値とは必ずしも一致しません。」と書く。

## 取り出し方

区分は catalog。`getStatsList` で表の目録が取れ、`getStatsData` で表ごと (地域や分類で絞って) 取れる。ファイルの側は表ごとの Excel (whole)。

### API

- `getStatsData` は 1 回に 100,000 件まで (API 仕様「省略時は10万件」)。超える分は `NEXT_KEY` を `startPosition` に渡して続ける。
- `cdArea=00000,13000` のように地域で絞れる。2025 年の 384 セルの表 (全国と東京都) は 1 回で返った。
- JSON の大きさは 1 セルあたり約 130 bytes (`0004065881` の 12,246 セルで 1,590,773 bytes)。
- 値は文字列。秘匿や該当なしの記号は `DATA_INF.NOTE` に定義がある (`***` と `-` がどちらも「当該数値がないもの」)。地域で絞らずに取った 3 表 (`0004065881`、`0004066121`、`0004050397`) には、数字でない値は無かった。

全表を取るときの見積もり。表ごとに `ceil(セル数 / 100,000)` を足した。

| 対象 | 表 | セル数 | getStatsData の回数 | JSON の大きさ (130 bytes/セルで換算) |
|---|---:|---:|---:|---:|
| 2025 原数値 | 222 | 176,804,043 | 1,904 | 約 23GB |
| 2025 不詳補完値 | 222 | 176,804,043 | 1,904 | 約 23GB |
| 2020 原数値 | 225 | 165,995,274 | 1,803 | 約 22GB |
| 2020 不詳補完値 (CANCEIS 遡及) | 225 | 165,995,274 | 1,803 | 約 22GB |
| 2020 不詳補完結果 (あん分等、人口等基本集計に対応) | 26 | 7,005,588 | 88 | 約 0.9GB |
| 2015 不詳補完結果 (あん分等の遡及、同上) | 26 | 7,011,888 | 88 | 約 0.9GB |
| 2015 原数値 | 61 | 110,878,238 | 1,143 | 約 14GB |
| 2010 原数値 | 65 | 139,316,422 | 1,426 | 約 18GB |
| 合計 | 1,072 | 949,810,770 | 10,159 | 約 123GB |

- 1 秒に 1 回なら 10,159 回で約 2 時間 50 分。API 利用規約 第 8 条は「短時間における大量のアクセスその他本機能の運用に支障を与える行為」を禁じている。
- セル数には「（再掲）」の分類や、構成比、平均年齢などの比率の表も含まれる。Parquet にしたときの大きさは測っていない。

### ファイル

- 2025 年の原数値の Excel 212 本の大きさの合計は 1,236,564,157 bytes (HEAD の `Content-Length`)。最大は `b14_02-01.xlsx` の 38,771,502 bytes、最小は `b54_01.xlsx` の 22,700 bytes。大きい表は複数の Excel に分割されている (`b14_02-01`、`b14_02-02`、`b14_02-03`)。
- ダウンロードは `https://www.e-stat.go.jp/stat-search/file-download?statInfId=<ID>&fileKind=0` (Excel)。小地域集計の CSV は `fileKind=1`。HEAD に `Content-Length` と `Content-Disposition` (ファイル名) が返る。
- ファイルの一覧の項目数 (212) と API の表の数 (222) は合わない。DB のボタンが指す ID は 189 あり、うち異なるものが 168 だった。ファイルと DB の表の対応は 1 対 1 ではない (対応の全体は未確認)。
- 2020 年には「分割版（容量の大きな一部のファイルについて都道府県別に分割して再掲）」という提供分類が別にあり、4,559 本。どの集計区分のファイルが何本入っているかは数えていない。

### 境界データとの結合

- 市区町村: API の `area` の 5 桁コード、境界の `PREF` + `CITY`。ABR の `lg_code` の先頭 5 桁とも一致する ([estat-boundary/README.md](../estat-boundary/README.md))。2000 年の市区町村の英字入りコード (`0120B`) は境界側に無い。
- 小地域: 小地域集計の CSV の `市区町村コード` + `町丁字コード` (4 桁または 6 桁)、または統計 GIS の統計データの `KEY_CODE` (5、9、11 桁)。境界データ (`A002005212020`) の `KEY_CODE` と同じ作り。境界の側は `KEY_CODE` が 1 行 1 キーではなく、桁数もそろっていない ([estat-boundary/README.md](../estat-boundary/README.md) の「KEY_CODE は 1 行 1 キーではない」)。
- 統計表の小地域の値には、秘匿 (`X`) と合算 (`秘匿先情報`、`合算地域`) がある。合算された地域の値は合算先の行に足し込まれているので、境界に塗るときは合算先の情報で境界を寄せるか、秘匿地域を欠測として扱う。
- 人口集中地区: 表の地域は「市区町村（人口集中地区）」。人口集中地区の境界は統計 GIS の境界データ (国勢調査 2020 年の人口集中地区) にある。2025 年の境界は 2027 年 3 月の予定。
- メッシュ: 統計 GIS の統計データ (1km から 125m) は地域メッシュコードで持つ。人口等基本集計の表とは別物で、メッシュの境界は計算で作れる。

<https://www.e-stat.go.jp/api/terms-of-use> (2026-10-04 に読んだ)。

> 第６条（コンテンツの利用） 本機能が提供する情報（以下「コンテンツ」という。）の利用条件等は、「政府統計の総合窓口（e-Stat）利用規約」に準じるものとします。

- 第 7 条で、API を使ったサービスを提供するときはクレジット表示が要る。表示の文 (<https://www.e-stat.go.jp/api/api-info/credit>):

> 「このサービスは、政府統計総合窓口(e-Stat)のAPI機能を使用していますが、サービスの内容は国によって保証されたものではありません。」

- API で取ったデータを Hugging Face に置くのが「サービスの提供」に当たるかは規約に書かれていない。クレジットの文をデータセットの説明に添えておけば、どちらに読んでも満たす。
- 第 8 条は短時間の大量アクセスを禁じる。
