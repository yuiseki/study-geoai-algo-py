2026-10-03 に読んで確かめた内容。e-Gov データポータルの CKAN API (`package_search`) でデータセットを集め、配布元のページは curl で取得して読んだ。大きさと Last-Modified は全ファイルへの HEAD の値。中身は青森県下北郡東通村の震災後植生図 (Shapefile の ZIP 6,528 bytes と KMZ 1,727 bytes) の 2 本だけを取得して見た。ほかの ZIP は Range 要求で中央ディレクトリと小さな DBF だけを読み、本体は落としていない。

## 中身

### 東通村の震災後植生図 (取得して確かめた)

- ZIP の中は `.shp`, `.shx`, `.dbf`, `.prj`, `.sbn`, `.sbx`, `.shp.xml` の 7 本。`.cpg` は無い。
- ZIP 内のファイル名は cp932 で、UTF-8 のフラグが立っていない。そのまま展開すると文字化けする。cp437 として読んだ名前を cp932 で読み直すと `02_下北郡東通村_震災後植生図.shp` になる。
- DBF は cp932 で読めた。列は `都道府県`, `市区町村`, `行政コード`, `沿岸区番号`, `沿岸区名称`, `被災状況`, `写真撮影日`, `震災後区分`, `震災後番号`, `震災後凡例`, `現地調査日`, `現地未到達`, `改変図番号`, `改変図凡例`, `Area`, `Hectares`。1 行目は `青森県`, `下北郡東通村`, `2424`, ..., `2011/04/05`, `自然裸地`, ..., `2012/09/08～2012/09/12`, ..., `変化なし`。行政コードは数値型で、先頭のゼロが落ちている。
- 東通村のこのファイルはポリゴン 1 個だけ。
- `.prj` は `JGD_2000_Japan_Zone_10` (平面直角座標系 X 系、JGD2000)。
- `.shp.xml` の `CreaDate` は 2013-11-07、`ModDate` は 2013-04-18。ZIP 内のタイムスタンプも 2013-11-07。
- KMZ の中は `doc.kml` 1 本。座標は経度緯度 (`141.3958341310108,41.1324003993858,0`)。属性は `description` の HTML の表に入っている。

## 取り出し方

区分は split。平成 24 年度は市町村 (63) と県 (6) ごとに、平成 25、26 年度は調査の主題ごとに、ファイルが分かれている。各ファイルは whole に近い。

- `curl -r 0-1023` は 206 を返した (`after_veg_02_424.zip` と `h26-1veg_kaihen_shape.zip` で確かめた)。ZIP の中央ディレクトリを Range で読めば、落とさずに中のファイル名と大きさを一覧でき、小さな DBF だけを取り出すこともできた。Shapefile 自体には空間索引の読み方が無いので、範囲で絞る使い方はできない。
- 目録は年度別の HTML ページと e-Gov の CKAN。CKAN の API で URL は一括で取れるが、bbox や日時で絞る仕組みは無い。市町村別のデータセットはタイトル (`..._<県>_<市町村>`) で選べる。
