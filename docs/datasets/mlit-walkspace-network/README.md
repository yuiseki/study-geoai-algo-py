# 国土交通省 歩行空間ネットワークデータ

2026-10-03 に読んで確かめた内容。ページとカタログは curl と CKAN API で読んだ。大きさは HEAD の Content-Length か CKAN の `size`。行数は東京駅周辺の CSV 2 本 (`tokyoeki_node1.csv` と `tokyoeki_link1.csv`) を取って数えた値。

歩行空間ネットワークデータは、歩道や通路を「リンク」(線) と「ノード」(点) で表し、リンクに段差、幅員、勾配、階段、エレベーターなどのバリアの情報を付けたもの。作っているのは国土交通省 政策統括官付で、地区ごとに整備して公開している。全国を覆うデータではない。

国土交通省自身が運営する配布元が 2 つある。

- 歩行者移動支援サービスに関するデータサイト (www.hokoukukan.go.jp)。2015 年開設。整備仕様 2018 年 3 月版までのデータ。
- 歩行空間ナビゲーションデータプラットフォーム オープンデータサイト (ckan.hokonavi.go.jp)。2025-09-30 開設。整備仕様 2024 年 7 月版に変換したデータ。

ほかに、e-Gov データポータルの目録と、G空間情報センターにも国土交通省 (政策統括官) の名前で載っている。この 2 つについては下の「目録と写し」に書く。

## 歩行者移動支援サービスに関するデータサイト (hokoukukan)

- 入口: <https://www.hokoukukan.go.jp/top.html>。データの一覧は <https://www.hokoukukan.go.jp/metadata/find>
- 運営と問い合わせ先: 国土交通省 政策統括官付 (各ページのフッター)。利用規約の第１条に「国土交通省が所有する歩行者移動支援サービスに関するデータをインターネット上で提供するために設置されたサイト」とある。
- curl の既定の User-Agent では、どのページも 403 になる (Web サーバーのテストページが返る)。ブラウザの User-Agent を付けると読める。
- 2025-09-30 の報道発表 (<https://www.mlit.go.jp/report/press/sogo23_hh_000182.html>) に「2018年３月版のデータ整備仕様以前の「歩行空間ネットワークデータ」や（中略）「施設データ」は、当面の間、「歩行者移動支援サービスに関するデータサイト」よりダウンロードをお願いいたします。」とある。

### 配布ファイル

- 地区ごとのページ `/metadata/detail/<番号>` に、リソース (`/metadata/resource/<番号>`) が並ぶ。ファイルは `/uploads/<地区番号>/<リソース番号>/<ファイル名>` に直接置かれている。
- 2018 年 3 月版の地区は、だいたい「CSV (link と node)」「Shapefile (link と node)」「整備範囲の PDF」の 3 リソースと、データ説明書 (XLSX)。
- それより前の地区は形がばらばら。CSV と GML と XSD の組 (品川区など)、XLS だけ (福島、下田)、Shapefile と CSV (新横浜など)。歩行空間ネットワークのほかに、施設データ (公共施設、公共用トイレ、指定避難所、病院)、出入口情報、場所情報コード、描画地図 (PDF) を同じページに含むものがある。
- 51 地区のページから拾えたファイルは重複を除いて 708 本。HEAD で 200 が返ったのは 569 本、合計 334,644,577 bytes。いちばん大きいのは千代田区の `リンクの情報.GML` (61,485,080 bytes)。2018 年 3 月版の地区は 1 地区あたり 0.5MB から 5MB 程度。
- `.dbf` (78 本) と `.xsd` (54 本) は、直接の GET が 403 になる。ページの「選択したファイルを一括ダウンロード」(POST) で作られる zip には入っていた (東京駅周辺の `tokyoeki_link1.dbf` 1,207,582 bytes と `tokyoeki_node1.dbf` 1,756,392 bytes で確かめた)。この 132 本の大きさは測っていない。
- ほかに CSV 5 本が 403、2 本 (大東市の `Link.csv` と `Node.csv`) が 404 だった。

## 歩行空間ナビゲーションデータプラットフォーム オープンデータサイト (hokonavi)

- 入口: <https://www.hokonavi.go.jp/opendata/>。カタログは CKAN で <https://ckan.hokonavi.go.jp/dataset/>
- 利用規約に「国土交通省が運営するウェブサイトです」とある。CKAN の組織はすべて「国土交通省」。
- 2026-10-03 時点で 43 データセット、191 リソース。
  - `nwd_*` が 28 件。歩行空間ネットワークデータで、各 4 リソース (link と node の CSV、link と node の GeoJSON)。27 件は hokoukukan の 2018 年 3 月版の地区と同じ名前で、説明に hokoukukan 側の更新日 (例: 東京駅周辺は「最終更新日: 2019/01/23」) が書いてある。新しい地区は赤羽駅周辺 (最終更新日 2026/03/19) だけ。
  - `station_oedo_*` と `mlit_station_oedo_*` が 12 件。都営大江戸線の駅構内の歩行空間ネットワークと構内地図 (国土地理院の階層別屋内地理空間情報データ仕様)。説明に「公共交通オープンデータチャレンジ2026 の期間中（2027年3月12日まで）のみの限定公開です。」とある。
  - `facility_*` が 3 件。バリアフリー施設等データ (池田市、豊中市、東京都の車椅子使用者対応トイレ)。
- 報道発表には、2024 年度に改定した整備仕様に基づき「幅員・縦断勾配・段差に関する情報をランク区分に変換したデータ」とある。東京駅周辺の link.csv は、hokoukukan の 15 列に対して 55 列あり、`rank`、`r_method`、`maint_date`、`levDif_max`、`stair`、`handrail` などが増えている。最初のリンクでは `vtcl_slope` と `lev_diff` の値が hokoukukan 版 (1) と違う (2)。コードの定義が版で違うので、2 つの版を混ぜて使うときは仕様書で読み替える必要がある。
- `nwd_*` 28 件の大きさは CKAN の `size` の合計で 79,172,723 bytes。最大は渋谷駅・千駄ヶ谷駅・新宿駅周辺の 12,023,514 bytes (CSV だけなら 2,358,251)、最小は新国立競技場周辺の 705,061 bytes。

## 中身

東京駅周辺 (hokoukukan、2018 年 3 月版、2019-01-23 更新) の CSV で確かめた。

- 文字コードは UTF-8 で、データは ASCII だけだった。
- ノード (`tokyoeki_node1.csv`、622,561 bytes): 4,161 行。列は `node_id,lat,lon,floor,in_out,link1_id`〜`link8_id`。`node_id` はすべて一意。緯度は 35.6677 から 35.6962、経度は 139.7437 から 139.7748。`floor` は 0.0 が 4,058、1.0 が 91、0.5 が 12。`in_out` (1: 施設外、2: 境界、3: 施設内) は 3,347 / 271 / 543。
- リンク (`tokyoeki_link1.csv`、626,886 bytes): 4,947 行。列は `link_id,start_id,end_id,distance,rt_struct,route_type,direction,width,vtcl_slope,lev_diff,tfc_signal,tfc_s_type,brail_tile,elevator,roof`。リンクの CSV に座標は無く、端点のノードを通して位置が決まる (Shapefile と GeoJSON は線を持つ)。`distance` の合計は 113,277.5 m。`route_type` は 1 (対応する属性情報なし) が 4,809、6 (階段) が 82、7 (スロープ) が 21、99 (不明) が 35。
- 列の意味とコードは 2018 年 3 月版の仕様の表 3.2 (リンク、31 項目、第 1 層は 15 項目) と表 3.6 (ノード) にある。CSV の 15 列は第 1 層の項目と一致した。
- 座標はノードの緯度経度 (10 進の度、JGD2011)。住所の列は歩行空間ネットワークには無い。施設データ (一部の地区に同梱) は別の表で、中身は確かめていない。
- 更新頻度: e-Gov の目録は「不定期」。hokoukukan の最後の登録は 2022-05-10。hokonavi の `nwd_*` で最後に変わったのは赤羽駅周辺 (2026-03-19)。

## 取り出し方

区分は split。地区ごとに分かれていて、必要な地区のファイルだけ取れる。各ファイルの中は whole。

- hokoukukan のファイルは `curl -r 0-1023` に 206 を返した (`tokyoeki_node1.csv`)。hokonavi の CSV も 206 を返した (東京駅周辺の node.csv と link.csv)。ただし CSV と GeoJSON と GML には索引が無いので、範囲の部分集合は選べない。
- 目録: hokonavi は CKAN API (`package_search`) で一覧と大きさが取れる。hokoukukan は HTML のページだけで、ファイルの URL はリソースのページを開かないと分からない。`.dbf` と `.xsd` は POST の一括ダウンロードでしか取れなかった。
- いちばん小さい単位は 1 地区の CSV 2 本で、数十 KB から 2.4MB 程度。

## 過去の版

- 仕様の版をまたぐ 2 つの形が並んで取れる。2018 年 3 月版の形は hokoukukan に、2024 年 7 月版に変換した形は hokonavi にある (27 地区)。
- hokoukukan では、新横浜と渋谷のページに 2017 年の版と 2018 年 3 月版のリソースが並んでいる。新宿駅周辺のページには平成 30 年度整備と令和元年度整備の 2 組がある。それ以外の地区で、置き換えられる前のファイルを取る手段は見つからなかった。
- hokonavi の CKAN に版の履歴は無い。大江戸線の 12 件は 2027-03-12 までの限定公開。

## 目録と写し

- e-Gov データポータル (<https://data.e-gov.go.jp/data/api/3/action/package_show?id=mlit_20150223_0105>) は目録だけ。248 リソースの URL はすべて hokoukukan のページ (`/metadata/detail/` か `/metadata/resource/`) を指していて、ファイルそのものは置いていない。データセット全体の `license_id` は空で、リソース 248 件の `license_id` が `gjstu` (政府標準利用規約 第 2.0 版)。248 件のうち歩行空間ネットワークに当たるのは先頭の 76 件で、残る 172 件は施設のバリアフリー情報 (2021-07-05 登録)。`landingPage` は hokoukukan の `/download/download/nwdata_download.html`。`notes` は「平成27年度_国土交通白書」、`size` は 2015 年ごろの値のまま。
- G空間情報センター (<https://www.geospatial.jp/ckan/dataset/0401>) にも、組織「政策統括官」(国土交通省) で「歩行空間ネットワークデータ等」がある。73 リソースで、2018 年 3 月版より前の地区 (zip) と、2018 年 3 月版の一部 (東京駅、新宿駅、池袋駅、上野駅、大門駅、千駄ヶ谷駅、渋谷南部、皇居外苑周辺) の zip と GeoJSON、2018 年 3 月版と 2024 年 7 月版の仕様書。`license_id` は `ogl` (政府標準利用規約)、`公開ウェブページ` は hokoukukan。作成者は同じ国土交通省だが、置き場としては hokoukukan の写しに当たる。GeoJSON は S3 へのリダイレクトで、Range に 206 を返した (東京駅周辺の link.geojson、2,641,029 bytes)。川崎市などの「その他」の地区は入っていない。
