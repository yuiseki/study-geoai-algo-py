# 国土交通省 不動産情報ライブラリ (不動産取引価格情報・成約価格情報)

2026-10-04 に読んで確かめた内容。静的なページは curl で取得して読み、JavaScript で描画される画面 (検索・ダウンロード画面、制度と用語、トップのお知らせ) は headless Chromium で描画した DOM を読んだ。件数は、検索・ダウンロード画面が「現在の条件での検索結果」を出すために呼んでいる件数のエンドポイントに、画面と同じ条件を渡して数えた値。中身は、画面のダウンロードと同じ要求で鳥取県・2026 年第 1 四半期・すべての種類・両方の価格情報区分の CSV を 1 本だけ取得して見た。全国のファイルは落としていない。公開 API (`ex-api`) は API キーが無いので呼んでいない (キーなしで 401 を返すことだけ確かめた)。

- 入口: <https://www.reinfolib.mlit.go.jp/> (サイト名「不動産情報ライブラリ」)。価格情報の検索とダウンロードは <https://www.reinfolib.mlit.go.jp/realEstatePrices/>、項目の説明は <https://www.reinfolib.mlit.go.jp/realEstatePrices/about/> (画面上の名前は「制度と用語」)。
- 作成: 国土交通省。サイトの運用は 国土交通省 政策統括官付 地理空間情報課 (国土交通省のページ「不動産情報ライブラリとは」<https://www.mlit.go.jp/tochi_fudousan_kensetsugyo/tochi_fudousan_kensetsugyo_tk17_000001_00038.html> の問い合わせ先と、概要資料の作成者)。
- 中身: 不動産の取引 1 件 1 行。所在地は町・大字 (地区名) まで。緯度経度は無い。価格情報は 2 種類あり、出どころが違う。
  - 不動産取引価格情報: 国土交通省が取引当事者に送るアンケート調査の回答を加工したもの。2005 年第 3 四半期から。
  - 成約価格情報: 指定流通機構 (レインズ、REINS) が保有する成約価格を国土交通省が加工したもの。2021 年第 1 四半期から。
- 更新は四半期ごと。取引時期から約 4 か月後に 1 四半期分を足す。

## 作成と一次配布元

### 不動産情報ライブラリと旧「土地総合情報システム」

概要資料「不動産情報ライブラリの概要について」(<https://www.mlit.go.jp/tochi_fudousan_kensetsugyo/content/001745809.pdf>、資料更新日 2026 年 9 月 2 日) の記載:

> 不動産に関する多様なオープンデータを、利用者のニーズに応じて重ね合わせて地図上に表示する「不動産情報ライブラリ」を2024年4月1日に公開。

同じ資料の「構築ステップ」の図に、旧システムとの関係がある:

> 平成16年～令和6年3月まで運用
> 価格情報である地価公示・地価調査と
> 取引価格情報を別システムとして情報提供
> 土地総合情報システム/基準地・標準地検索システム

> 令和6年度 ３月 一部データ移管

> 価格情報に新たに成約価格情報を加え、
> 地形情報・防災情報・周辺施設情報・都市計画情報・
> 人口情報等も含めWebGISとしてサービス提供開始

- 旧「土地総合情報システム」(`https://www.land.mlit.go.jp/webland/`) は 2026-10-04 時点でホスト名が DNS で引けない。Internet Archive の CDX では、200 で残っている最後の取得が 2024-03-27、2024-04-06 以降は 503。旧システムの取引価格情報 API (`/webland/api/TradeListSearch`) も同じホストにあり、使えない。
- 不動産取引価格情報は旧システムから引き継がれ、期間の始まり (2005 年第 3 四半期) も同じ。成約価格情報は不動産情報ライブラリで新しく加わった。

### 不動産取引価格情報

利用規約の第 2 条 (4):

> 「不動産取引価格情報」とは、土地・建物の取引を対象としたアンケート調査の結果得られた回答について、個別の物件を特定できないよう加工した、国土交通省が保有し提供する不動産取引価格情報をいいます。

「制度と用語」の説明:

> 国土交通省が不動産の取引当事者を対象に不動産取引のアンケート調査を実施し、その結果得られた回答などについて物件が容易に特定できないよう加工した上で公表するものです。

> 不動産取引のアンケート調査は、土地及び区分所有物件の所有権移転登記情報をもとに実施しておりますが、次の取引は調査対象外としています。

- 調査対象外: 調査対象地域外の取引、面積が小さい取引 (宅地 30㎡ 又は 60㎡、山林・農地・その他 100㎡、区分所有 10㎡ 未満)、持分の一部の移転、異なる地目を一体とした取引、複数戸の一括取引、借地権等の区分所有、1 年以上前の取引など。区分所有物件は三大都市圏以外の人口 10 万人未満の都市等も対象外。
- 対象地域は段階的に広がった。2005 年第 3 四半期は東京都 23 区と一部の政令市を中心とする地域、2006 年第 2 四半期から全国の政令市、2007 年第 2 四半期から県庁所在市など地価公示対象地域等 (北海道は札幌市、旭川市、函館市のみ)、2008 年第 2 四半期から「ほぼ全国」。
- アンケートなので全数ではない。回答の無い取引は入らない。

### 成約価格情報

利用規約の第 2 条 (5):

> 「成約価格情報」とは、指定流通機構（レインズ）保有の不動産取引価格情報を、国土交通省が個別の不動産取引が特定できないよう加工し、消費者向け不動産取引情報サービスである、「レインズ・マーケット・インフォメーション」（RMI）にて公表している情報をいいます。

検索画面の説明 (価格情報区分の「?」):

> なお、マンション及び一戸建ての不動産取引価格（成約価格）については、統計情報としての正確性に配慮した絞り込みを行った上で、個別の不動産取引が特定できないように加工し提供しております。

「制度と用語」の留意事項:

> 当情報は国土交通省が、情報の入力状況を精査し異常値等を検知した際に、相場情報として適切でないことが考えられるため項目単位で提供対象外としている場合があります。

- 元のデータは、宅地建物取引業者が指定流通機構 (レインズ) に登録した成約情報。レインズ・マーケット・インフォメーション (<http://www.contract.reins.or.jp/>) は全国指定流通機構連絡協議会が運営し、東日本、中部圏、近畿圏、西日本の 4 つの指定流通機構が保有する取引情報を出している (RMI の「初めてご利用するかたへ」)。
- 種類は戸建て (「宅地(土地と建物)」と表示) と中古マンション等の 2 つだけ。土地のみ、農地、林地は無い。
- 不動産取引価格情報と同じ取引が両方に載ることがある (利用規約 第 5 条 (2) と検索画面の留意事項)。両者を足して件数を数えると重複する。

### 列 (ダウンロードの CSV)

30 列。見出しはそのまま次のとおり。不動産取引価格情報と成約価格情報は同じ列で 1 つのファイルに混ざり、`価格情報区分` で分かれる。

`種類`, `価格情報区分`, `地域`, `市区町村コード`, `都道府県名`, `市区町村名`, `地区名`, `最寄駅：名称`, `最寄駅：距離（分）`, `取引価格（総額）`, `坪単価`, `間取り`, `面積（㎡）`, `取引価格（㎡単価）`, `土地の形状`, `間口`, `延床面積（㎡）`, `建築年`, `建物の構造`, `用途`, `今後の利用目的`, `前面道路：方位`, `前面道路：種類`, `前面道路：幅員（ｍ）`, `都市計画`, `建ぺい率（％）`, `容積率（％）`, `取引時期`, `改装`, `取引の事情等`

- `種類` は `宅地(土地)`、`宅地(土地と建物)`、`中古マンション等`、`農地`、`林地`。鳥取県 2026 年第 1 四半期では 不動産取引価格情報 223 行 (宅地(土地) 82、宅地(土地と建物) 75、農地 44、林地 21、中古マンション等 1)、成約価格情報 37 行 (宅地(土地と建物) 26、中古マンション等 11)。
- `取引価格（総額）` は円の整数 (`14000000`)。`取引時期` は `2026年第1四半期` の形。日付は四半期より細かくならない。
- `面積（㎡）` は数値か、`2,000㎡以上`、`5,000㎡以上` のような文字列。`最寄駅：距離（分）` は分の数値か、`30分～60分`、`1H～1H30`、`1H30～2H` のような区分。数値の列に文字列が混ざる。
- `建築年` は `2004年` の形 (1945 年以前は `戦前`)。
- API (XIT001) の出力にはある `DistrictCode` (地区コード、9 桁) は CSV には無い。
- 住所の番地、物件名、緯度経度の列は無い。

### 所在地の粒度と、特定されないための加工

「制度と用語」の項目の説明から。不動産取引価格情報:

> 町・大字までの表示としています（例：千代田区霞が関、大阪市港区弁天　等）。ただし、町・大字まで表示すると物件の特定が可能と思われる場合は、町・大字より広い地域単位での表示としています。

- 取引総額、坪単価、㎡単価は上位 3 桁目を四捨五入して上位 2 桁。
- 面積は 200㎡ 未満が 5㎡ 刻み、200㎡ 以上は上位 2 桁、2,000㎡ 以上 (農地・林地は 5,000㎡ 以上) はまとめて表示。10㎡ 未満は公表しない。
- 延床面積も同じ丸め。間口は 50m 以上をまとめる。
- 最寄駅までの時間は 30 分未満が分単位、30 分以上は区分。
- 取引時期は四半期単位。売買契約日 (不詳なら登記原因日) から決める。
- 価格は「数値の丸め以外は一切補正を行っておりません」。

成約価格情報:

- 所在地は町・大字まで (例の文言は同じ。より広い単位にする但し書きは無い)。
- 取引総額は上位 3 桁目を四捨五入して上位 2 桁。
- 面積と延床面積は 5㎡ 単位で切り上げ。
- 戸建ての最寄駅までの時間は 5 分単位で切り上げ。
- 前面道路の種類は `公道` と `私道` の 2 つ。

### 形式 (取得した 1 本で確かめた)

- 応答は zip 1 本。中に CSV が 1 本 (`Tottori Prefecture_20261_20261.csv`、53,153 bytes、zip 内の圧縮後 9,312 bytes、260 行と見出し 1 行)。
- 文字コードは Shift_JIS (cp932 で読めた。BOM なし)。全角の数字や記号が値に入る (`３ＬＤＫ`、`ＲＣ`、`２中住専`)。
- 改行は LF (最終行だけ CRLF)。全項目がダブルクォートで囲まれる。

## 取り出し方

### 検索・ダウンロード画面

- 画面: <https://www.reinfolib.mlit.go.jp/realEstatePrices/>。条件は 地域 (都道府県、市区町村、地区。「全都道府県」も選べる。または 路線・駅)、価格情報区分 (取引価格・成約価格のどちらか又は両方)、種類、時期 (開始と終了の四半期)。
- 件数の上限について、画面の留意事項:

> ※検索結果一覧では、検索結果（該当件数）が１万件を超えた場合、表示される情報は１万件までです。

> ※検索結果が１万件を超えていても、ダウンロードする場合には、該当する情報はすべてダウンロードされます。ただし、ダウンロードに時間を要する場合があります。

- 申請やログインは要らない (API 利用申請画面に「Web画面の利用において、API利用申請は不要です。」とある)。
- 画面の「ダウンロード」は、サイト内部向けの API (`https://www.reinfolib.mlit.go.jp/in-api/api-aur/aur/csv/transactionPrices`) を呼ぶ。条件は `areaCondition`、`prefecture` (2 桁、全国は `99`)、`city`、`district`、`transactionPrice`、`closedPrice`、`kind` (`all`、`residential`、`place`、`building`、`used`、`farmland`、`woods`)、`seasonFrom`、`seasonTo` (`YYYYN` の 5 桁、例 `20261`)。応答は JSON で、小さい結果は zip を base64 で `body` に入れて返す。画面の JavaScript には、ほかに「処理中」(時間切れの案内を出す) と、用意済みのファイルの URL へ移動する分岐がある。大きい要求がどちらになるかは試していない (未確認)。
- この内部 API は公開 API ではなく、画面の JavaScript が自分用の識別キーを付けて呼んでいる。画面の外から機械的に大量に呼ぶことは、利用規約 第 6 条の禁止事項 (「本ウェブサイトの運用に支障を及ぼし、又はそのおそれのある行為」など) に触れうる。まとめて取るなら公開 API を申請して使うのが筋。

### 公開 API

- 一覧: <https://www.reinfolib.mlit.go.jp/help/apiManual/>。価格情報は XIT001 (不動産価格情報取得)、XPT001 (ポイント)、XIT002 (都道府県内市区町村一覧) など。
- API キーが要る。利用申請 (<https://www.reinfolib.mlit.go.jp/api/request/>) で 氏名、メールアドレス、利用目的、利用者種別 (法人、法人以外の団体、個人) を出し、審査のあと発行される。画面の案内は「API利用申請の審査結果は、申請後5営業日を目安にメールにて通知いたします。」。無償。
- キーは `Ocp-Apim-Subscription-Key` ヘッダーで渡す。キー無しでは 401 を返した。
- XIT001: `https://www.reinfolib.mlit.go.jp/ex-api/external/XIT001?<パラメータ>`。`year` (必須、4 桁)、`quarter` (1 から 4)、`area` (都道府県コード) か `city` (5 桁) か `station` (6 桁) のどれか 1 つ以上、`priceClassification` (`01` 取引価格のみ、`02` 成約価格のみ、未指定で両方)、`language` (`ja`、`en`)。出力は gzip された JSON。項目は CSV とほぼ同じで、`PriceCategory` と `DistrictCode` が付く。`DistrictCode` については「過去にAPIにて取得したデータの地区コード及び地区名との継続性に関し保証するものではありません。」とある。
- XPT001: XYZ タイル (ズーム 11 から 15) で GeoJSON か PBF を返す。点は物件ではなく最寄り駅の位置 (「本APIは、対象となる不動産の最寄り駅のポイントを返却します。」)。
- 回数の上限は明示されていない。API 操作説明の Q&A:

> リクエスト数の明確な上限はありませんが、APIを実行する際は、間隔を空けてリクエストするなど、連続して実行しないようお願いいたします。

### 区分と量の目安

区分は split。都道府県 (または市区町村) と四半期の組み合わせで、必要な部分だけを取れる。画面でも API でも、1 回の応答は丸ごとで Range は無い。最小の単位の例は 鳥取県・1 四半期・両区分で zip 9,312 bytes (CSV 53,153 bytes)。

全期間・全国の量は、取得した 1 本の 1 行あたり約 204 bytes (Shift_JIS) と件数 6,589,044 (取引価格と成約価格の和) から見積もると、CSV で約 1.3GB、zip で約 0.2GB。1 本の比率を当てはめただけの目安で、測っていない (未確認)。API で全国・全期間を取ると、XIT001 は 1 要求が 1 年 (又は四半期) × 1 都道府県なので、47 都道府県 × 約 21 年 = 約 1,000 要求。

PDL1.0 が適用されないコンテンツとして挙がっているのは、国土数値情報、地理院タイル「陰影起伏図」、重ねるハザードマップのオープンデータ、都市計画決定 GIS データ、地域メッシュ統計、地形区分に基づく液状化の発生傾向図、背景地図 (ゼンリン、地理院タイル)。不動産取引価格情報と成約価格情報はこの例外に入っていない。

- 「コンテンツの出典」ページ (<https://www.reinfolib.mlit.go.jp/help/contents/>) の表でも、不動産取引価格情報と成約価格情報は「API配信」「CSVファイル出力」「商用利用の可否」がいずれも「〇」。
- 公共データ利用規約 (第 1.0 版) は CC BY 4.0 と互換で、複製、公衆送信、翻案、商用利用を認める (国税庁法人番号の項で原文を確かめた)。規約の文面どおりなら、出典と加工の記載をすれば、再配布 (Hugging Face に置くこと) も商用利用もできる。
- 第 3 条 (7) に、許可なく「不動産情報ライブラリ」という名称を製品、サービス、アプリケーション名に使えないとある。データセットの名前の付け方には注意が要る。
- 第 6 条の禁止事項は、不正アクセス、サーバーへの妨害、システムのリバースエンジニアリングや二次利用、運用に支障を及ぼす行為など。データの保存や再配布を禁じる条項は無い。

### API 利用規約

同じページの「不動産情報ライブラリ　API利用規約」(2024 年 4 月 1 日施行、2024 年 8 月 28 日、2024 年 10 月 30 日、2025 年 6 月 18 日改正)。

> （３）API利用者は、本API機能を無償で利用することができます。提供情報については、自由に無償で利用できます。ただし、本API機能を利用するための通信費等の費用は、利用者の負担となります。

- 利用には申請と審査が要り、反社会的勢力でないことの確約が要る (第 3 条、第 5 条)。キーは第三者に公開してはならない (第 8 条 (2))。3 年アクセスが無いと停止されうる (第 5 条 (5))。
- API を使ったサービスを出すときのクレジット (第 7 条):

> 「このサービスは、国土交通省の不動産情報ライブラリのAPI機能を使用していますが、提供情報の最新性、正確性、完全性等が保証されたものではありません」

- 取得したデータの保存や再配布を禁じる条項は無い。条件に無い事項はサイトの利用規約に従う (第 1 条 (2))。データの利用条件は画面と同じで、違いは API を使うこと自体の手続き (申請、キーの管理、クレジット表示、アクセスログの保存など)。

### 成約価格情報の元の権利者の表示との食い違い

レインズ・マーケット・インフォメーションの「初めてご利用するかたへ」(<http://www.contract.reins.or.jp/step/step.html>、2026-10-04 に読んだ) の「著作権について」:

> 当サイト内に掲載されている全ての情報については、全国指定流通機構連絡協議会が著作権を保有しております。許可なく複製、変造、第三者への貸与、配布を行うことは、著作権侵害となりますのでご注意ください。

- 不動産情報ライブラリの規約は、成約価格情報を PDL1.0 の例外に挙げず、「コンテンツの出典」で商用利用も「〇」としている。RMI 側のこの表示は RMI のサイトに載った情報についての文で、国土交通省が加工して不動産情報ライブラリで出したものに及ぶかは書かれていない (未確認)。
- 概要資料には「ライブラリで表示しているデータには、データ提供元からの利用条件（データの転売等の商用利用不可など）が付されているものがあり、利用には注意が必要。」とある。どのデータを指すかは書かれていない。「コンテンツの出典」で一部非商用とされているのは国土数値情報由来の一部の自治体分で、価格情報ではない。

## 版

- 四半期ごとに 1 四半期分が足される。トップのお知らせでは、2025 年第 4 四半期分が 2026-04-27、2026 年第 1 四半期分が 2026-07-29 に追加された。「制度と用語」には「次回は、取引時期が2026年（令和８年）第２四半期（４～６月）のデータを、2026年（令和８年）１０月に公表することを予定しています。」とある。
- 過去の四半期の不動産取引価格情報は、公表後も増える。利用規約 第 5 条 (3):

> 不動産取引価格情報等は、四半期ごとにデータの追加を行います。ただし、不動産取引価格情報においては、掲載以降順次追加される可能性があるので、ご注意ください。

検索画面の留意事項:

> また、取引価格情報のデータ数はアンケートの収集状況により、今後も変わる可能性があります。特に最新の期は翌期以降大きく変わる可能性がありますのでご注意ください。

  上の件数の表でも、最新の四半期は前の四半期の約半分しかない。
- 市区町村は最新の区画に揃えて出し直される。「制度と用語」に「2026年（令和8年）4月1日時点の市区町村で公表しています。」とあり、取引件数の説明に「市町村合併があった場合には、それ以後のデータは合併後の市町村のデータに含めて集計しています。」とある。地区コードも継続性を保証しない (XIT001 の説明)。
- 不具合の修正で、過去に出した CSV の中身が変わったことがある。2025-02-07 のお知らせ: 「不動産取引価格・成約価格情報のダウンロード機能で出力されるCSVの最寄り駅の情報が不足する不具合を解消いたしました。」。2025-11-26 には API の返却項目が変わった。
- 古い期間は消えていない。不動産取引価格情報は旧システムと同じ 2005 年第 3 四半期から、成約価格情報は 2021 年第 1 四半期から、2026-10-04 にも検索とダウンロードの対象に残っている。直近 5 年に限られるのは地図画面の表示だけ。ただし規約 第 9 条には「コンテンツは、予告なしに内容を変更、移転又は削除等する場合があります。」とある。
- 過去の時点の版 (ある四半期に公表された時点のデータ) を取る手段はサイトに無い。取れるのは常に最新の状態。同じサイトの鑑定評価書情報の CSV は、価格時点が直近 5 年 (2022 年から 2026 年) だけで、古い年は選べない。
