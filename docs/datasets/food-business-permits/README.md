# 食品営業許可・届出のオープンデータ

2026-10-03 に読んで確かめた内容。ページは curl で取得して読んだ。大きさは HEAD の Content-Length、列は厚生労働省の北海道 (保健所設置主体としての北海道) のファイル `01000_food_business_all.csv` を 1 本だけ取得して見た。

「食品営業許可・届出オープンデータ」という単一の公式データセットは無い。公的機関が出しているものが 2 種類ある。

- 厚生労働省「食品衛生申請等システム」(i2fas) のオープンデータ。全国 157 の保健所設置主体ごとに 1 本の CSV。
- 各自治体のオープンデータ。形式も列も自治体ごとに違う。

## 厚生労働省 食品衛生申請等システムのオープンデータ

- 入口: <https://i2fas.mhlw.go.jp/faspub/IO_S010303.do?method=a_menu_o01Action> (ページ名「食品衛生公開[オープンデータ閲覧]」)
- 作成: 厚生労働省 健康・生活衛生局 食品監視安全課 (利用規約ページの問い合わせ先)。保守と運用は東芝デジタルエンジニアリング株式会社。
- 中身: システムで電子申請された営業許可と届出のうち、申請者が掲載に賛同したものだけ。ページの注記:

> 前月までに公開された食品等事業者の営業許可・届出情報を自治体別にダウンロードできます。

> ※オープンデータは、（食品衛生申請等システムを用いて管轄保健所へ電子申請された情報のうち、）申請者にオープンデータ掲載に賛同いただいているものに限定して掲載しております。

> ※オープンデータ上のD列は管轄自治体所在地となります。施設の住所はI列をご参照ください。

- 紙で申請した施設や、掲載に賛同しなかった施設は入らない。全数ではない。
- 時点の表示は「2026年08月末現在」。FAQ (<https://i2fas.mhlw.go.jp/faq.htm>) に「オープンデータの作成は毎月15日に実施されます」とある。月 1 回の更新。

### 配布ファイル

- 保健所設置主体ごとに 1 本、`<自治体コード5桁>_food_business_all.csv`。全部で 157 本 (都道府県 47、指定都市 20、中核市 62、その他政令市 5、特別区 23 と数が合う)。ファイル名はページの JavaScript (`/faspub/script/IO_S011001_base.js`) に並んでいる。
- ダウンロードの URL は `https://i2fas.mhlw.go.jp/faspub/page/opendatadownload.jsp?param=<ファイル名>`。画面ではアイコンを押すと JavaScript がこの URL を開く。HEAD はセッション無しでも 200 を返した。
- 157 本すべてに HEAD を送り、合計 381,877,428 バイト。最大は北海道 (01000) の 16,866,660、千葉県 (12000) 16,404,239、静岡県 (22000) 16,196,764、福岡市 (40130) 14,880,467。最小は 161,039 (02203、八戸市)。Last-Modified は返らない。
- Range 要求は効かず、`-r 0-2047` でも全体を返した。
- 形式は CSV、UTF-8 (BOM あり)。
- 過去の版を取る手段はページに無い。ファイル名に時点が入らず、毎月上書きされる。

### 取り出し方

区分は split。保健所設置主体ごとの 157 本から必要なものだけ取れる。1 本の中は Range が効かないので丸ごと (最小 161,039 バイト、最大 16,866,660 バイト)。

### 列 (北海道 01000 で確かめた)

25 列。見出しはそのまま次のとおり。

`自治体コード`, `行番号`, `都道府県名`, `市区町村名`, `営業施設名称、屋号又は商号`, `営業施設名称、屋号又は商号（フリガナ）`, `営業の種類`, `業態`, `営業施設所在地`, `営業施設方書`, `緯度`, `経度`, `営業施設電話番号`, `法人名`, `法人番号`, `法人住所`, `許可番号`, `初回許可年月日`, `許可年月日`, `許可開始日`, `許可満了日`, `廃業年月日`, `申請区分`, `許可条件`, `備考`

- `市区町村名` (D 列) は施設の場所ではなく管轄自治体の所在地 (北海道では全行「札幌市中央区」)。施設の場所は `営業施設所在地` (I 列)。

## 自治体のオープンデータ

CKAN (BODIK、東京都オープンデータカタログ、各市のカタログ) や自治体の Web ページに置かれている。ここでは 2 つだけ原文を確かめた。

- 札幌市 <https://ckan.pf-sapporo.jp/dataset/be44af14-f135-41b9-acca-08e215d8a540>。CKAN の `license_id` は `CC-BY-4.0`。全件のスナップショット (`shokuhin260331.csv`、2026 年 3 月 31 日時点、5,708,754 bytes) と、月ごとの新規許可のファイル (2025 年 9 月分から 2026 年 8 月分まで) が並ぶ。見出しは `区名,許可番号,許可年月日,業種名,申請者名,屋号,施設所在地`。
- 新宿区 <https://catalog.data.metro.tokyo.lg.jp/dataset/t131041d0000000124>。CKAN の `license_id` は `CC-BY-4.0`。ファイルは `https://www.city.shinjuku.lg.jp/content/000399975.csv` (4,445,074 bytes、Last-Modified 2026-08-31、UTF-16)。見出しは自治体標準オープンデータセットの「食品等営業許可・届出一覧」と同じ並びで、`法人名` と `法人番号` を含む。

加工したときの記載例は「「食品衛生申請等システム」（厚生労働省）（当該ページのURL）を加工して作成」。

同じページの「３．免責事項・著作権」の「２）著作権について」には、PDL1.0 と食い違う一文がある:

> イ　本サイトで提供している記事、写真、イラスト等に関する著作権は、厚生労働省又は情報提供者に帰属します。
> ウ　利用者は、これらの情報について営利目的での複製・頒布等、再利用しないことに同意するものとします。

- PDL1.0 は CC BY 4.0 と互換で、商用と再配布を認める。一方で「ウ」は営利目的の複製と頒布を禁じている。どちらがオープンデータの CSV に掛かるのか、ページは書いていない (未確認)。「ウ」は「記事、写真、イラスト等」を受けた文なので、サイトの記事を指すと読む余地はあるが、断定はできない。
