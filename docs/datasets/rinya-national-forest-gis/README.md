## nfgis-2024 のライセンス

- CKAN の license_id は `ol` (独自利用規約)。実体は、リソースに入っている「公共データ利用規約 (第 1.0 版) に関する重要情報」の PDF で、PDL1.0 (CC BY 4.0 と互換)。
- 条件: 出典「国有林 GIS データ (当該ページの URL)、PDL1.0」を書く。編集・加工したらその旨を別に書く。林野庁が作ったかのように見せない。
- 「国有林 GIS データの利用に当たっての留意事項」の PDF は、森林法などに基づく行政の事務のために作ったもので他の用途のために作ったものではないこと、位置情報の誤差や空中写真の判読による部分があり現地や権利と一致しないこと、作成時点の現況であること、入林手続のお願いを述べる。再配布を禁じる文言ではないので、カードにそのまま載せる。
- 仕様書に測量法、国土地理院、国土数値情報の記載はない。

## ksj-a45-2019 のライセンスと来歴

- ページの使用許諾条件は「オープンデータ (CC_BY_4.0)」(適用する利用規約に基づく)。国土数値情報の規約 (政府標準規約準拠版) は、複製、公衆送信、翻案を自由とし、商用も可。
- 同じページに「本製品を複製する場合には、国土地理院の長の承認を得なければならない」とある。承認番号の記載はなく、zip 内メタデータ (KS-META) の来歴は「出典：農林水産省林野庁業務資料『国有林GIS貸与可能地図データ (平成30年度版、小班区画ポリゴン)』」だけで、地理院の成果への言及もない (「測量法施行令」は座標系の根拠として出るだけ)。利用制限は「国土情報利用約款を参照」とのみある。承認の一文が何を指すかは確かめられていない。
- 国土数値情報の規約ページの測量法の条は、国土調査の成果の背景図 (基本測量成果) についてのもので、A45 のような国土数値情報には直接触れていない。
- 以前の扱い (N13 道路など) に合わせ、承認の一文があるものは再配布しない側に倒す。A45 の中身は nfgis-2024 の旧版 (2018 年基準) で、新しい nfgis-2024 が上流の林野庁から PDL1.0 で出ているため、公開しなくても失うものは小さい。

## 取得の注意

- G空間情報センターのカタログ (package_show) に載るファイル名の多くは先頭に `www.geospatial.jp` が付いた形で、その URL は HTTP 500。接頭辞を除いた URL で、カタログの大きさと完全に一致して取れる。収集スクリプトはカタログの URL を先に試し、500 のときだけ切り替える。
- 速度は 1 接続で毎秒 50KB ほどと遅い (国土数値情報側は毎秒 1.3MB)。nfgis-2024 の全量に 7〜8 時間かかる。

## 判断 (2026-10-10)

公開するのは nfgis-2024 だけ。ksj-a45-2019 は手元に置くだけで公開しない。地理院長の承認は申請すれば得られなくもないが手間がかかり、A45 は nfgis-2024 の旧版 (2018 年基準) で、上流の林野庁の最新版が PDL1.0 で出ているため、申請しない。
