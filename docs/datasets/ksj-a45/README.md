# 国土数値情報 A45 国有林野 (2019 年度版)

2026-10-10 に確かめた内容。収集は hf_data/ksj-a45-2019 (公開しない)。

- 配布元: 国土交通省 国土政策局 国土情報課 (<https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A45.html>)。2019 年度 (令和元年度) 版、基準日 2018-04-01 (最新版のまま、2020 年公開)。
- 中身: 47 都道府県の zip (1.53GB、Shapefile、GeoJSON、GML と JPGIS メタデータ KS-META) と製品仕様書。座標系は JGD2011 の経緯度。林野庁のデータを国土交通省が編集して配っている旧版で、上流の林野庁の最新版は [../nfgis-2024/README.md](../nfgis-2024/README.md)。

## ライセンスと来歴

- ページの使用許諾条件は「オープンデータ (CC_BY_4.0)」(適用する利用規約に基づく)。国土数値情報の規約 (政府標準規約準拠版) は、複製、公衆送信、翻案を自由とし、商用も可。
- 同じページに「本製品を複製する場合には、国土地理院の長の承認を得なければならない」とある。承認番号の記載はなく、zip 内メタデータ (KS-META) の来歴は「出典：農林水産省林野庁業務資料『国有林GIS貸与可能地図データ (平成30年度版、小班区画ポリゴン)』」だけで、地理院の成果への言及もない (「測量法施行令」は座標系の根拠として出るだけ)。利用制限は「国土情報利用約款を参照」とのみある。承認の一文が何を指すかは確かめていない。
- 国土数値情報の規約ページの測量法の条は、国土調査の成果の背景図 (基本測量成果) についてのもので、A45 のような国土数値情報には直接触れていない。
