# 国有林 GIS データ nfgis-2024 (林野庁)

2026-10-10 に確かめた内容。収集は hf_data/nfgis-2024 (未公開)。

- 配布元: 林野庁 国有林野部 経営企画課、G空間情報センター (<https://www.geospatial.jp/ckan/dataset/nfgis-2024>)。2024 年度 (令和 6 年度) 版、基準日 2024-04-01、掲載 2025-12。
- 中身: 47 都道府県の zip (1.42GB)、仕様書 PDF、コード表、規約 PDF 2 本。zip の中は 都道府県 / 森林計画区 / 第N系 / レイヤー.shp で、レイヤーは小班区画 (1.1GB)、林班区画 (0.32GB)、林道 (54MB)。Shapefile 486 本、座標系は日本測地系 2000 の平面直角座標系の 17 の系 (EPSG:2443〜2461)、.cpg は無い。

## ライセンス

- CKAN の license_id は `ol` (独自利用規約)。実体は、リソースに入っている「公共データ利用規約 (第 1.0 版) に関する重要情報」の PDF で、PDL1.0 (CC BY 4.0 と互換)。
- 条件: 出典「国有林 GIS データ (当該ページの URL)、PDL1.0」を書く。編集・加工したらその旨を別に書く。林野庁が作ったかのように見せない。
- 「国有林 GIS データの利用に当たっての留意事項」の PDF は、森林法などに基づく行政の事務のために作ったもので他の用途のために作ったものではないこと、位置情報の誤差や空中写真の判読による部分があり現地や権利と一致しないこと、作成時点の現況であること、入林手続のお願いを述べる。再配布を禁じる文言ではないので、カードにそのまま載せる。
- 仕様書に測量法、国土地理院、国土数値情報の記載はない。

## 取得の注意

- G空間情報センターのカタログ (package_show) に載るファイル名の多くは先頭に `www.geospatial.jp` が付いた形で、その URL は HTTP 500。接頭辞を除いた URL で、カタログの大きさと完全に一致して取れる。収集スクリプトはカタログの URL を先に試し、500 のときだけ切り替える。
- 速度は 1 接続で毎秒 50KB から 1MB と遅い。

## 判断 (2026-10-10)

公開するのはこちらだけ。旧版にあたる国土数値情報 A45 は [../ksj-a45/README.md](../ksj-a45/README.md) のとおり手元のみ。公開の形は、配布元のファイル (zip など 51 ファイル) をそのまま上げ、あわせてレイヤー × 系ごとの GeoParquet (47 ファイルと索引) を上げる (ユーザー判断、2026-10-10)。

## GeoParquet の作り方 (2026-10-10)

- 属性は DBF を自前で読む。属性名も値も Shift_JIS (LDID 19) で、DuckDB 内蔵の GDAL は属性名を復号できない。Microsoft の cp932 (Python) で読み、全角ハイフンマイナス (0x817C) など 6 つの符号は iconv の読み方 (JIS X 0208) と違うので、カードに書いた。ジオメトリは ST_Read で読み、レコード番号で属性と結ぶ。
- 座標系は系ごとに違うので、再投影せず、レイヤー × 系で分ける (第 N 系は EPSG:2442+N)。小班区画 975,666、林班区画 58,293、林道 57,912 で計 1,091,871 地物、Shapefile 486 本。林道の 5 本は空で Parquet を作らず、索引に 0 行と残した。
- 照合: 全属性を別の読み手 (anaconda の GDAL 3.9.2) と突き合わせ (ダイジェスト)、全レコードの bbox と点の数を .shp の見出しと突き合わせた。無効なジオメトリは 4,618 件あり、直さずに数だけカードに書いた。
- 見つけた不具合: DuckDB は既定でブルームフィルタを書く (無効にした)。
