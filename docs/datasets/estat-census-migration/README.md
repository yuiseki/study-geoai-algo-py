# 国勢調査 人口移動集計 (5 年前の常住地、移動人口)

2026-10-04 に読んで確かめた内容。表の一覧は e-Stat の統計データ API 3.0 (`getStatsList`、政府統計コード `00200521`) で数え、分類事項は主な市区町村 OD 表 23 本の `getMetaInfo` で読んだ。実データは `getStatsData` で小さい切り出しを 2 本 (令和 2 年の表 7-1 の台東区、平成 2 年の `0000031789` の台東区) だけ取り、件数は `cntGetFlg=Y` で数えた。ファイル配布は e-Stat の一覧ページを `chromium --headless=new --dump-dom` で描画して読み、令和 2 年の 325 本は HEAD で大きさを測った。用語の定義は総務省統計局の「国勢調査の結果で用いる用語の解説」(令和 2 年、`ug_03.pdf`) で確かめた。

- 入口 (統計局): <https://www.stat.go.jp/data/kokusei/2020/kekka.html> の「人口移動集計」のタブ
- 入口 (e-Stat ファイル): <https://www.e-stat.go.jp/stat-search/files?page=1&layout=datalist&lid=000001287959> (令和 2 年 移動人口の男女・年齢等集計)
- 入口 (API): `https://api.e-stat.go.jp/rest/3.0/app/json/getStatsList?statsCode=00200521&searchWord=移動`
- 作成: 総務省統計局。e-Stat の運用は独立行政法人統計センター ([../estat/README.md](../estat/README.md))。
- 中身: 調査時の常住地 (現住地) と 5 年前の常住地を組み合わせた人口。転入、転出、移動なし、国外からの移動、不詳を区分し、男女、年齢、居住期間、産業、職業、国籍、世帯の類型などと掛けた表。
- 5 年前の常住地は、1990 年、2000 年、2010 年、2015 年、2020 年の各回にある。1995 年と 2005 年には無い。1 年前の常住地を問う表は見つからなかった。
- 市区町村から市区町村への OD 行列は、1990 年、2000 年、2010 年、2015 年、2020 年のすべてにある (表 ID は下の「市区町村 OD 表」)。
- 地域の単位は、全国、都道府県、21 大都市 (令和 2 年の呼び方)、人口 50 万以上の市、市区町村。2020 年は町丁・字等の小地域の表もあるが、OD ではなく 5 年前の常住地の区分別の人口。

## 用語

「用語の解説」(<https://www.stat.go.jp/data/kokusei/2020/kekka/pdf/ug_03.pdf>) の定義:

> 「５年前の常住地」とは，その世帯の世帯員が５年前にふだん居住（常住）していた市区町村をいいます。

> 令和２年調査では，平成27年10月１日（前回調査時）に常住していた市区町村について調査し，５年前から調査時までの当該地域への転入状況を，以下の区分などで表章しています。

> なお，平成12年以前の調査では５歳以上の人のみ集計していましたが，22年以降の調査では，５歳未満の人についても，出生後に常住していた場所を調査し，集計しています。

- 区分は、現住所 (5 年前と同じ場所)、自市町村内から、自区内から、自市内他区から、県内他市町村から、他県から、国外から、5 年前の常住市区町村「不詳」、移動状況「不詳」。「転入」と「転出」は地域の階層ごとに足し方が違い、たとえば市町村の転入は (県内他市町村から) + (他県から) + (国外から)。
- 転出の側 (「5 年前の常住者」) には、5 年前に国外にいた人は入らない。
- 移動は 5 年前と調査時の 2 時点の比較で、その間の途中の移動は数えない。この点は住民基本台帳人口移動報告の転入・転出 (届出の件数) と性質が違う ([../estat-jumin-idou/README.md](../estat-jumin-idou/README.md))。

### 属性

令和 2 年の表題から読める掛け合わせ:

- 男女、年齢 (5 歳階級、各歳)、居住期間、配偶関係
- 世帯の家族類型、世帯の移動類型、世帯主との続き柄、施設等の世帯の種類、住宅の所有の関係
- 国籍 (外国人の表、表 9-1 から 9-3)
- 労働力状態、産業 (大分類)、職業 (大分類)、従業上の地位 (移動人口の就業状態等集計)

市区町村どうしの OD に掛かっているのは、男女と年齢 (5 歳階級) と居住期間まで。産業や職業や国籍は、相手側の地域を都道府県や大都市までに縮めた表にしか無い。2010 年と 2015 年には「男女別人口及び15歳以上就業者数」の市区町村 OD がある (表 ID は下)。

## 市区町村の境界

- 表の市区町村は、その回の調査時点の市区町村。2020 年の「用語の解説」:

> 国勢調査実施日（令和２年10月１日）現在の境界による，各市町村，東京都特別区部の各区及び政令指定都市の各区の区域です。

- 5 年前の常住地の側も、調査時点の市区町村のコードで表されている。どの回の OD 表でも、現住地と 5 年前の常住地の市区町村コードの集合が一致した (差は下の例外だけ)。たとえば 2020 年の表は両側とも那珂川市 (`40231`、2018 年に那珂川町 `40305` から市制施行) を持ち、`40305` を持たない。2015 年の表は両側とも白岡市 (`11246`) と野々市市 (`17212`) を持つ。どちらも 2010 年から 2015 年の間に市になったもの。5 年前の住所を調査時点の市区町村へどう割り当てたかの説明は、読んだ資料には無かった (未確認)。
- 例外は人口 0 の自治体。2015 年の `0003169740` では、福島県の富岡町、大熊町、双葉町、浪江町、葛尾村、飯舘村が 5 年前の常住地の側にだけあり、現住地の側に無い。2000 年の `0000033427` では三宅村 (`13381`) が 5 年前の常住地の側にだけある。
- 回をまたいだ組み替えはされていない。2024 年に公開された 2015 年の不詳補完 (`0004019721` など) も、2015 年の市区町村 (那珂川町 `40305`) のまま。2000 年の表は 3,000 を超える平成の大合併前の市区町村、1990 年の表も同じく合併前の市区町村で持つ。回をつなぐには利用者が対応表を用意する必要がある。
- 統計局は、人口と世帯数については前回の結果を今回の境域に組み替えた値を載せている (「用語の解説」の「境界変更等に伴う前回調査結果の取扱い」)。移動の表にそれがあるかは見つからなかった。

## 版と改訂

- 古い回の表も残っている。1990 年と 2000 年の表は ID が `0000031xxx`、`0000033xxx` の古い系列で、公開日は 2007-10-05 と 2007-10-07。`getStatsData` で 1990 年の表から実データが返った。
- 2010 年は同じ中身の系統が 3 つ並んでいる。2012 年公開の元の表 (`0003046148` など)、2017 年公開の「遡及集計」(`0003111505` など、平成 27 年の表の形に合わせたもの)、2020 年公開の全国 OD (`0003412171`)。新しい系統が出ても古い系統は消されていない。
- 2015 年と 2020 年には、2024-09-30 に不詳補完の表 (5 年前の常住地の不詳を補完した参考表) が追加された。元の表は残っている。
- API の `UPDATED_DATE` は、2010 年、2015 年、2020 年の表がそろって 2026-09-29、1990 年と 2000 年の表が 2026-05-29。e-Stat のファイル一覧の「公開（更新）日」は 2020 年の表で 2022-02-28 のまま。`UPDATED_DATE` が数値の改訂を表すのかは分からない (未確認)。
- 統計局の利用規約は「コンテンツは、予告なく変更、移転、削除等が行われることがあります」と書いている。

## 取り出し方

区分は catalog。表 ID を目録 (`getStatsList`) で選び、`getStatsData` を `startPosition` と `NEXT_KEY` で繰り返して取る。ファイルで取る場合は split (現住地の都道府県 × 男女で分かれた Excel や CSV)。

- 認証: API はアプリケーション ID が要る。ファイルは不要。
- 結果の判定: API は HTTP 200 の中の `RESULT.STATUS` で見る (0 が正常、1 が該当なし)。
- 絞り込み: `cdArea`、`cdCat01` などで現住地や男女を指定できる。`cntGetFlg=Y` で件数だけを返す。
- 1 件あたりの JSON は、2020 年の表 7-1 で約 119 bytes、1990 年の表で約 91 bytes (`VALUE` の要素を区切りなしで書き出して測った)。

### 全部の OD を取る量

上の表の件数からの見積もり (実際に全件は取っていない):

| 範囲 | 表 | 件数 | 要求数 |
|---|---|---:|---:|
| 各回 1 本、男女まで | 1990 `0000031797`、2000 `0000033427`、2010 `0003412171`、2015 `0003414233`、2020 `0003447424` | 119,326,312 | 1,197 |
| 2020 年を年齢まで | `0003447421` | 337,978,035 | 3,380 |
| 2010 年と 2015 年を年齢まで (転入) | `0003111505`、`0003169080`、`0003169100` | 127,945,125 | 1,281 |
| 不詳補完 (2015、2020) | `0004019721`、`0004020974` | 580,205,625 | 5,803 |

- 各回 1 本で男女までなら、要求 1,200 回、約 1.2 億件。JSON で 1 件 100〜120 bytes とすると十数 GB。
- 2020 年の表 4 だけで 3.4 億件、JSON で 40GB 前後。同じ表の Excel は 144 本で約 1.5GiB。
- 2020 年の表 7-1 は件数の 46,405,440 が 男女 3 × 居住期間 4 × 5 年前 1,968 × 現住地 1,965 にちょうど一致する。ゼロも `-` として行を持つ密な表で、件数の多くは `-` (台東区では 1,968 のうち 749)。
- 1 回の要求にかかる時間は測っていない。API の利用規約は「短時間における大量のアクセスその他本機能の運用に支障を与える行為」を禁じている。
