### 住所と座標

- 住所はある。E 列は 656 行すべてに値があり、すべて都道府県名から始まる (`北海道札幌市白石区流通センター7-9-35`、`東京都江東区南砂7-12-4　東東京流通センターB棟6F`)。郵便番号は無い。
