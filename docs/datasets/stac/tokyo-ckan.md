# tokyo-ckan

2026-09-28 に読んで確かめた内容。

- `https://stac.yuiseki.net/tokyo-ckan/`
- 1 組織 = 1 コレクション、1 データセット = 1 Item、1 ファイル = 1 asset。
- 区市町村をまたいで比べるなら「共通項目」(families) から。43 種類あり、うち 23 種類はデジタル庁の自治体標準オープンデータセット。

気をつけること:

- CKAN には場所も時刻も無いので、どちらも推定値。どう推定したかが `tokyo:footprint_basis` と `tokyo:datetime_basis` に書いてある。
- 場所は公開した組織の管轄区域の矩形。データの点がその中にあるとは限らない。
- 時刻がデータの時期を表すのは、`datetime_basis` が `resource-name` か `dataset-title` のものだけ。
- 同じ名前のデータセットでも列構成が同じとは限らない。`family_layout_match` で確かめる。

## 施設一覧の CSV のミラー

施設一覧の CSV は各区のサイトにあり、リンクが切れる (2026-09-28 に取得した時点で 11 件が 404)。
再現できるように、23 区の 17 の共通項目の CSV (CC-BY-4.0 のものだけ) を、中身を変えずに <https://z.yuiseki.net/static/tokyo-ckan-files/> に置いた。
取得は `scripts/mirror_tokyo_ckan.py`。取得できなかったものも manifest.json と README.md に記録している。

- 194 件のうち 183 件を置いた (合計 8.9MB)。11 件は公開元で 404。
- 文字コードは UTF-8 が 140、CP932 が 30、UTF-16 が 9。名前は .csv なのに中身が xlsx のものが 2、zip のものが 2 (まだ読んでいない)。
- テキストの 179 件はすべて緯度と経度の列を持つ。列名は `緯度` か、`投票所_緯度` のように施設の種類が頭に付いた形。
- ただし値が空のものが多い。台東区は公立図書館、スポーツ施設、投票所などで緯度と経度がすべて空で、住所だけが入っている。使うには住所から位置を引く必要がある (アドレス・ベース・レジストリの町字の代表点か、Nominatim など)。
- 台東区の指定緊急避難場所一覧の ID の列は `1.31067E+11` のように指数表記に化けている (表計算ソフトで保存したものと見られる)。

`study_geoai.ckan.facilities(con, area, "指定緊急避難場所一覧")` で、範囲の区が出した施設を 1 行ずつ読む。座標が無い行、壊れた行、読めなかったファイル、取れなかったファイルも消さずに残し、`status` で分かるようにしている。
