# 国土交通省 国土調査 (土地分類調査・水調査) の GIS データ

2026-10-03 に読んで確かめた内容。ページは curl で取得して読んだ。大きさと Last-Modified は、GIS データのダウンロードページと地下水資料台帳のページに並ぶファイル 500 本すべてへの HEAD。ZIP の中身は、HTTP Range で末尾の中央ディレクトリだけを読んで一覧にした。丸ごと取得して中を見たのは、東京都の地下水資料台帳 (`F9/data/13.zip`、267,326 bytes) と令和元年東日本台風の浸水域 (`FC/GIS/2019_10_r1_t.zip`) の 2 本だけ。

国土数値情報 (`nlftp.mlit.go.jp/ksj`) は同じサイトにあるが、ここでは扱わない。

- 入口: <https://nlftp.mlit.go.jp/kokjo/inspect/landclassification/index.html> (土地分類調査・水調査の概要)
- GIS データの一覧: <https://nlftp.mlit.go.jp/kokjo/inspect/landclassification/download.html>

### 地下水資料台帳

- ZIP の中は `<都道府県コード>.dat` が 1 本。タブ区切り、cp932、改行は CRLF。東京都 (13) は 3,520 行、47 列。
- 列: `NEN`, `PREF`, `CITY`, `X`, `Y`, `ADR`, `HEIGHT`, `USE`, `DEP`, `SC`, `SCL`, `SCREENS`, `DD`, `DIA`, `START`, `FINISH`, 自然水位と揚水水位と揚水量 (`NWL_xx`, `PWL_xx`, `Q_xx`, `QSP_xx` と日付)、`GEOLOGY` (深さ、記号、地質名を `|` で連ねた柱状)、`TEMP`, `PH`, 水質 (`NOX`, `NH4-N`, `CL`, `FE`, `CA`, `MG`, `SO4` など)。
- 座標の列 `X` と `Y` はあるが、東京都では 3,520 行すべて空だった。ページにも次の注意がある:

> （注意）公開中のデータには、調査地点の経緯度や詳細な所在地は掲載しておりません。

- 位置を示すのは `CITY` (市区町村コードの下 3 桁、東京都では `101` 千代田区など) と `ADR` (町名。「麹町」「内幸町2丁目」程度。3,356 行に値がある) だけ。番地は無い。
- `NEN` は 1952 年から 2023 年。ページの表示では、30 道府県が令和 4 年度、17 都道県が令和 5 年度までのデータ。
- 都道府県ごとの調査地点位置図 (PDF) はあるが、機械可読の座標ではない。

### 座標と住所

- 土地分類と土地保全、利水現況図はすべて Shapefile のポリゴン、ライン、ポイントで、座標を持つ。利水現況図には取水口、排水口、水文観測所などのポイントがある。
- 個人の住所を持つ表は見当たらない。地下水資料台帳は井戸ごとの記録だが、位置は町名までで座標は空。

## 取り出し方

区分は split。調査ごとに、都道府県、5 万分の 1 図幅、土地履歴調査の図郭、水系、災害のどれかで分かれた ZIP が並ぶ。各 ZIP の中は whole。

- `curl -r 0-1023` は 206 を返した (`F5/GIS/01.zip`、土地履歴調査 `533946_gisdata.zip`、`F2/GIS/13.zip`)。Range で ZIP 末尾の中央ディレクトリを読めば、落とさずにファイルの一覧が取れ、個別のメンバー (`.prj` や `readme.txt`) も抜き出せた。ただし Shapefile は索引を持たないので、地物の部分集合は選べない。
- 最小単位はばらつきが大きい。5 万分の 1 の烏帽子島は 10,221 bytes、20 万分の 1 土地保全の北海道は 464,694,059 bytes。土地保全の 16 本だけで全体の半分を超える。
- 目録は HTML のページだけ。機械可読の一覧は無い。e-Gov データカタログ (下記) は一部の ZIP しか載せていない。

- `cc-by` は現在の規約 (PDL1.0、CC BY 4.0 互換) とは合う。ダウンロードページの「そのまま複製して配布することは禁じています」とは合わない。

## 更新と過去の版

- 更新は続いている。土地履歴調査は 2025-10-15 に 3 地区を追加 (国土調査の新着情報 <https://nlftp.mlit.go.jp/kokjo_news.html>)。災害履歴図の水害は 2025-01 に `_add24` の版が出た。地下水資料台帳は 47 本すべて 2025-12-19 に置き直されている。20 万分の 1 土地分類は 2022〜2024 年に 21 本が新しくなった。
- 古い 50 万分の 1、5 万分の 1、土地保全、利水現況図は 2009〜2017 年から変わっていない。
- 過去の版を一覧する手段はページに無い。ただし、置き換わった古いファイルがリンクを外されたまま残っている例がある。
  - 災害履歴図: `1959_09_s34_t.zip` (194,531 bytes、2021-02-03) と、今リンクされている `1959_09_s34_t_add24.zip` (262,841 bytes、2025-01-10) の両方が 200 を返す。全期間版も `_add23` (6,927,643 bytes、2024-03-11) が残っている。`_add2x` の付かない全期間版は 404。
  - 土地履歴調査: e-Gov に載っている旧い URL (`mapdata/tokyo01/gisdata.zip` など) は今も 200 で、大きさと Last-Modified は今の URL と同じ。
- 地下水資料台帳はファイル名に時点が入らず、上書きされる。前の年度の版を取る手段は見当たらない。
