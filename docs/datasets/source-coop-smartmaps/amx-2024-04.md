## 中身 (PMTiles ヘッダとメタデータ)

- PMTiles v3、ベクトルタイル (MVT)、タイルは gzip、clustered。
- ズーム 14 から 16 のみ。広域の表示には使えない。
- bounds: 122.934191, 24.045645, 145.816789, 46.051342。
- タイル数 (addressed) 1,217,008、中身の数 (contents) 1,204,701。
- 生成: tippecanoe v2.17.0。元は `/data/MOJ-XML_2024/14_FlatGeobuf_All/MojMap_2024.fgb` (FlatGeobuf) を MBTiles にしたもの (generator_options による)。
- 生成時に `筆ID`, `version`, `代表点緯度`, `代表点経度`, `地番区域CD`, `XML_File`, `公図面積` の列を落としている (`-x`)。`--drop-densest-as-needed` も付いている。

レイヤーは `fude` の 1 つ。tilestats の件数は 108,962,309 (Polygon)。属性は 8 つ、すべて文字列:

| 属性 | 異なる値の数 (tilestats) | 例 |
|---|---:|---|
| 地図名 | 1000 以上 (打ち切り) | `01101_2010_1` |
| 地番 | 1000 以上 (打ち切り) | `1-1`, `071-道-1` |
| 地番区域 | 1000 以上 (打ち切り) | `あきる野市_三内___` |
| 座標値種別 | 2 | 図上測量, 測量成果 |
| 座標系 | 17 | 公共座標1系 から 17系 |
| 測地系判別 | 2 | 変換, 測量 |
| 精度区分 | 6 | 甲一, 甲二, 甲三, 乙一, 乙二, 乙三 |
| 縮尺分母 | 21 | 50 から 20000 |

## 気づいたこと

- メタデータの name と description がどちらも作者の手元の MBTiles のパス (`/data/MOJ-XML_2024/21_MBTiles/MojMap_amx.mbtiles`) のまま。
- 縮尺分母が数値ではなく文字列で入っている。
- 地番に `(1235+1236)` や `*12-1`、`07市道-1` のような表記の揺れがそのまま残っている。
- 筆 ID や代表点が落とされているので、別のデータと筆単位で突き合わせるのは難しい。
- 法務省の公開は 2024 年 4 月の版 (Web ページの説明による「3rd release」)。以後の版は反映されていない。

## 学習での使い道 (案)

- 2 Decision Tree/Random Forest, 3 Gradient Boosting: 筆の面積・形状 (幾何から計算) と座標系などから、精度区分 (6 クラス) や座標値種別 (図上測量か測量成果か) を予測する。
- 4 データリーク: 地図名の先頭 5 桁は市区町村コードに見えるので (未確認)、同じ地図名の筆が学習と評価に分かれるとリークする。地図名や市区町村でグループ分割する題材になる。
- 11 SHAP: 上の分類で、形状と地域のどちらが効いているかを見る。
- 5 DBSCAN: 筆の代表点 (重心を自分で計算) を密度でクラスタリングし、市街地と農地を分ける。
- ズーム 14 から 16 しか無いので、全国を扱うならタイルを大量に読むことになる。まずは 1 市区町村の範囲で試すのがよい。
