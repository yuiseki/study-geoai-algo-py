この FAQ は (a) の重みを持つ国土交通省自身の文章だが、出典記載の義務に一度も触れていない。「手続き不要」「ご自由に」「無料で自由に」という語だけが並ぶ。後述する実務者の沈黙の源として、この FAQ は最も有力な候補である。同じ文面は Start Guide (https://www.mlit.go.jp/plateau/start-guide/) にも掲載されている。

なお FAQ の二つ目の答えは著作権の帰属先を地方公共団体と明確に述べており、サイトポリシーの括弧書きと一致する。

### 1.3 PLATEAU Journal の弁護士対談

https://www.mlit.go.jp/plateau/journal/j011/ 掲載日 2022.2.3 (2026-09-30 取得)

記事名は「地図は誰のもの？3Dモデルオープンデータ周辺の権利を多角的に考える。」である。弁護士と国土交通省都市局の担当者が測量法について直接やりとりしている。逐語で引く。

弁護士側の問い:

> 都市データの取得や利活用にあたっては、取得にあたって所有権や施設管理権等の制約が意外と大きいです。著作権、商標権、意匠権などの知的財産権については、気にしなきゃいけないポイントはあるものの、例外規定等を丁寧にみていくと意外に法的なハードルはそんなにないように思います。あとは、個人情報やプライバシー、肖像権といった権利も検討が必要ですが、やはり大きなハードルではないように思います。あえて言うと、測量法が若干今の時代にアップデートされていない印象があるのですが、測量法の現代的な意義についてはどのように考えられるでしょうか？

国土交通省側の答え:

> 測量法はクオリティの担保なんです。測量法上決められたプロセスで精度管理されているので、みんなが地図を信用できる。また、公共測量と言いたい場合はこうしてというだけで、測量法自体の規制法ではないんです。ただ、公共測量は膨大な作業でルールも多いので、測量法を守った測量ができるのは、実質的には専門家を持つ測量会社などに限られてきます。

弁護士がこれを受けて確認する:

> 測量法は公式の地図としての精度担保のためのルールであり、規制法ではない、というのはなるほどなんですが、大規模な測量ができるプレイヤーが極めて限定されていることと、その測量した結果が誰もが自由に使えて、アクセスしやすい形で公開されているかが課題ですよね。測量法が悪いのではなく、一応オープンになっているとはいえ、測量データにアクセスしづらいのが問題なのかもしれません。

この対談の結論は、測量法は精度と品質を担保するための手続法であって、下流の利用を禁じる規制法ではない、というものである。これは (a) の重みを持つ。

### 1.4 測量マニュアルの実際の記述

https://www.mlit.go.jp/plateau/file/libraries/doc/plateau_doc_0010_ver02.pdf (2026-09-30 取得、PDF をテキスト化)

サイトポリシーが個別法令の制約として名指ししているのはこのマニュアルである。承認申請について書かれている箇所を逐語で引く。

> 基本測量の測量成果を使用して基本測量以外の測量を実施しようとする者は、国土交通省令で定めるところにより、あらかじめ、国土地理院の長の承認を得なければならない。［出典 測量法第30条］

> 公共測量の測量成果を使用して測量を実施しようとする者は、あらかじめ、当該測量成果を得た測量計画機関の承認を得なければならない。［出典 測量法第44条］

いずれも主語は「測量を実施しようとする者」である。マニュアル本体も「航空測量の実施から3D都市モデル作成までの工程を公共測量成果として作成することを想定している」と自ら述べており、想定読者は測量を発注する自治体と受注する作業機関である。公開済みの 3D 都市モデルをダウンロードして可視化やシミュレーションに使う人が承認申請を要するとは、どこにも書かれていない。1.3 の対談の結論と整合する。

## 2. コミュニティ全体の振る舞い (b)

Qiita のタグ API で PLATEAU タグの記事を全件取得した (https://qiita.com/api/v2/tags/PLATEAU/items、2026-09-30 取得)。総数 189 件。本文に対して機械的に判定した結果は次のとおりである。

- 出典の記載に触れている記事 (「出典：」「出典表記」「クレジット表記」等を含む): 11 件
- ライセンスに触れている記事 (PDL、CC BY、公共データ利用規約、site-policy 等を含む): 8 件
- どちらにも触れていない記事: 172 件

つまり PLATEAU を題材にした技術記事の約 9 割は、出典にもライセンスにも一言も触れずに、スクリーンショットとデータを載せている。これが最も重要な観測結果である。実務者が誤った主張を積極的に広めているのではなく、話題にすること自体がほとんど起きていない。

Zenn についても API で本文を取得して同じ観点で読んだが (https://zenn.dev/api/search?source=articles&q=PLATEAU および各記事の https://zenn.dev/api/articles/{slug}?username={user}、2026-09-30 取得)、PLATEAU を扱う記事 30 件強のうち出典表記に踏み込んでいたのは 1 件だけであり、Qiita と同じ傾向である。

この集計は (b) の重みを持つ。個々の記事の是非ではなく、コミュニティが何を当たり前と扱っているかの指標として読むべきである。

## 3. 個々の記事が読者に何をせよと言っているか (c)

### 3.4 著作権の帰属先を逆に書いている例

同じ記事 https://qiita.com/Retro-Maid/items/d99e436fe0b19e151709 2026-07-11

サイトポリシーと FAQ はいずれも、G空間情報センターで公開されている 3D 都市モデルの著作権は各地方公共団体に帰属すると述べている。「原則が国土交通省で、一部が自治体」という書き方は、3D 都市モデルに関しては逆である。ただしこの記事は出典表示が必要であることを正しく伝えており、その点では 3.2 の例より正確である。

## 4. 検証した二つの仮説

### 4.1 「出典は不要」と言っている人がいるか

今回の範囲では、出典は不要である、と明示的に書いている記事は見つからなかった。代わりに見つかったのは沈黙である。2 節のとおり Qiita の PLATEAU タグ 189 件中 172 件が出典にもライセンスにも触れていない。3.2 のように、サイトポリシーを引用しながら出典義務の行だけを落とす形もある。

この沈黙の最も有力な説明は、国土交通省自身の FAQ と Start Guide が「手続き不要」「ご自由に」「無料で自由に」とだけ書き、出典記載に一言も触れていないことである。実務者は誤情報を広めているのではなく、公式の要約を素直に読んだ結果そうなっている。これは (a) と (c) の食い違いというより、(a) の内部に食い違いがあり、(c) がその一方だけを受け取っている状態である。

### 4.2 「測量法が利用を禁じる」と言っている人がいるか

こちらも、今回の範囲では見つからなかった。Qiita の PLATEAU タグ 189 件のうち測量法に言及しているものは実質なく、測量法を理由に利用を控えよと読者に指示している記事は確認できなかった。1.4 のとおりマニュアルの承認申請規定は測量を実施する者に向いており、1.3 のとおり国土交通省自身が対談で「測量法自体の規制法ではない」と述べている。恐れが広まっている形跡はない。

ただしこれは「誰も言っていない」ではなく「今回 curl で読めた範囲では見つからなかった」である。note や企業ブログの一部、勉強会のスライドは網羅できていない。

## 5. 国土交通省と自治体の書き分けについて

出典文字列のなかで自治体名を書いている記事は、今回見た範囲で一件もなかった。3.1 に挙げたどの例も、名前としては国土交通省ないし PLATEAU だけを書いている。3.4 のように帰属先そのものを逆に書いている例すらある。

実務者を責めるべきではない。原因はほぼ確実に公式の例文にある。サイトポリシー第3節は同じ段落のなかで、3D 都市モデルの著作権は各地方公共団体に帰属すると明記しておきながら、その直後の出典記載例は「出典：国土交通省 PLATEAUウェブサイト（当該ページのURL）」だけを示している。自治体名を含む例文は存在しない。配布点である G空間情報センターも、1.5 のとおり推奨出典文字列を提示していない。公式が示した唯一の型が国土交通省だけを名指ししている以上、実務者がそれを写すのは自然な帰結である。

書き分けが必要だと考えるなら、その要求は現状どこにも明文化されていない。逆に、国土交通省だけを書けば足りると考えるなら、それは公式の例文に忠実であるという以上の根拠を持たない。どちらの立場を取るにせよ、拠り所は例文一つしかないというのが 2026-09-30 時点の事実である。
