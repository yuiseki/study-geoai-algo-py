# 指定緊急避難場所・指定避難所データ (国土地理院)

2026-10-06 に読んで確かめた内容。件数と日付は同日に取得した `yuiseki/gsi-evacuation-sites-jp` の `data/raw/2026-10-05/` (取得リポジトリは `/sata_hdd_24tb/hf_data/gsi-evacuation-sites-jp/`) から数えたもの。

- 市町村長が災害対策基本法第49条の4・第49条の7 に基づいて指定し、市町村が国土地理院に登録して公開に同意したものを、国土地理院が地理院地図で表示し CSV と GeoJSON で配っている。内閣府・消防庁との共同の取り組み。
- 案内: `https://www.gsi.go.jp/bousaichiri/hinanbasho.html`
- ダウンロード: `https://hinanmap.gsi.go.jp/index.html` (注意事項への同意画面) から `https://hinanmap.gsi.go.jp/hinanjocp/hinanbasho/koukaidate.html` (一覧) へ進む。
- 指定緊急避難場所は命を守るために緊急的に逃げる場所で、災害種別 (洪水、崖崩れ・土石流及び地滑り、高潮、地震、津波、大規模な火事、内水氾濫、火山現象) ごとに指定される。指定避難所は危険がなくなるまで滞在する施設。国土地理院は「災害発生時には、指定避難所ではなく、指定緊急避難場所へ避難してください」と書いている。

## 一次配布元とファイル

一覧ページは静的な HTML で、ダウンロードボタンはスクリプトが 3 つの CSV 一覧から組み立てる。ボタンを押すとブラウザの中で次の 3 つを ZIP にまとめる。

| 中身 | URL の形 | 形式 |
|---|---|---|
| CSV | `https://hinanmap.gsi.go.jp/hinanjocp/defaultFtpData/csv/<キー>.csv` | UTF-8 BOM 付き |
| GeoJSON | `https://hinanmap.gsi.go.jp/hinanjocp/defaultFtpData/geoJSON/<キー>.geojson` | Point、座標は小数 6 桁に丸めてある |
| ご利用上の注意 | `https://hinanmap.gsi.go.jp/hinanjocp/assets/notice/ご利用上の注意.txt` | Shift_JIS |

キーは `<コード>_2` が指定緊急避難場所、`<コード>_1` が指定避難所。コードは全国が `mergeFromCity`、都道府県が `01000` の形、市町村が 5 桁の団体コード。全国ファイルは公開している全市町村をまとめたもので、都道府県別と市町村別は同じ行を分けたもの。全国 CSV にだけ「都道府県名及び市町村名」列がある。

一覧の元になる CSV は 3 つある。

- `defaultFtpData/publicHistoryCSV/publicHistoryListData.csv`: 市町村ごとに コード、名称、公開日、最終更新日、状態フラグ、特筆事項。フラグ 11 は指定緊急避難場所のみ公開、12 は指定避難所のみ公開、9 はデータ未登録。
- `defaultFtpData/publicHistoryCSV/prefectureListData.csv`: 都道府県ごとの最終更新日と状態フラグ。
- `defaultFtpData/publicHistoryCSV/countrySetData.csv`: 全国ファイルの状態フラグ。

Shapefile は国土地理院からは配られていない。G空間情報センターの `https://www.geospatial.jp/ckan/dataset/db74071f-cd0a-406d-ba3d-57c7a25d9925` にある Shapefile と GeoJSON は、社会基盤情報流通推進協議会 (AIGID) が国土地理院のデータを加工したもので、指定緊急避難場所だけ、2026-06 時点のもの。一次配布元ではないので取らなかった。

`www.gsi.go.jp` と `hinanmap.gsi.go.jp` は TLS の legacy renegotiation を要求する。OpenSSL 3 の既定では curl も Python も接続に失敗するので、`ssl.OP_LEGACY_SERVER_CONNECT` を立てて取る。

## 更新のされ方

上書き型である。版番号も日付付きのファイル名も無く、同じ URL のファイルが毎朝作り直される。2026-10-06 に見た Last-Modified は全国 CSV が 00:30:57 GMT、GeoJSON が 00:31:01〜02 GMT、一覧 CSV 3 つも 00:30:57 GMT だった。ご利用上の注意だけは 2026-04-01 のまま。

版の目印になるのは一覧の最終更新日である。一覧ページは市町村ごとの最終更新日の最大値を全国データの最終更新日として表示している。2026-10-06 の取得ではこれが 2026-10-05 だったので、取得リポジトリは `data/raw/2026-10-05/` に置いた。一覧の日付は国土地理院のデータベースが更新された日で、市町村長が指定した日とは違うとページに書いてある。

保守の予告もある。一覧ページのお知らせは 2026-10-07 (水) 9:00〜12:00 にメンテナンスで止まると告げていた。

## 座標系

国土地理院はこのデータの測地系を書いていない。一覧ページは緯度と経度を「10 進法」とだけ定義している。GeoJSON には `crs` メンバーが無く、RFC 7946 の読み方では WGS 84 の経度・緯度になる。取得リポジトリの GeoParquet は再投影せず、`crs` を書かない (GeoParquet の既定で OGC:CRS84)。

## 毎朝の作り直しと上流 (2026-10-06)

全国ファイルは毎朝作り直されるが、別の配布元から取り込んでいるのではなく、市町村が国土地理院に登録した内容を全国版にまとめ直していると読める。根拠は、全国ファイルの名前が mergeFromCity であること、一覧 (publicHistoryListData.csv) の 1,747 市町村それぞれに初回公開日 (2017 年が 1,137) と最終更新日 (市町村ごとにばらばら) があること、「ご利用上の注意」1. が「各市町村に登録いただいたもの」と書くこと。登録の仕組みを書いた文書は確かめていない。さらに上流は指定をする市町村長 (災害対策基本法 49 条の 4) で、市町村によっては自分のサイトで「指定緊急避難場所一覧」をオープンデータとして出しているが、全国でまとまった形の一次の置き場所は国土地理院とみる。
