# 3-E 3 つの四半期をまとめた目的変数

```sh
uv run python src/003-E-pooled-target/run.py
```

3-C で、1 つの四半期のタイルの速度はほとんど雑音だと分かった。そこで 2025 年第 4 四半期、2026 年第 1、第 2 四半期をまとめて、雑音の少ない目的変数を作り、3-A と 3-D をやり直した。数字は 2026-09-29 に回したもの。8GB の上限で囲み、最大 442MB、107 秒。

## 目的変数の作り方

1. 四半期ごとに、下りの平均速度の対数から、その四半期の 23 区全体の平均 (測定回数で重み付け) を引く。四半期の間で全体の速度がずれていたため (3-C)。
2. タイルごとに、1 の値を測定回数で重み付けして平均する。重みは 3 つの四半期の測定回数の合計。

対象は 3-A と同じ 2026 年第 2 四半期の 2,246 タイル。3 つの四半期すべてにあるタイルが 78%、2 つが 17%、1 つが 5%。1 タイルの測定回数の中央値は 6 回から 17 回になった。

## 結果

測定回数で重み付けした R²、5 分割 (ランダム) の予測をまとめて測る。分割の切り方 (乱数の種 0 から 4) を 5 通り変えた平均と標準偏差:

| モデル | 1 つの四半期、基地局なし | まとめた目的変数、基地局あり |
|---|---:|---:|
| 線形 | 0.046 (0.018) | 0.020 (0.027) |
| scikit-learn HistGB | 0.094 (0.015) | 0.083 (0.049) |
| XGBoost | 0.080 (0.023) | 0.094 (0.025) |
| LightGBM | 0.042 (0.035) | 0.110 (0.030) |
| CatBoost | 0.099 (0.012) | 0.175 (0.027) |

乱数の種 0 の 1 回だけで見たときの、4 通りの組み合わせ:

| モデル | 1 つの四半期 | + 基地局 | まとめた目的変数 | + 基地局 |
|---|---:|---:|---:|---:|
| 線形 | 0.059 | 0.044 | 0.046 | 0.009 |
| scikit-learn HistGB | 0.095 | -0.009 | 0.161 | 0.072 |
| XGBoost | 0.068 | 0.010 | 0.031 | 0.065 |
| LightGBM | -0.023 | -0.022 | 0.073 | 0.139 |
| CatBoost | 0.081 | 0.120 | 0.001 | 0.167 |

## 読み方

- 分割の切り方を変えるだけで、点数は標準偏差で 0.01 から 0.05 動く。これはモデルの間の差と同じくらいの大きさ。1 回の分割での順位はあてにならない (乱数の種 0 の HistGB の 0.161 は、5 通りの平均では 0.083)。
- それでも CatBoost は、0.099 から 0.175 へ、ばらつきの 3 倍ほど上がった。雑音の少ない目的変数と基地局の特徴量の組み合わせは、CatBoost では確かに効いている。線形は上がらない。
- 1 つの四半期とまとめた目的変数では、目的変数そのものが違い、R² の分母 (目的変数のばらつき) も違う。2 つの列の R² は厳密には同じ物差しではない。
- 3-C の天井 (前の四半期で R² 0.15) を超えたのは、目的変数の雑音が減ったため。まとめた目的変数の天井は、別の年の四半期が手に入れば同じ方法で測れる。

この 3 番のタイルでも、隣り合うタイルが学習とテストに分かれるランダム分割を使っている。4 番で空間的に分けたときに点数がどれだけ下がるかを見る。
