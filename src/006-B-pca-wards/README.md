# 6-B PCA: 23 区の道で、台東区の軸は保たれるか

```sh
uv run python src/006-B-pca-wards/run.py
```

6-A と同じ道路の数値を、23 区の 250m 格子ごとに集計して PCA にかける (`study_geoai.features.street_cells`)。6-A で「道の性質ではない」とわかった撮影の枚数は外し、11 個の数値を使う。撮影 30 枚以上の格子は 7,152 個。格子の区は、写真が最も多く入っている区とした。数字は 2026-09-29 に回したもの (`output/run.log`)。8GB の上限で囲み、最大 392MB、3 秒。

|---|---:|---:|---:|---:|
| 車道の幅 | 0.26 | 0.45 | 0.07 | 0.06 |
| 歩道の幅 | 0.37 | 0.01 | 0.49 | 0.05 |
| 歩道のある割合 | -0.28 | -0.05 | 0.58 | -0.02 |
| 電柱の数 | -0.38 | 0.31 | 0.19 | 0.34 |
| 街灯の数 | 0.25 | 0.45 | -0.05 | 0.14 |
| 緑の割合 | 0.03 | -0.42 | -0.01 | 0.52 |
| 色の鮮やかさ | 0.17 | -0.27 | -0.24 | 0.61 |
| 無電柱化の割合 | 0.44 | -0.06 | -0.15 | -0.16 |
| 電線の多い割合 | -0.43 | 0.11 | -0.01 | 0.17 |
| ブロック舗装の割合 | 0.16 | -0.41 | 0.47 | -0.11 |
| 見通しの悪い割合 | -0.27 | -0.26 | -0.28 | -0.39 |
| 説明する分散の割合 | 0.329 | 0.193 | 0.122 | 0.095 |

- PC1 (33%): プラス側が無電柱化・広い歩道・広い車道・街灯、マイナス側が電線・電柱・見通しの悪さ。「整備された広い道」と「電柱と電線の細い道」の軸。地図 (`output/pc1-tokyo23.png`) では、幹線道路が赤い線として浮かび、都心と湾岸の埋立地は面として赤い。西の住宅地は青い。
- PC2 (19%): プラス側が車道の幅・街灯・電柱、マイナス側が緑・ブロック舗装・色の鮮やかさ。「幹線道路」と「緑とブロック舗装の歩行者の道」の軸。
- 歩道のある割合が PC1 でマイナスなのは意外。広い道では、歩道が写真の画角の外になり、「画角外で不明」と判定されやすいためかもしれない (未確認)。
- 並行分析では 4 つがシャッフルより大きい (PC4 は 1.04 と 1.03 で、ぎりぎり)。台東区の 173 格子では 2 つだった。データが増えると、小さな構造も偶然と区別できるようになる。5-D の DPMM で型が増えたのと同じこと。ブートストラップでは、4 つとも向きがほぼ変わらない (|cos| の 5 パーセンタイル 0.99 以上)。

## 2. 台東区の軸は 23 区でも保たれるか

台東区だけの PCA (6-A から撮影の枚数を外したもの) の主成分と、23 区の主成分を比べた。

| 台東区の主成分 | 23 区の PC1 との \|cos\| | PC2 との \|cos\| | 23 区の PC1-PC2 平面に入る割合 |
|---|---:|---:|---:|
| PC1 | 0.63 | 0.71 | 0.95 |
| PC2 | 0.64 | 0.42 | 0.77 |
| PC3 | 0.22 | 0.09 | 0.23 |

- 台東区の PC1 は、23 区の PC1 とも PC2 とも一致しない。しかし、23 区の PC1 と PC2 が作る平面には 95% 入っている。同じ平面の中で、軸が約 45 度回っている。
- 主成分の 1 本ずつは、どのデータで計算したかで回る。比べるなら、1 本ずつではなく、主成分が作る平面 (部分空間) で比べる必要がある。

区ごとに同じことをした (区の中だけで標準化して PCA)。

| 区 | 格子 | 区の PC1 と 23 区の PC1 の \|cos\| | 区の PC1 が 23 区の平面に入る割合 | 区の PC1、PC2 の説明割合 |
|---|---:|---:|---:|---|
| 世田谷区 | 734 | 0.99 | 0.99 | 0.32、0.22 |
| 品川区 | 299 | 0.98 | 0.99 | 0.33、0.21 |
| 港区 | 327 | 0.97 | 0.98 | 0.32、0.25 |
| (中略) | | | | |
| 中央区 | 166 | 0.64 | 0.93 | 0.39、0.22 |
| 台東区 | 154 | 0.64 | 0.96 | 0.45、0.23 |
| 文京区 | 176 | 0.53 | 0.94 | 0.44、0.27 |
| 杉並区 | 408 | 0.40 | 0.94 | 0.28、0.26 |
| 目黒区 | 193 | 0.16 | 0.87 | 0.30、0.26 |

- すべての区で、区の PC1 は 23 区の平面に 87% 以上入る。道の違いを表す 2 次元の平面は、23 区で共通している。
- 平面の中の向きは区によって違う。目黒区と杉並区は、PC1 と PC2 の説明割合がほぼ同じ (0.30 と 0.26、0.28 と 0.26)。固有値が近い 2 本は、少しのデータの違いで入れ替わる。
- 台東・中央・文京区は、PC1 の説明割合が大きいのに向きが違う。こちらは区の道の違いが、23 区全体とは別の組み合わせで起きていると考えられる。
- ほとんどの区が PC1 と PC2 の向きまで一致するのは、世田谷区 (734 格子) や大田区 (696) のように格子の多い区が 23 区の PCA を決めているからでもある。

## 3. 区ごとの違い

23 区の主成分得点を区ごとに見た (`output/ward-medians.png`)。

| 区 | PC1 の中央値 | PC2 の中央値 |
|---|---:|---:|
| 中央区 | +2.17 | +0.18 |
| 千代田区 | +1.96 | +0.22 |
| 江東区 | +1.63 | +0.03 |
| 港区 | +1.26 | -0.07 |
| (中略) | | |
| 杉並区 | -1.03 | +0.18 |
| 世田谷区 | -1.36 | -0.43 |
| 中野区 | -1.39 | +0.55 |
| 練馬区 | -1.49 | +0.61 |

- PC1 では、都心 (中央・千代田・港区) と湾岸の埋立地 (江東区) が「整備された広い道」の側にあり、西の住宅地 (練馬・中野・世田谷・杉並区) が「電柱と電線の細い道」の側にある。
- ただし、区の違いで説明できるのは、PC1 の得点の分散の 23% (イータ二乗)、PC2 では 6% だけ。どの区の中にも、幹線道路と細い道が混ざっている。区の 10 パーセンタイルから 90 パーセンタイルの幅 (例えば江東区の PC1 は -0.48 から +4.17) は、区の中央値の差より大きい。
- 区の中央値は PC1 の方向に並び、PC2 では区の違いがほとんど無い。

## まとめ

- 23 区の道も、台東区と同じ「整備された広い道」と「電柱と電線の細い道」の軸が第 1 主成分になった。幹線道路が地図の上で線として見える。
- 主成分が作る平面は区によらず共通だが、1 本ずつの向きは区で回る。主成分を比べるときは、1 本ずつでなく平面 (部分空間) で比べる。
- データが増えると、並行分析で残す主成分の数も増える (台東区 2 つ、23 区 4 つ)。
- 区の違いは道の違いのごく一部 (PC1 の分散の 23%)。区の中の違いのほうがずっと大きい。
