# 4-C 台東区だけ大きく下がったのは、範囲が小さいからか

```sh
uv run python src/004-C-small-areas/run.py
```

4-A で、空間ブロックで分けると台東区の点数は大きく下がったが、23 区ではほとんど下がらなかった。仮説は「範囲が小さくブロックが少ないと、抜いたブロックの場所の型をほかから学べない」。
正しければ、どの区も区の中だけで CV をすれば下がり、ブロックの少ない区ほど大きく下がるはず。もう 1 つの説明は「台東区だけの事情 (無電柱化が観光地にまとまっている、など)」で、その場合ほかの区はあまり下がらないはず。

各区で、区の中だけのデータで、ランダムと 2km ブロックの 5 分割を比べた。あわせて、ほかの 22 区で学習したモデルでその区を当てた。モデルは 4-A と同じ。数字は 2026-09-29 に回したもの (`output/run.log`)。8GB の上限で囲み、最大 1.5GB、133 秒。

## 無電柱化 (AUC): 仮説を支持

(23 区すべては `output/run.log`)

- 23 区すべてで、区の中の空間ブロックは AUC を下げた。下がり幅の中央値は 0.022。台東区だけの事情ではない。
- ブロックの少ない区ほど大きく下がった。下がり幅とブロックの数の順位相関 (スピアマン) は -0.54 (p = 0.008)。台東区は 7 ブロックで、最も少ない区の 1 つ。
- ブロックの少ない区では、ほかの 22 区で学習したモデルのほうが、区の中の空間 CV より良く当てる (文京区 0.922 と 0.863、台東区 0.892 と 0.870)。範囲の広いデータで学ぶ利点が、小さな範囲ほど大きい。
- ただし、区の大きさはほかのこと (土地の使われ方の多様さ、撮影の量) とも一緒に変わる。ブロックの数だけが原因とまでは言えない。

## 人口密度 (R²): はっきりしない

- 1 区あたり 51 から 276 小地域しかなく、R² そのものが大きくぶれる (区の中のランダム分割で 0.04 から 0.60)。
- 下がり幅は中央値 0.032 で、上がる区もある (-0.10 から +0.32)。ブロックの数との順位相関は -0.16 (p = 0.45) で、偶然と区別できない。
- 台東区の下がり幅 0.316 は 23 区で最も大きい (次は豊島区の 0.273)。人口密度では、台東区に特有の分 (上野公園のような外れ値) が乗っていると考えられる。

## まとめ

- 無電柱化で台東区が大きく下がったのは、主に範囲が小さいため。どの区でも起き、小さな区ほど大きい。
- 小さな範囲のモデルを空間ブロックで測ると、点数は低く出る。それは「その範囲のデータだけでは足りない」ことを示していて、広い範囲で学ぶほうがよい。
- 人口密度は 1 区の小地域が少なすぎて、この比較には向かない。
