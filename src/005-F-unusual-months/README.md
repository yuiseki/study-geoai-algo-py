# 005-F 異常検知: 日本の天気の「普通でない月」を、Isolation Forest と LOF で

```sh
uv run python -u src/005-F-unusual-months/run.py
```

1979-01 から 2025-12 までの 564 か月を、それぞれ 1 行にする。特徴量は、8 地方 x 4 変数 (雨、基準蒸発散量、日最高気温、日最低気温、AgERA5) の偏差。地方の平均から同じ月の 1991-2020 年の平年値を引き、その月の年ごとのばらつきで割った z 値なので、6 月の大雨と 12 月の大雨が同じ重さになる。32 個。数字は 2026-09-29 に回したもの (`output/run.log`)。8GB の上限で囲み、最大 433MB、3 秒。

- Isolation Forest: 無作為な分割を繰り返し、少ない回数で孤立する月ほど異常とする (500 本、乱数の種 0)。
- LOF: 近い 20 か月と比べて、周りがどれだけ疎らか。
- 比べるために、32 個のうち最も大きい |z| の順位も並べた。

## 結果

- Isolation Forest の上位は、1984 年の 1 月から 3 月 (全国の低温。3 月は関東と四国の最低気温が -4 標準偏差)、1980-08 (全国の低温と西日本の大雨、z は最高気温 -2.3 から -3.2、中国の雨 +3.0)、2023-03 と 2024-09 (全国の高温)、2025-07 (北海道の最高気温 +4.5)。
- 2 つの方法の一致は中くらい。スコアの順位相関は 0.79 だが、上位 20 の重なりは 7 か月。Isolation Forest と「最大の |z|」の上位 20 の重なりは 10 か月。
- Isolation Forest の上位 20 には、どの特徴量も |z| 2.5 を超えない月は無かった。この 32 個では、組み合わせだけが珍しい月は上位に出てこなかった。
- 前後の期間の偏りは小さい。上位 50 に入ったのは 1979-2000 年の 264 か月から 27、2001-2025 年の 300 か月から 23。

覚えている人の多い月の順位 (564 か月中):

- 1993 年の冷夏: 7 月は Isolation Forest 45 位、8 月は 20 位。
- 2023-08 の猛暑: 22 位。2020-01 の暖冬: 12 位。
- 2010-08 の猛暑は 125 位、2024-07 は 70 位、2018-07 (西日本の豪雨と猛暑) は 79 位で、上位に出ない。
- 2010-08 を確かめると、最高気温の z はどの地方も +1.0 から +1.8 で、全国がそろって暑いだけだった。基準の 1991-2020 年には暑い 8 月が多く含まれ、そろって暑い組み合わせも何度も起きているので、この基準では珍しくない。2018-07 の雨も、地方の月平均では四国 +1.8、中国 +1.0 にとどまる。数日の豪雨は、月と地方で平均すると薄まる。
- 反対に 1980-08 が 2 位に入る。この夏も記録的な冷夏だったが、最初に並べた「覚えている月」には入れていなかった。

## まとめ

- 異常検知は「基準から離れていること」を測るので、基準の選び方がそのまま答えになる。温暖化を含む 1991-2020 年の基準では、真夏の猛暑 (2010-08、2024-07) は上位に出にくい。上位に入る近年の月は、季節外れの暑さ (2023-03、2024-04、2024-09、2021-03) のほう。
- Isolation Forest と LOF は同じ月を上位に挙げることもあるが、上位 20 の半分以上は入れ替わる。どちらか 1 つの順位を「異常さ」として扱うのは危うい。
- 月と地方で平均すると、短い極端な現象 (豪雨) は消える。何を 1 行にするかで、見つかる異常が変わる。
