# 011-C 予測区間: 90% の区間は、本当に 90% を含むか

```sh
uv run python -u src/011-C-prediction-interval/run.py
```

関東 (1 都 6 県) の AgERA5 格子 331 個の、各月の雨 (mm) と日最高気温 (C) に、90% の予測区間を付ける。手がかりは、月、格子の位置、その格子の過去 12 か月の値。数字は 2026-09-29 に回したもの (`output/run.log`)。8GB の上限で囲み、最大 543MB、23 秒。

年で分ける: 学習 1980-2010、較正 2011-2015、試験 2016-2025。

- 平年値の区間: 学習期間の、同じ格子と同じ月の 5% 点と 95% 点。モデルは使わない。
- 分位点 GBDT: 分位点の損失で、0.05 と 0.95 の 2 つのモデルを学習する。
- CQR (conformalised quantile regression): 同じ 2 つのモデルの区間を、較正期間で外れた幅の 90% 点だけ広げる (または狭める)。較正期間と試験期間の年が入れ替え可能なら、平均で 90% が保証される。

## 雨

- 平年値: 含む割合 87.1%、幅 170mm、上に外れる 6.5%、下に外れる 6.5%
- 分位点 GBDT: 80.3%、幅 148mm、上 9.2%、下 10.5%
- CQR (+21.0mm 広げた): 91.5%、幅 190mm、上 4.9%、下 3.6%

- 分位点 GBDT の区間は狭く (学習期間に合わせすぎたためと考えられる)、較正期間でも 79.1% しか含まない。CQR がその分を広げて 90% に戻した。
- ただし月ごとには保証されない。10 月は CQR でも 71% (台風の大雨が外れていると考えられるが、確かめていない)、平年値の区間では 6 月が 75%。
- 年ごとの CQR は 83% (2020 年) から 99% (2016 年)。

## 気温

- 平年値: 含む割合 56.9%、幅 3.5C、上に外れる 43.1%、下に外れる 0.0%
- 分位点 GBDT: 76.0%、幅 3.2C、上 15.0%、下 8.9%
- CQR (+0.3C 広げた): 84.6%、幅 3.8C、上 9.6%、下 5.9%

- 平年値の区間は、試験期間の 43% で上に外れ、下には一度も外れない。1980-2010 年の同じ月の範囲は、温暖化した 2016-2025 年には低すぎる。
- CQR でも 90% に届かない (84.6%)。較正の 2011-2015 年より試験の年が暖かく、入れ替え可能という前提が崩れているためと考えられる。年ごとには 2018 年 76%、2023 年 74%、2025 年 77% と、暑かった年に下がる。
- 最も外れるのは 3 月 (CQR 61%)。3 月の気温は、過去 12 か月の値からは読みにくいようだ。

## 気をつけること

- 試験の行は 39,720 あるが、同じ月の 331 格子はほぼ同じ天気なので、独立な標本は 120 か月に近い。含む割合の 1% の差を読むほどの精度は無い。
- 平年値の区間は格子と月ごとに 31 年の値から取るので、端の分位点は粗い。

## まとめ

- 分位点を学習したモデルの区間は、そのままでは狭すぎることがある (雨で 80%)。較正の期間で外れ方を測って広げると、平均では 90% に戻る。
- conformal の保証は「較正と試験が入れ替え可能」なときだけ。温暖化のような傾向があると、較正したのに 90% に届かない。
- 平均で 90% でも、月ごと (台風の 10 月、季節外れの 3 月) には保証されない。区間を使う人が、どの条件での 90% なのかを知っている必要がある。
