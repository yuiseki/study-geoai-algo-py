# 9-B 施設配置: p-median と、最大被覆との違い

```sh
uv run python src/009-B-facility-location/run.py
```

台東区で、8 章と同じ 566 か所の候補地 (医療機関 P04 と学校 P29) から p か所を開き、住民がそれぞれ最寄りの開いた拠点まで歩く距離の合計を最小にする (p-median 問題)。需要は住む人のいる 108 の町丁目 (2020 年国勢調査)、距離は 7-A の歩行者の道路網で測る (町丁目ごとに Dijkstra を 1 回、24 秒)。数字は 2026-09-29 に回したもの (`output/run.log`)。8GB の上限で囲み、最大 1.5GB、55 秒。

モデル (`study_geoai.facility.p_median`、scipy の `milp` から HiGHS を呼ぶ):

```
最小化    Σ 人口_i 距離_ij x_ij
制約      Σ_j x_ij = 1          (町丁目ごとに 1 つの拠点へ)
          x_ij ≤ y_j            (開いた拠点にだけ)
          Σ_j y_j = p
          x, y は 0 から 1、y は整数
```

## 1. 厳密解と、LP、欲張り法、交換法

| p | 平均の歩く距離 (MILP) | 秒 | LP / MILP | 欲張り法 / MILP | 交換法 / MILP |
|---:|---:|---:|---:|---:|---:|
| 1 | 1,442m | 7.4 | 1.0000 | 1.0000 | 1.0000 |
| 2 | 1,014m | 2.4 | 1.0000 | 1.0575 | 1.0000 |
| 3 | 842m | 2.0 | 1.0000 | 1.0260 | 1.0000 |
| 5 | 666m | 1.9 | 1.0000 | 1.0340 | 1.0000 |
| 8 | 528m | 1.9 | 1.0000 | 1.0524 | 1.0064 |
| 10 | 473m | 1.7 | 1.0000 | 1.0331 | 1.0270 |
| 15 | 378m | 1.5 | 1.0000 | 1.0631 | 1.0004 |
| 20 | 320m | 1.4 | 1.0000 | 1.0748 | 1.0000 |

- LP は、どの p でも最初から整数の解になった (y が小数の拠点は 0)。p-median の LP は、この程度の大きさの問題では整数になることが多いと知られていて、そのとおりだった。8 章の最大被覆で k = 8 から小数が出たのとは対照的。
- 欲張り法 (歩く距離の合計を最も減らす拠点を 1 つずつ開く) は、最適より 3 から 7% 長い。最初に開いた拠点を後から動かせないため。
- 交換法 (Teitz と Bart の方法: 開いた拠点を閉じた拠点と入れ替えて、良くなる限り続ける) を欲張り法の後に回すと、8 つの p のうち 5 つで最適に届き、残りも 2.7% 以内になった。
- p = 1 の 7.4 秒は、初回の準備を含むと考えられる (測ってはいない)。

## 2. p-median と最大被覆は、違う拠点を選ぶ

同じ p で、8 章の最大被覆 (400m 以内の人口を最大にする、同じ町丁目と同じ距離で解き直したもの) と比べた。

| p | p-median の平均 | p-median で 400m 以内 | 最大被覆の平均 | 最大被覆で 400m 以内 |
|---:|---:|---:|---:|---:|
| 2 | 1,014m | 8.1% | 1,327m | 13.2% |
| 5 | 666m | 15.1% | 791m | 31.7% |
| 10 | 473m | 35.3% | 589m | 54.4% |
| 20 | 320m | 72.8% | 380m | 84.9% |

- p = 5 で、p-median は平均 666m だが 400m 以内は 15% だけ。最大被覆は 400m 以内が 32% だが、平均は 791m。
- 地図 (`output/p5-taito.png`) では、p-median は 5 か所を区全体に散らし、どの町丁目も極端には遠くならない。最大被覆は人の多い北東に 4 か所を集め、400m の円にできるだけ多くの人を入れる。その代わり、西 (上野、谷中の側) と区の端の町丁目は 1.2 から 1.5km 歩く。
- 「平均の近さ」(p-median) と「一定の距離に入る人の多さ」(最大被覆) は、どちらも「近くに置く」の言い換えに見えるが、選ぶ拠点がまったく違う。どちらを目的にするかは、拠点の役割 (毎日通う所か、数分以内に届くことが大事な所か) で決める。2 つを同時に見るなら、12 章の多目的最適化になる。

## 気をつけること

- 需要は町丁目の中心に集めている。400m 以内の割合は、町丁目の中心が 400m 以内に入るかで数えたので、100m 格子で数えた 8 章の値とは合わない。
- 候補地の多くは診療所と歯科医院で、拠点の名前 (歯科医院など) に意味は無い。「その場所に置く」ことだけを表す。

## まとめ

- p-median の LP はここでは常に整数で、MILP はどの p も 2 秒前後で解けた。
- 欲張り法は 3 から 7% 悪いが、交換法を足すとほぼ最適になる。
- 同じ数の拠点でも、平均の距離を小さくする (p-median) か、一定の距離に入る人を増やす (最大被覆) かで、選ぶ場所がまったく変わる。
