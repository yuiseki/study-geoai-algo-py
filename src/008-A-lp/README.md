# 8-A LP: 最大被覆を連続値に緩めて解く

```sh
uv run python src/008-A-lp/run.py
```

台東区で、候補地から k か所を選び、歩いて 400m 以内に住む人を最大にする (最大被覆問題)。AED のような拠点を置く場面を想定した。この 8-A では、選ぶかどうかの変数を 0 から 1 の連続値に緩めた LP を解く。数字は 2026-09-29 に回したもの (`output/run.log`)。8GB の上限で囲み、最大 432MB、8 秒。

## 問題

- 需要: WorldPop 2025 年の 100m 格子のうち、台東区に入り人口のある 1,422 格子 (209,240 人)。格子の中心を、7-A の歩行者の道路網の最寄りのノードに寄せた。
- 候補地: 区内の医療機関 (P04、病院・診療所・歯科) と学校 (P29、幼稚園を含む) の 566 か所。
- 覆う: 候補地から道に沿って 400m 以内の格子 (`study_geoai.cover.coverage`、Dijkstra を 400m で打ち切る)。どこかの候補地から届く人は 97.8%。1 か所で覆う格子は中央値 42。

変数は、候補地 j を選ぶか x_j と、格子 i が覆われるか y_i (`study_geoai.cover`)。

```
最大化    Σ 人口_i y_i
制約      y_i ≤ Σ (i を覆う候補地 j の) x_j    (格子ごと)
          Σ x_j = k
          0 ≤ x, y ≤ 1   (8-B の MILP では x を整数に)
```

(k = 1 から 20 のすべては `output/run.log`。「LP を丸めた解」は x の大きい順に k か所を選んだもの)

### LP の解は、k が小さいうちは整数

- k = 7 までは、LP の最適解がそのまま 0 か 1 だった。LP を解くだけで最適な選び方が出る。
- k = 8 から小数が現れる。ほとんどが x = 0.5。地図 (`output/lp-k10.png`、k = 10) では、区の中ほどの北寄りに x = 0.5 の拠点が 8 つ互い違いに並び、その周りの格子が「半分だけ覆われた」状態 (y = 0.5) になっている。重なり合う候補地を半分ずつ使うと、1 か所をまるごと使うより多くの人を「半分ずつ」覆える。整数の選び方ではありえない状態で、LP の上限はその分だけ水増しされる。
- k = 16 以上では 60 から 70 か所が小数になった。

### 双対価格: 拠点を 1 つ増やすと何人増えるか

- `Σ x_j = k` の制約の双対価格は、k を少し増やしたときの LP の最適値の増え方 (傾き) で、「拠点をもう 1 か所増やす価値」を人数で表す。k = 1 で 9,811 人、k = 20 で 5,130 人と、k が増えるほど小さくなる (人の多い所から先に覆われるので)。
- 実際に k を 1 増やしたときの LP の増分 (LP(k+1) − LP(k)) は、どの k でも双対価格以下だった。LP の最適値は k について凹なので、傾きは右へ行くほど小さく、1 つ先までの平均の増分は今の傾きを超えない。
- 双対価格は、HiGHS が最小化で解く都合で符号が反転する。k = 1.5 の前後の差分の傾きと一致することをテストで確かめた (`tests/test_cover.py`)。

### LP を丸めても良い解にならない

- x の大きい順に k か所を選ぶと、LP の上限の 88% まで落ちることがある (k = 11、18)。x = 0.5 の拠点どうしは覆う範囲が重なっているので、上から選ぶと重なった拠点を両方選んでしまう。
- 欲張り法 (覆われていない人を最も多く増やす拠点を 1 つずつ選ぶ) は、どの k でも LP の上限の 97% 以上だった。欲張り法には「最適の 1 − 1/e (63%) 以上」という保証があるが、実際にはずっと良い。
- 最適な選び方 (MILP の解) は、欲張り法と LP の上限の間にある。k = 20 でも、その幅は 2.8% しかない。どこに落ちるかは 8-B で MILP を解いて確かめる。

### 解法

- k = 10 で、HiGHS (highspy を直接呼ぶ) も OR-Tools の GLOP も 88,134 人で一致した。時間は HiGHS 0.19 秒、GLOP 0.01 秒。HiGHS の時間には、呼び出しの準備が含まれていると考えられる (内訳は測っていない)。

## まとめ

- 最大被覆を LP に緩めると、上限と、拠点 1 か所の価値 (双対価格) が一度に出る。
- k が小さいうちは LP の解がそのまま整数だが、拠点の覆う範囲が重なり合う所では x = 0.5 のような「半分ずつ使う」解が現れ、上限が水増しされる。
- LP の小数解を上から丸めるのは悪い方法で、欲張り法のほうがずっと良い。
