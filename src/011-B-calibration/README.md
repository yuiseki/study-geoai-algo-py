# 11-B 較正: 無電柱化の分類器の確率は、確率として信用できるか

```sh
uv run python -u src/011-B-calibration/run.py
```

1-B から 3-B の 3 つのモデル (ロジスティック回帰、ランダムフォレスト、XGBoost) を、台東区のみちよみの写真 32,593 枚 (無電柱化 11.6%) で比べる。特徴量は 11-A と同じ道の 6 つ。分割の外の予測 (out of fold) をまとめて採点する。数字は 2026-09-29 に回したもの (`output/run.log`)。8GB の上限で囲み、最大 611MB、72 秒。

## 何を測るか

- AUC: 無電柱化の写真を、そうでない写真より上に並べられるか (順位だけを見る)。確率の値そのものは見ない。
- Brier スコア: 確率と 0 か 1 の答えの差の 2 乗の平均。小さいほどよい。
- log loss: 答えに付けた確率の対数の平均 (の符号を反転したもの)。自信を持って外すと大きく罰せられる。
- ECE (期待較正誤差): 予測の確率を 10 等分した区間ごとに、「予測の平均」と「実際の割合」の差を、区間の行数で重み付けして平均したもの。「0.3 と言ったものが実際に 3 割当たるか」を 1 つの数にした。
- 較正曲線 (`output/reliability-*.png`): 予測の確率を 10 分位に分け、横に予測の平均、縦に実際の割合を取る。対角線に乗っていれば、確率として信用できる。

後から較正するのは次の 2 つで、どちらも学習用の分割の中で 3 分割の交差検証をして当てる (scikit-learn の `CalibratedClassifierCV`)。

- Platt (sigmoid): モデルの出力をロジスティック関数 (S 字の曲線) で写し直す。
- isotonic: 単調に増える階段関数で写し直す。形を仮定しない。

## 1. ランダムな 5 分割

| モデル | 較正 | AUC | Brier | log loss | ECE | 予測の平均 |
|---|---|---:|---:|---:|---:|---:|
| ロジスティック | なし | 0.849 | 0.0739 | 0.2674 | 0.0182 | 0.116 |
| ロジスティック | Platt | 0.849 | 0.0739 | 0.2670 | 0.0190 | 0.116 |
| ロジスティック | isotonic | 0.852 | 0.0728 | 0.2535 | 0.0019 | 0.116 |
| ランダムフォレスト | なし | 0.926 | 0.0587 | 0.1990 | 0.0039 | 0.116 |
| ランダムフォレスト | Platt | 0.927 | 0.0600 | 0.2089 | 0.0190 | 0.116 |
| ランダムフォレスト | isotonic | 0.926 | 0.0587 | 0.1981 | 0.0032 | 0.116 |
| XGBoost | なし | 0.926 | 0.0594 | 0.2008 | 0.0118 | 0.114 |
| XGBoost | Platt | 0.928 | 0.0602 | 0.2120 | 0.0215 | 0.116 |
| XGBoost | isotonic | 0.928 | 0.0582 | 0.1965 | 0.0062 | 0.116 |

- 較正しないとき、ランダムフォレストが最もよく較正されていた (ECE 0.004)。較正曲線はほぼ対角線に乗る。「ランダムフォレストは確率を 0 と 1 から遠ざける」とよく言われるが、この問題では目立たなかった。葉の最小の行数を 5 にしていることと、確率の高い写真が少ないこと (基準の割合 11.6%) が効いていると考えられる (確かめてはいない)。
- XGBoost は AUC がランダムフォレストと同じ (0.926) なのに、ECE は 3 倍 (0.012)。確率の高い側で言い過ぎる (予測 0.72 に対して実際 0.67)。順位のよさと確率の正しさは別のもの。
- ロジスティック回帰は、中ほどの確率 (0.1 から 0.2) で実際より高く言う。特徴量と対数オッズの関係を直線と仮定しているので、11-A で見た「細い道と 15m の道が無電柱化の側」のような形を表せず、その分が確率のずれとして出る。
- isotonic は、3 つのモデルとも ECE を下げ、曲線を対角線に乗せた (ロジスティック 0.018 → 0.002)。
- Platt は、ランダムフォレストと XGBoost をかえって悪くした (ECE 0.004 → 0.019、0.012 → 0.022)。S 字の曲線は「モデルの出力が S 字にずれている」ときの直し方で、すでに対角線に近い木のモデルには合わない。低い確率の側を持ち上げてしまう (曲線の中央の図)。
- 較正しても AUC はほとんど変わらない (順位を保つ単調な変換なので。isotonic は同じ値を束ねるので、わずかに動く)。

## 2. 250m の格子を丸ごと試験に回す

同じことを、250m 格子 (195 個) を単位にした GroupKFold で行った。学習に使っていない場所で、確率がどれだけ当たるか。

| モデル | 較正 | AUC | ECE |
|---|---|---:|---:|
| ロジスティック | なし | 0.844 | 0.0161 |
| ロジスティック | isotonic | 0.845 | 0.0049 |
| ランダムフォレスト | なし | 0.921 | 0.0022 |
| ランダムフォレスト | Platt | 0.919 | 0.0188 |
| ランダムフォレスト | isotonic | 0.922 | 0.0029 |
| XGBoost | なし | 0.922 | 0.0143 |
| XGBoost | Platt | 0.918 | 0.0186 |
| XGBoost | isotonic | 0.923 | 0.0043 |

(すべての行は `output/run.log`)

- 知らない場所では AUC が少し下がる (0.926 → 0.921 から 0.922)。4-A の台東区の 2km ブロックほどは下がらない。250m の格子は小さく、隣の格子が学習に入るため。
- 較正の順位は同じだった。ランダムフォレストはそのままで最もよく、isotonic は 3 つとも改善し、Platt は木のモデルを悪くする。isotonic で較正したものは、知らない場所でも ECE 0.005 以下を保った。

## 気をつけること

- ECE は、行の大半が入る確率 0 から 0.1 の区間に強く左右される。確率の高い側のずれ (XGBoost の 0.72 と 0.67) は、行が少ないので ECE にはあまり効かない。較正曲線と合わせて見る。
- みちよみの無電柱化の判定そのものが VLM の推定で、正解ではない。ここで言う「当たる」は、「VLM の判定と合う」という意味。

## まとめ

- 順位のよさ (AUC) と確率の正しさ (ECE) は別のもの。同じ AUC のランダムフォレストと XGBoost で、ECE は 3 倍違った。
- 後からの較正は、isotonic がどのモデルでも効いた。Platt は、S 字にずれていないモデルをかえって悪くする。
- 知らない場所 (格子を丸ごと試験に回す) でも、較正の結果はほぼ保たれた。
