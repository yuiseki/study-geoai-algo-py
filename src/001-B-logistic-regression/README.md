# 1-B ロジスティック回帰: その道は無電柱化されているか

```sh
uv run python src/001-B-logistic-regression/run.py            # 台東区と 23 区
uv run python src/001-B-logistic-regression/run.py --area taito
```

数字は 2026-09-29 に回したもの (`output/run.log`、git には入れない)。

## 問題

- 行: みちよみの街路のシーン (Mapillary の画像 1 枚を VLM が読んだもの)。
- 目的変数: `undergrounded` が「無電柱化済」なら 1、「架空線あり」なら 0。「不明」は除く。
- 特徴量 (標準化してからロジスティック回帰):
  - 道と見た目 (street): 車道の幅、左右の歩道の有無、緑の割合、色の鮮やかさ、道路照明の数
  - 比べるために、電柱と電線を足したもの: 見える電柱の数、電線の密度が「高」か
- 使った行: どれかの特徴量が空の行と、隔離 (quarantined) されたシーンは除いた。台東区 53,948 シーンのうち 32,593、23 区 1,386,941 のうち 988,619。
- 目的変数も特徴量も、同じ VLM の読み取りから来ている。VLM の読み違いは両方に同じ向きで入りうる。

## 結果

| 範囲 | 無電柱化済の割合 | 全部「架空線あり」と答えたときの精度 | street の AUC | street の精度 | 電柱と電線ありの AUC |
|---|---:|---:|---:|---:|---:|
| 台東区 | 11.6% | 0.884 | 0.849 | 0.905 | 0.988 |
| 23 区 | 21.4% | 0.786 | 0.702 | 0.792 | 0.968 |

AUC と精度は、ランダムに分けた 5 分割の予測で測った。

### 精度はあてにならない

無電柱化済が少ないので、いつも「架空線あり」と答えるだけで精度は 0.884 (台東区) になる。モデルの 0.905 はそれとほとんど変わらない。
AUC は、どちらが無電柱化済らしいかの並びの正しさを見るので、偏った問題でも差が見える。

### 目的変数の漏れ

「見える電柱の数」と「電線の密度」を入れると、AUC は 0.849 から 0.988 に上がる。係数は電柱の数が -5.9 (標準偏差あたりのオッズが 0.003 倍) で、ほかはほとんど効かなくなる。
電柱が見えることは、架空線があることの言い換えなので、モデルは答えを読み返しているだけになる。予測に使える場面 (電柱の数が分からない場所で無電柱化を推定したい) では使えない特徴量。

### 係数の向きが範囲で変わる

street のモデルの係数 (標準化した特徴量 1 つあたり):

| 特徴量 | 台東区 | 23 区 |
|---|---:|---:|
| 道路照明の数 | -0.999 | +0.160 |
| 緑の割合 | +0.674 | +0.189 |
| 車道の幅 | -0.421 | +0.285 |
| 色の鮮やかさ | +0.144 | +0.179 |
| 左の歩道あり | -0.036 | -0.521 |
| 右の歩道あり | -0.009 | -0.159 |

- 台東区では「照明が多いほど無電柱化されていない」。日本の街灯の多くは電柱に付いているので、VLM が数えた照明の数が電柱の数の代わりになっている (間接的な漏れ) のかもしれない。確かめてはいない。
- 車道の幅の向きも逆になる。台東区では、広い道 (昭和通り、国際通りなど) より、上野や浅草の観光地の狭い道が無電柱化されている、という読み方ができるが、これも確かめていない。
- 1-A の人口密度と違い、こちらは係数が範囲でそろわない。台東区だけで学んだことは、23 区にそのまま持ち出せない。

## 次に確かめること

- 同じ場所の別の年のシーン、同じ撮影の続きのシーン (`sequence_id`) が、学習とテストの両方に入っている。ランダムな 5 分割の AUC は楽観的なはず。4 番で `cell_250m` や `sequence_id` を groups にして比べる。
- 照明の数が電柱の代わりになっているかは、電柱の数との相関や、電柱の数で層を分けた当てはめで見られる。
