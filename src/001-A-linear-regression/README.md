# 1-A 線形回帰: 町丁目の人口密度を建物と POI から

```sh
uv run python src/001-A-linear-regression/run.py            # 台東区と 23 区
uv run python src/001-A-linear-regression/run.py --area taito
```

残差の地図を `output/` に書く (git には入れない)。数字は 2026-09-29 に回したもの。

## 問題

- 行: 2020 年国勢調査の小地域 (町丁目)。台東区 108、23 区 3,150。
- 目的変数: 人口密度 (人/km²)。分布が右に長いので、log(1 + 密度) でも当てはめる。
- 特徴量 (`study_geoai.features.small_areas`):
  - `coverage`: 中心が小地域の中にある Overture の建物の足元の面積 / 小地域の面積 (建蔽率に近い)
  - `log_place_density`: log(1 + Overture の POI の数 / km²)
- 使わなかったもの: 建物の階数と高さ。台東区では階数が 15%、高さが 10% の建物にしか入っていない。

## 結果

| 範囲 | 小地域 | R² (学習) | R² (5 分割) | coverage | log_place_density |
|---|---:|---:|---:|---:|---:|
| 台東区 | 108 | 0.364 | 0.284 | +0.438 | -0.296 |
| 23 区 (0 人を含む) | 3,150 | 0.196 | 0.190 | +0.812 | -0.065 |
| 23 区 (0 人を除く) | 3,072 | 0.171 | 0.165 | +0.450 | -0.181 |

係数は log(1 + 密度) に対する、標準化した特徴量の係数。

- 建物が詰まっているほど住む人が多く、POI が多いほど住む人は少ない。POI が多い町は商業地で、住む場所ではない。
- Ridge と Lasso は、台東区ではほとんど係数を縮めなかった (Ridge 0.419 / -0.281、Lasso 0.419 / -0.277)。特徴量が 2 つで、どちらも効いているため。23 区 (0 人を含む) の Lasso は POI の係数を 0 にした。
- 台東区で外れたのは上野公園 (人口 287 人、密度 348 人/km²) と上野二・四・六丁目。どれも公園か商業地。
- 残差は場所ごとにまとまっている (西の上野・谷中は負、東の浅草側は正)。隣り合う町丁目の誤差が似ているので、ランダムに分けた 5 分割の R² は楽観的かもしれない。4 番 (空間的なデータリーク) で確かめる。

## 23 区で係数が大きく違って見えた理由

23 区には住む人が 0 人の小地域が 78 ある (丸の内などの業務地、臨海の埋立地、大きな公園)。
log(1 + 0) = 0 なので、これらの残差は -10 から -15 になり、当てはめ全体を引っ張る。
0 人の小地域を除くと、coverage の係数は +0.450 で、台東区の +0.438 とほぼ同じになった。

「住む人がいるか」と「いるならどれだけ密か」は分けて扱うほうがよい。前者はロジスティック回帰の題材になる。

## まだ足りないもの

R² は 0.2 から 0.4 で、2 つの特徴量では足りない。23 区で予測より密度が高かったのは勝どき六丁目、晴海二丁目など、高層の集合住宅が多い町。建物の高さが入れば効くはずだが、Overture では大半の建物で空いている。
