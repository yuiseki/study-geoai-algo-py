# 005-E k-means: 日本の気候型を、月ごとの平年値から

```sh
uv run python -u src/005-E-climate-types/run.py
```

006-C と同じ 48 個の特徴量 (雨、基準蒸発散量、日最高気温、日最低気温の 1991-2020 年の月別平均。雨は log(1 + mm)、標準化) で、日本の陸の格子 3,845 個を k-means にかける。数字は 2026-09-29 に回したもの (`output/run.log`)。8GB の上限で囲み、最大 442MB、22 秒。

## 48 個の特徴量のまま

- シルエットは k = 2 が最も高く (0.442)、k を増やすと 0.24 から 0.33 に下がる。乱数の種 5 つでほぼ同じ。
- k = 2 は暖かい所 (2,117 格子、1 月の最高気温 6.8C) と寒い所 (1,728 格子、-2.5C、北海道、東北、中部の山) に分かれる。
- k = 3 も暖かさの帯で分かれる。暖 (1,418、九州、近畿、中国)、寒 (1,183、北海道が 73%)、中間 (1,244、東北と中部。雨が多い)。
- 8 地方との一致 (adjusted Rand index) は 0.300。k = 8 にしても 0.339。天気の型は地方の区分とは別物。
- 48 個のうち 36 個は気温と蒸発散量で、これらは一緒に動く。標準化しても、距離の大半を暖かさが決める。そのため日本海側と太平洋側の違いは、k = 2 と 3 では型として出てこない (ほかの k の中身は見ていない)。

## 主成分 4 つを等しく重み付けすると

- 006-C で並行分析を通った 4 つの主成分を、それぞれ分散 1 にそろえて (whiten)、同じ k-means にかけた。軸ごとに 1 票になる。
- シルエットは k = 5 が最も高い (0.326)。
- 5 つの型: 北海道と東北北部 (1,108)、温暖で雨の少ない所 (1,109、中国、近畿、関東)、雨の多い所 (720、中部 41%、九州・沖縄 18%、関東 16%。年 2,281mm)、日本海側 (553、1 月の雨が 191mm、東北と中部の日本海側)、沿岸と島 (355、九州・沖縄 37%、北海道 11%、中国 11%。地図では海沿いの格子と島)。
- 日本海側が型として出てきた。重み付けで PC3 (冬の雨) に 1 票が回ったためと考えられる。
- 一方で「沿岸と島」は、沖縄と北海道の海沿いを 1 つの型にしている。0.1 度の格子の海沿いは海の影響を受けた値になるので、この型は気候の違いではなく格子の作りを拾っている疑いがある (未確認)。
- 8 地方との一致は 0.300 のまま。48 個の特徴量での k = 5 との一致も 0.451 で、型の分かれ方は大きく変わる。

## 期間を変えると

- 1981-2000 年と 2006-2025 年で別々に k = 3 を当てはめると、一致は 0.870、型が変わる格子は 4.6%。
- 前の期間の中心に、後の期間の平年値を当てはめると、12.1% の格子が別の型に入る。中間の型から暖の型へ 253 格子、寒の型から中間の型へ 214 格子。暖かさの帯が北と山の上へずれたと読める (地図では確かめていない)。

## まとめ

- k-means の型は、特徴量の数え方で決まる。同じ向きに動く特徴量がたくさんあると、その方向だけで分かれる。
- 主成分にして重みをそろえると、別の型 (日本海側) が見える。ただし、どの重みが正しいという答えはない。
- シルエットは 0.24 から 0.44 で、はっきりした塊ではない。005-A (町丁目の型) や ferspas-udf の気候型と同じく、選んでいるのは「いちばんましな切り方」。
