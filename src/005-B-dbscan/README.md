# 5-B DBSCAN と HDBSCAN: POI の点の集まりを見つける

```sh
uv run python src/005-B-dbscan/run.py
```

5-A と 5-C は、地域を特徴量で分けた。ここでは Overture の POI の点そのものを、距離だけで塊にする。点は平面直角座標系 IX 系 (EPSG:6677) に変換してあり (`study_geoai.features.place_points`)、eps の単位はメートル。数字は 2026-09-29 に回したもの (`output/run.log`)。8GB の上限で囲み、最大 1.1GB、541 秒 (うち 23 区の HDBSCAN が 502 秒)。

DBSCAN は「半径 eps の中に min_samples 個以上の点がある点」をつなげて塊にし、どこにもつながらない点をノイズ (-1) にする。塊の数を先に決めなくてよく、形も自由だが、密度の基準は全体で 1 つしかない。

## 3. 23 区 (361,206 点): 1 つの eps は、密度の違う区に合うか

仮説: 「DBSCAN の密度の基準は 1 つなので、密な区では広い範囲が 1 つの塊になり、疎な区では点のほとんどがノイズになるはず。HDBSCAN は密度の基準を場所ごとに変えるので、その偏りが小さいはず」。

区ごとに、面積あたりの POI の数と、どこかの塊に入った POI の割合を比べた。

| 区 | POI/km² | DBSCAN (eps 50m、min_samples 20) | HDBSCAN (min_cluster_size 25) |
|---|---:|---:|---:|
| 中央区 | 2,364 | 0.919 | 0.487 |
| 千代田区 | 2,289 | 0.918 | 0.481 |
| 渋谷区 | 2,154 | 0.883 | 0.489 |
| 新宿区 | 1,623 | 0.814 | 0.540 |
| 台東区 | 1,584 | 0.715 | 0.374 |
| (中略) | | | |
| 板橋区 | 300 | 0.315 | 0.552 |
| 練馬区 | 228 | 0.298 | 0.577 |
| 足立区 | 225 | 0.254 | 0.548 |
| 江戸川区 | 217 | 0.287 | 0.544 |
| 江東区 | 209 | 0.393 | 0.578 |
| 23 区の幅 | | 0.254 から 0.919 | 0.374 から 0.659 |
| 密度との順位相関 (スピアマン) | | +0.89 (p < 0.001) | -0.57 (p = 0.005) |

- DBSCAN は仮説どおり。塊に入る割合が区の密度でほぼ決まる。地図 (`output/dbscan-tokyo23.png`) では、中心部が数万点の大きな塊になり、周辺の区では駅前だけが小さな塊として残る。大きな塊は次の 4 つ (中身は別に数えた):
  - 29,803 点: 渋谷 (宇田川町、道玄坂) から港区・目黒区へ。全体の 8% で最大。
  - 28,166 点: 丸の内から銀座、港区へ。
  - 22,303 点: 神保町・神田から湯島を通って上野六丁目まで。千代田・中央・台東の 3 区にまたがって連鎖した。
  - 18,021 点: 新宿三丁目、西新宿、歌舞伎町。渋谷とは別の塊。
- HDBSCAN は区ごとの差が小さくなり、順位相関は逆向きになった。地図 (`output/hdbscan-tokyo23.png`) では、周辺の区の駅前の商店街も塊として拾われ、中心部はたくさんの小さな塊に割れる。台東区でも、DBSCAN で上野と浅草が 4,000 点規模の 2 つの塊になったのに対し、HDBSCAN は浅草一丁目 (1,546 点) や上野六丁目 (288 点) のように細かく分ける (`output/hdbscan-taito.png`)。
- HDBSCAN は、それぞれの点の近くで密度を測るので、「周りより密か」で塊を作る。その代わり、中心部のように全体が密な場所では「どこも周りと同じくらい密」になり、ノイズが半分近く残る。どちらが正しいのではなく、DBSCAN は「決めた絶対的な密度より密な場所」、HDBSCAN は「周りに比べて密な場所」を探している。
- 計算の重さが違う。23 区の DBSCAN は 1.9 秒、HDBSCAN は 502 秒 (台東区では 0.9 秒)。

## まとめ

- DBSCAN の結果は eps で大きく変わり、切れ目の無い街では、ある距離を超えると一気に連鎖する。k 距離グラフの折れ目も、こういう街では見えない。
- 1 つの eps は、密度の違う地域に同時には合わない。塊に入る割合は区の密度で決まってしまう (順位相関 +0.89)。
- HDBSCAN は、密度が場所で変わっても周りより密な所を拾えるが、全体が密な中心部は細かく割れ、計算は 250 倍かかった。
- 点を飲食店に絞るなど、目的に合わせて何を点にするかを選ぶと、DBSCAN でも意味のある塊 (飲食街) が出る。
