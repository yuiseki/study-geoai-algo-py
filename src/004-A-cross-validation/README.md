# 4-A Cross Validation: 分け方を変えると点数はどう変わるか

```sh
uv run python src/004-A-cross-validation/run.py
```

1 から 3 番はすべてランダムな 5 分割で測ってきた。ここではモデルを固定し、分け方だけを変える。数字は 2026-09-29 に回したもの (`output/run.log`)。8GB の上限で囲み、最大 1.5GB、39 秒。

## 分け方

| 分け方 | 同じグループの行は、学習かテストのどちらかにまとめて入る |
|---|---|
| ランダム | (グループなし。これまでの方法) |
| 撮影の続き | みちよみの `sequence_id` (同じ撮影で続けて撮ったシーン) |
| 250m 格子 | みちよみの `cell_250m` (同じ場所の、別の年のシーンも含む) |
| 1km、2km ブロック | 経度・緯度を 0.01 度、0.02 度で区切った格子 (約 0.9km、1.8km) |
| 区ごと | 1 つの区をテストにし、残りの 22 区で学習する。23 区すべてで繰り返す |

モデル: 無電柱化は XGBoost (学習率 0.1、深さ 6、100 本、3-B の結果から)、人口密度はランダムフォレスト (300 本、葉 5 以上)。点数は分割の予測をまとめて 1 回で測る。23 区の無電柱化は 20 万行の標本。

## 結果

| 問題 | ランダム | 撮影の続き | 250m 格子 | 1km | 2km | 区ごと | 22 区で学習して台東区 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 無電柱化、台東区 (AUC) | 0.931 | 0.927 | 0.924 | 0.889 | 0.870 | | |
| 無電柱化、23 区 (AUC) | 0.894 | 0.893 | 0.893 | 0.892 | 0.892 | 0.887 | 0.890 |
| 人口密度、台東区 (R²) | 0.456 | | | 0.236 | 0.139 | | |
| 人口密度、23 区 (R²) | 0.317 | | | 0.311 | 0.296 | 0.300 | 0.416 |

23 区の無電柱化は、標本でなく全 988,619 行でも、ランダム 0.895、2km ブロック 0.893 だった。標本にしたせいで差が小さく見えたのではない。

## 読み方

- 台東区では、空間で分けると点数がはっきり下がる。無電柱化は 0.931 から 0.870、人口密度は 0.456 から 0.139。ランダム分割の点数は、隣の場所の答えを見て当てていた分だけ水増しされていた。
- 同じ場所の別の年 (250m 格子) や同じ撮影 (撮影の続き) で分けたときの下がり方は小さい (0.931 から 0.924)。効いているのは「同じシーンの写し」より「近所どうしが似ている」こと。無電柱化は地区単位で進むので、筋が通る。
- 23 区では、どう分けてもほとんど下がらない (0.894 から 0.887)。
- 22 区で学習して台東区で試すと、無電柱化 0.890、人口密度 0.416。どちらも、台東区の中だけで空間で分けたとき (0.889、0.236) と同じか、それより良い。広い範囲で学んだモデルのほうが、よく持ち出せている。

## なぜ台東区だけ大きく下がるのか (仮説)

- 台東区は 1km ブロックが 18 個しかない。1 つ抜くと、その地区の特徴 (無電柱化がまとまって進んだ観光地など) を学ぶ例が、ほかにほとんど残らない。
- 23 区には似た地区がたくさんあるので、1 つ抜いても同じ型を別の場所から学べる。

確かめるには、23 区のデータを台東区くらいの小さな範囲に切って、同じ比較をすればよい。

## 使いどころに合った分け方

- 「まだデータの無い場所で予測したい」(新しい区、新しい街) なら、空間ブロックか区ごとの点数が実際に近い。
- 「同じ場所の来年を予測したい」なら、撮影年で分ける (4-B)。
- ランダム分割の点数は、どちらの使いどころでも楽観的になりうる。
