# 6-A PCA: 台東区の道を 250m 格子ごとに 2 つの軸に縮める

```sh
uv run python src/006-A-pca/run.py
```

みちよみの道路の写真の分析結果を、250m 格子 (`cell_250m`) ごとに平均した 12 個の数値を PCA で縮める (`study_geoai.features.street_cells`)。撮影が 30 枚未満の格子は除き、台東区で 173 格子。数字は 2026-09-29 に回したもの (`output/run.log`)。8GB の上限で囲み、最大 305MB、2 秒。

`cell_250m` の ID の作り方は、みちよみの説明に書かれていない。写真の位置から「行 x 100000 + 列、南西の角が北緯 20 + 行 x 0.00225 度、東経 120 + 列 x 0.00275 度」と読み取り、すべての写真が自分の格子の中に入ることをテストで確かめた (`michiyomi.cell_bounds`)。

使った 12 個の数値: 車道の幅、歩道の幅、歩道のある割合、電柱の数、街灯の数、緑の割合、色の鮮やかさ、無電柱化の割合、電線の多い割合、ブロック舗装の割合、見通しの悪い割合、撮影の枚数。割合は「不明」「該当なし」を除いて数えた。撮影年は 1970 年から 2026 年まで混ざっている (中央値 2021 年)。

## 1. 標準化した PCA

| | PC1 | PC2 | PC3 | PC4 |
|---|---:|---:|---:|---:|
| 車道の幅 | 0.20 | 0.43 | 0.41 | 0.22 |
| 歩道の幅 | -0.23 | 0.49 | -0.09 | 0.09 |
| 歩道のある割合 | 0.33 | 0.19 | -0.06 | -0.12 |
| 電柱の数 | 0.42 | 0.02 | 0.08 | -0.08 |
| 街灯の数 | 0.31 | 0.38 | 0.21 | -0.06 |
| 緑の割合 | -0.27 | -0.18 | 0.46 | -0.36 |
| 色の鮮やかさ | -0.23 | -0.06 | 0.36 | 0.65 |
| 無電柱化の割合 | -0.39 | 0.05 | -0.06 | -0.39 |
| 電線の多い割合 | 0.32 | -0.29 | -0.01 | -0.08 |
| ブロック舗装の割合 | -0.30 | 0.23 | -0.41 | 0.23 |
| 見通しの悪い割合 | 0.06 | -0.46 | 0.08 | 0.35 |
| 撮影の枚数 | -0.23 | 0.07 | 0.51 | -0.18 |
| 説明する分散の割合 | 0.409 | 0.207 | 0.108 | 0.074 |

- PC1 (41%): プラス側が電柱・電線の多さ、マイナス側が無電柱化・ブロック舗装・緑。「電柱と電線のある普通の道」と「整備された道」の軸。
- PC2 (21%): プラス側が車道と歩道の幅・街灯、マイナス側が見通しの悪さと電線。「広い通り」と「見通しの悪い細い道」の軸。
- PC3 (11%) は撮影の枚数が最も大きく、緑と車道の幅が一緒に乗る。道の性質というより「どれだけ撮られたか」が混ざった軸。PCA は、どの列に意味があるかを知らない。
- 2 つで 62%、4 つで 80%。

## 2. 標準化しないと

撮影の枚数の標準偏差は 300 で、ほかの列 (0.04 から 1.6) より 2 桁以上大きい。標準化しないと、PC1 は撮影の枚数そのものになり、分散の 100% を説明する。車道の幅 (標準偏差 1.6m) は PC2 に回る。PCA は分散の大きい方向を探すので、単位の大きい列がそのまま勝つ。単位の違う列を混ぜるなら、標準化はほぼ必須。

## 3. 主成分をいくつ残すか: 並行分析

各列を独立にシャッフルしたデータ (列ごとの分布は同じで、列の間の相関は無い) で PCA を 200 回行い、その固有値の 95 パーセンタイルと比べた。

| | PC1 | PC2 | PC3 | PC4 | PC5 |
|---|---:|---:|---:|---:|---:|
| データ | 4.93 | 2.50 | 1.31 | 0.89 | 0.70 |
| シャッフル (95 パーセンタイル) | 1.57 | 1.40 | 1.31 | 1.22 | 1.13 |

- シャッフルより大きいのは PC1 と PC2 だけ。PC3 はちょうど同じ。「固有値 1 以上を残す」というよく使われる目安だと PC3 まで残るが、173 格子のデータでは、PC3 は偶然の相関と区別できない (`output/scree-taito.png`)。

## 4. 負荷量は安定しているか: ブートストラップ

格子を 500 回、重複ありで抜き直し、各主成分がもとの主成分とどれだけ同じ向きか (|cos|) を見た。

| | PC1 | PC2 | PC3 | PC4 |
|---|---:|---:|---:|---:|
| 中央値 | 0.99 | 0.98 | 0.95 | 0.88 |
| 5 パーセンタイル | 0.96 | 0.93 | 0.65 | 0.29 |

- PC1 と PC2 は、抜き直してもほぼ同じ向き。PC3 以降は、ときどき別の向きに入れ替わる (固有値が近い主成分どうしは混ざりやすい)。読んでよいのは 2 つまで、という並行分析の結果と合う。

## 5. 地図で確かめる

- PC1 (`output/pc1-taito.png`): マイナス (整備された道) は、西の上野公園の一帯と、東の隅田川沿い。最もマイナスの格子 (北緯 35.7185、東経 139.7753 から) は無電柱化 86%、電柱 0.1 本。プラス (電柱と電線) は、区の中ほどから南の、住宅と商店が混ざる地域。最もプラスの格子 (北緯 35.7028、東経 139.7835 から) は電線の多い割合 85%、電柱 4.1 本、無電柱化 0%。
- PC2 (`output/pc2-taito.png`): マイナス (細い道) は北西の谷中・根岸・鶯谷にまとまる。最もマイナスの格子 (北緯 35.7253、東経 139.7725 から) は、歩道のある割合 6%、見通しの悪い割合 40%。プラス (広い通り) は浅草・蔵前の一帯で、車道 8 から 9m、歩道 2.5 から 3m。
- どちらの主成分も、位置を入れていないのに、地図の上でまとまっている。

## まとめ

- 台東区の道は、12 個の数値のうち、2 つの軸でおよそ説明できる。「電柱と電線があるか、整備されているか」(PC1) と、「広い通りか、見通しの悪い細い道か」(PC2)。
- 残す数は、固有値 1 以上の目安より、並行分析とブートストラップで決めるほうが確か。この例ではどちらも 2 つ。
- 標準化を忘れると、単位の大きい列 (ここでは撮影の枚数) がそのまま第 1 主成分になる。標準化しても、意味の無い列 (撮影の枚数) は第 3 主成分に紛れ込むので、入れる列は選ぶ必要がある。
