# 4-B データリーク: わざと作って、どの分け方なら見抜けるかを見る

```sh
uv run python src/004-B-data-leakage/run.py
```

台東区の無電柱化 (32,593 シーン)、XGBoost (4-A と同じ)。数字は 2026-09-29 に回したもの (`output/run.log`)。

## 1. 目的変数の近所平均 (target encoding)

「同じ 250m 格子の中で、無電柱化済のシーンがどれだけあるか」を特徴量に足す (全体の割合へ少し寄せて平滑化)。

- 全データで計算: テストの行自身の答えが、その行の特徴量に入っている。漏れ。
- 学習側だけで計算: テストの行には学習側の値を使い、学習側の行にも学習側の中でさらに分けて計算した値を使う。正直な作り方。

| 分け方 | 近所平均なし | 全データで計算 (漏れ) | 学習側だけで計算 (正直) |
|---|---:|---:|---:|
| ランダム | 0.931 | 0.970 | 0.967 |
| 1km ブロック | 0.889 | 0.955 | 0.854 |

- ランダムに分けると、漏れのある計算と正直な計算の差がほとんど無い (0.970 と 0.967)。同じ格子のほかの行 (同じ場所の別の年、同じ撮影の続き) が学習側にあるので、正直に作っても近所の答えがそのまま入る。ランダム分割では、この漏れは見抜けない。
- 空間で分けると、正直な計算は 0.854 に落ち、近所平均を足さないとき (0.889) より悪くなる。テストの場所の格子は学習側に無く、特徴量が全体の割合になってしまうため。漏れのある計算は 0.955 のままで、漏れを隠す。
- 空間で分け、かつ正直に計算して初めて、「この特徴量は新しい場所では役に立たない」ことが分かる。

## 2. 時間

| 学習 | テスト | AUC |
|---|---|---:|
| 2020 年以前 (15,376 シーン) | 2021 年以降 | 0.897 |
| 2021 年以降 (17,217 シーン) | 2020 年以前 | 0.927 |
| ランダムな 5 分割 | そのうち 2021 年以降の行 | 0.912 |
| どの年からも無作為に 15,376 シーン | 学習に使っていない 2021 年以降の行 | 0.907 |

- 過去で学習して未来を当てると 0.897、同じ行をランダムに分けると 0.912。差は 0.015 ほどで、時間の漏れはこの問題では小さい。
- 未来で学習して過去を当てるほうが点数が高い (0.927)。未来のほうが無電柱化済の例が多く、学ぶ材料が多いためと考えられる。
- 無電柱化済の割合が、2020 年以前の 4.9% から 2021 年以降は 17.6% に増えている。実際に無電柱化が進んだのか、Mapillary の撮影場所が変わったのか、VLM の読み方が年で違うのかは分からない。AUC は割合の変化に鈍いが、確率の当たり方 (11 番の較正) には効くはず。

## 4 番のまとめ

- 分け方は、使いどころに合わせて選ぶ。新しい場所で使うなら空間ブロック、来年の同じ場所なら時間。
- ランダム分割は、台東区の空間の漏れ (4-A) も、近所平均の漏れ (ここ) も見抜けない。
- 1 から 3 番の点数は、台東区ではランダム分割で楽観的だった。23 区ではほとんど変わらなかった (4-A)。
