# 3-C 雑音の天井: タイルの速度はどこまで繰り返し同じか

```sh
uv run python src/003-C-noise-ceiling/run.py
```

タイルの速度は、そのタイルの数回の測定の平均なので、どんな特徴量でも予測できない雑音を含む。同じタイルの別の四半期の速度を予測値とみなすと、「その場所そのもの」で説明できる量の目安 (天井) になる。
23 区のタイルのうち両方の四半期にあるもので、下りの平均速度の対数を比べた。R² は今の四半期の測定回数で重み付け。「直線で当てはめた R²」は、四半期の間の全体のずれを直線で取り除いたもの。数字は 2026-09-29 に回したもの。

## 結果

2026 年第 2 四半期と第 1 四半期 (両方にある 1,917 タイル):

| 両方の四半期での測定回数 | タイル | 相関 | R² (そのまま) | R² (直線で当てはめ) |
|---|---:|---:|---:|---:|
| 1 以上 | 1,917 | +0.199 | -0.360 | +0.151 |
| 10 以上 | 506 | +0.338 | +0.263 | +0.363 |
| 30 以上 | 146 | +0.560 | +0.592 | +0.601 |
| 100 以上 | 34 | +0.848 | +0.768 | +0.816 |

2026 年第 2 四半期と 2025 年第 4 四半期 (1,955 タイル) もほぼ同じ (すべてで直線の R² 0.166、100 回以上で 0.688)。

## 読み方

- すべてのタイルで見ると、同じタイルの前の四半期の速度ですら R² 0.15 ほどしか説明できない。
- 3-A と 3-D の特徴量の点数 (測定回数で重み付けした R² で 0.06 から 0.12) は、この天井の半分から 8 割ほどに届いている。特徴量が悪いというより、目的変数がほとんど雑音。
- 測定回数が多いタイルほど、四半期をまたいでよく一致する (100 回以上で 0.8 前後)。測定が十分あれば、タイルの速度は安定している。
- 「そのまま」の R² がマイナスになるのは、四半期の間で全体の速度がずれる (その四半期のほうが全体に速い、など) ため。直線で当てはめると消える。

## 次に試せること

- 3 つの四半期を測定回数で重み付けして平均し、雑音の少ない目的変数を作ってから、3-A と 3-D をやり直す。
- 測定回数の多いタイルだけで学習と評価をする (ただし 30 回以上だと 146 タイルしか残らない)。
