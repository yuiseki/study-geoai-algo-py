# 009-C ランダムな配置と現在の避難場所: 最適化はどれだけ得か

```sh
uv run python -u src/009-C-random-placement/run.py
```

8 章と 9 章の最適化が、何も考えずに置いた場合と比べてどれだけ良いかを測る。ケーススタディ [002](../../case-studies/002-shelter-planning/README.md) のベースライン。設定は 9-B と同じで、台東区の住む人のいる町丁目 108 (2020 年国勢調査、211,444 人)、7 章の歩行者の道路網での歩く距離、候補地 566 か所 (医療機関と学校)。数字は 2026-09-29 に回したもの (`output/run.log`)。8GB の上限で囲み、最大 862MB、62 秒。

配置の良さは 2 つで測る。

- 平均の歩く距離: 住民が最寄りの拠点まで歩く距離の平均 (p-median の目的)。
- 400m 以内の人の割合 (最大被覆の目的)。町丁目の中心が 400m 以内かで数える。

## 1. ランダムに選んだ p か所

候補地から p か所を無作為に選ぶことを 2,000 回繰り返し、欲張り法とそれぞれの目的の最適解と比べた。

平均の歩く距離 (ランダムの 5%、50%、95% 点、欲張り法、最適):

- p = 5: 823m、975m、1,349m、欲張り法 689m、最適 666m
- p = 10: 625m、725m、916m、489m、473m
- p = 17: 499m、576m、695m、375m、353m
- p = 20: 469m、540m、649m、344m、320m

400m 以内の人の割合 (同じ順):

- p = 5: 6.8%、11.7%、17.2%、欲張り法 31.7%、最適 31.7%
- p = 10: 15.0%、21.7%、28.9%、54.4%、54.4%
- p = 17: 25.3%、33.7%、42.3%、77.0%、78.4%
- p = 20: 29.4%、38.2%、46.9%、83.3%、84.9%

- どの p でも、2,000 回のランダムな配置の中に最適を上回るものは 1 つも無かった。最適は、ランダムの 95% 点よりずっと先にある。
- 400m 以内の割合は、最適化で 2 倍から 3 倍になる (p = 10 でランダムの中央値 21.7% に対して 54.4%)。平均の歩く距離は 3 割から 4 割縮む (p = 10 で 725m に対して 473m)。
- 欲張り法は、ランダムと最適の差のほとんどを埋める。

## 2. 現在の 17 か所の避難場所

- 現在の指定緊急避難場所 17 か所: 平均の歩く距離 449m (9-A の最寄りへの割当と同じ値)、400m 以内 33.7%。
- 候補地から 17 か所をランダムに選ぶと、平均の歩く距離の中央値は 576m で、現在の配置は 2,000 回のすべてより近い。400m 以内の中央値は 33.7% で、現在の配置とちょうど同じだった。
- 候補地から最適に選んだ 17 か所は、平均の歩く距離なら 353m (400m 以内 61.2%)、400m 以内なら 78.4% (平均 459m)。

- 現在の避難場所は、平均の近さではランダムよりはっきり良いが、400m に届く人の多さではランダムと同じくらい。区全体に散らしてあり、人の多い所に寄せてはいない、と読める (配置の意図は確かめていない)。
- 最適な 17 か所との比較は、同じ土俵ではない。避難場所は学校や公園などで、候補地 (医療機関と学校) と同じ場所とは限らず (重なりは数えていない)、容量 (9-A) も比べていない。最適化で分かるのは「距離だけなら、どこまで縮められるか」の上限。

## まとめ

- 最適化は、ランダムな配置のどれよりも良い。差は大きく、400m 以内の人の割合で 2 倍から 3 倍。
- 欲張り法でも、その差のほとんどが取れる。
- 現在の避難場所は平均の距離ではランダムより良く、400m のカバーではランダムと同じ。どちらの指標で評価するかで、「今の配置の良さ」の答えが変わる。
