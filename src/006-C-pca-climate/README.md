# 006-C PCA: 日本の気候の軸は、期間や場所を変えても保たれるか

```sh
uv run python -u src/006-C-pca-climate/run.py
```

FAO FERSPAS の AgERA5 月別データ (0.1 度、約 10km) で、日本の陸の格子 3,845 個を、月ごとの平年値で表して PCA にかける。数字は 2026-09-29 に回したもの (`output/run.log`)。8GB の上限で囲み、最大 430MB、5 秒 (データの取得は別で、4 変数 x 564 か月を初回だけ約 10 分)。

- 特徴量: 雨 (mm)、基準蒸発散量 (mm)、日最高気温と日最低気温 (C) の 4 つについて、1991-2020 年の各月の平均 (12 か月)。4 x 12 = 48 個。雨は偏っているので log(1 + mm) にし、すべて標準化した。
- 格子は、中心が都道府県の中にあるもの ([ferspas.japan_cells](../study_geoai/ferspas.py))。AgERA5 が海として扱う 5 個は除いた。
- 006-B と同じ問いを立てる。ある標本で当てはめた軸が、別の標本でも同じ向きに出るか。

## 結果

- 並行分析で残す主成分は 4 つ。PC1 が 72.6%、PC2 が 12.4%、PC3 が 5.9%、PC4 が 3.4%。
- PC1 は暖かさ。気温と蒸発散量の 36 個がどの月も +0.15 前後で揃って効く。地図では北海道と山が青、九州と沖縄が赤 (`output/pc-maps.png`)。
- PC2 は一年中の雨の多さ。雨の 12 か月がすべて +0.2 から +0.3 で、ほかはほぼ 0。地図では北陸の山地、紀伊半島、四国南部が赤く出る。
- PC3 は冬の雨と夏の雨の対比。1、2、11、12 月の雨が +0.25 から +0.42、4 月から 10 月の雨がマイナス。地図では日本海側の沿岸と沖縄が赤く、内陸と太平洋側が青い。
- 期間を変えても軸は保たれた。1981-2000 年と 2006-2025 年で別々に当てはめると、PC1 から PC3 の向きの一致 (|cos|) は 0.997、0.991、0.987。
- 場所を変えると、2 番目の軸から揃わなくなる。東日本 (東経 137.5 度以東、2,308 格子) と西日本 (1,537 格子) で別々に当てはめると、|cos| は 0.903、0.712、0.811。PC2 は相手の PC1-PC2 平面にも 0.813 しか入らない。東日本だけの当てはめと日本全体の当てはめは 0.996、0.991 で揃うので、ずれているのは西日本のほう。西日本で何が 2 番目の軸になるのかは、まだ確かめていない。
- 後の期間 (2006-2025) を前の期間の軸に載せると、PC1 はすべての格子で上がり、平均で標準偏差の +0.21。日本の日最高気温の平均は 14.04C から 14.96C に上がっていた。
- PC3 も 97% の格子で上がった (+0.30)。PC3 は最低気温に +、最高気温に - が付くので、夜のほうが速く温まったのではと考えたが、確かめると最高気温は +0.92C、最低気温は +0.94C で同じだった。冬 (12 月から 2 月) の雨は 273mm から 310mm に 13% 増え、夏 (6 月から 8 月) の 4% より大きい。PC3 の上がり方は、この冬の雨の増え方と合う。

## まとめ

- 日本の気候は 48 個の数を 4 つの軸でほぼ表せ、1 つ目は暖かさ、2 つ目は雨の多さ、3 つ目は日本海側か太平洋側か。
- 軸は 20 年ずらしても変わらないが、東と西に分けると 2 つ目から向きが変わる。006-B で台東区の軸が 23 区の平面の中で回っていたのと同じく、軸は当てはめた範囲のもので、ほかの範囲に持っていく前に確かめる必要がある。
- 同じ軸に載せれば、温暖化は「全格子が PC1 の方向に 0.2 標準偏差動いた」と測れる。
